## 一、一句话结构

**原型里 120 屏其实只有 6 件事：拜、祭、读、愿、善、我。** 海外版把它们重排成 5 个 Tab，其中「禅院」不是新增的第 7 件事，而是把**拜（佛前供灯）、愿（许愿树）、善（护生池）、买（陈设斋）**四件散事收进同一个场景——院子是容器，也是养成游戏本体。

| Tab | 承载的原型页面 | 处理 |
|---|---|---|
| **禅院** | 修行/签到、功德详情、供品兑换、我的物品、放生（鱼/龟/蟾）、许愿树、祈福 | 全部收进场景。签到→功课；功德币→香积；供品兑换→陈设斋；放生→护生池；许愿树→院中一树 |
| **经藏** | 经书列表/分类/专题/详情、阅读模式、抄经、抄经设置、批注、诵经、经书排行榜 | 结构基本原样，排行榜删除 |
| **祭怀** | 牌位列表、单/双/三牌位、设立牌位全流程、定制场景、摆放香烛/贡品、祭拜、佛像列表/详情、供香烛、供佛灯 | **全套保留**，从"一次性购买"改成"年费安奉" |
| **善缘** | 祈福列表/主页/主题/编辑/拆福卡/查看所有、行善（规则/列表/详情/发布/记录）、寺庙列表/详情、社区（发布/图/视频/详情/消息/关注/佛友） | 合并为轻社区：祈福墙 + 行善 + 共修。UGC 视频流、关注体系、粉丝、私信**首版不做**（审核与合规成本高于收益） |
| **我的** | 个人中心、编辑资料、登录/注册、功德币/充值/明细、修行值/获取记录、任务、兑换、我的物品、足迹、感悟、攻略、设置、等级、各类排行榜 | 保留账号与钱包，排行榜全删，新增会员与功课年报 |

**删掉的**：功德榜/等级榜/祈福榜/放生榜/善行榜/签到榜/经书榜、排行奖励、抢福袋、拆福卡、寺庙列表与详情、视频社区、关注/粉丝、私信、修行攻略。

理由统一：**榜单 = 把修行变成排名，海外用户对"宗教 KPI"更敏感；福袋/拆卡 = 抽奖机制，触碰 App Store 3.1.1 与各地博彩类审查；寺庙 O2O 与视频社区 = 重运营、重审核，一阶段不背。**

## 二、禅院：把"解锁"换成"生长"

原型的院子是"12 件陈设逐件点亮"，这是一个**有终点的曲线**：重度用户 3 个月点满，之后页面变成静态壁纸，而它占着一级 Tab。改成四层生长模型后永不见底：

| 层 | 机制 | 落地对象 |
|---|---|---|
| **L1 参数化** | 时间量（时段/季节/天气）控光；功课量（字数/连续天/最早抄经时刻）控苔痕厚薄、石阶磨损、树冠疏密、灯色昏黄、倒影清晰度 | 一张宋画底图 + ColorMatrix 调色，不新增美术资源 |
| **L2 转岁** | 不清零，转存。除夕把一年凝成一件留在院里（年轮 / 刻字碑 / 收入书箱的经卷），次年重新起算 | 每年 1 个新物件，成本可控，天然年度仪式 |
| **L3 换维度** | 物有来历（每件陈设一段小传，随天数逐句展开）；院有四季；客有往来（朋友可"路过"留一片叶） | 小传是纯文本，零边际成本，最承载文化调性 |
| **L4 记忆** | 第 100 天它记得你哪天没来：「这三日院中落了叶，无人扫」 | 不消耗美术产能，只消耗用户自己的时间 |

**页面上已经落地的证据**（见 `屏_01禅院.png`）：面板不再写"已置 5/12 · 还差 7,388 字"，而是三行状态——苔 / 树 / 灯。用户看到的是"它现在长成什么样"，不是"我还差多少"。

### 原型玩法 → 院中物件

| 院中物件 | 承接玩法 | 货币 |
|---|---|---|
| 佛前（佛龛） | 供香烛、供佛灯、佛像瞻仰 | 灯油 IAP / 香积 |
| 许愿树 | 祈福、许愿、查看他人愿望 | 免费（限每日 1 枚新签） |
| 护生池 | 放生（改造） | 一念（功课产出）/ 可选真实捐助 |
| 石灯 | 长明灯、夜灯 | 灯油 IAP |
| 陈设斋 | 供品兑换、我的物品 | IAP + 香积 |

**放生必须改造**：西语区与北美对"放生"有明确的生态入侵与动物福利争议（放生外来物种在许多州违法）。海外版改为「护生池」——**不买卖活物、不放归野外**，池中每一尾鱼对应一次功课产出的一念，且可选 1:1 联动真实保护组织的湿地救助（凭证回执公示）。这样既保留原型的情绪内核，又把合规与舆论风险降到最低。

## 三、商业化：三条腿，不碰抽卡

| 商品 | 形式 | 定价（USD） | 说明 |
|---|---|---|---|
| 灯油 7 日 / 30 日 / 365 日 | 消耗型 | $0.99 / $2.99 / $19.99 | 30 日比 7 日省 40%，是主推档 |
| 上香 / 鲜花 / 供果 | 消耗型（香积） | 90–180 香积 | 保底体验，付费用户用香积更划算 |
| 院中陈设（石灯笼/檐铃/苔石/四季换色） | 非消耗型 | $4.99–$6.99 | 26 件，持续上新 |
| **禅心会员** | 订阅 | $4.99/月，$39.99/年（首月 $0.99） | 灯油 85 折 + 精校经藏与诵读 + 陈设先享 |
| **牌位安奉** | 年费订阅 | 单 $9.99/年，双 $14.99，三 $19.99（首年 $6.99 起） | 含长明灯、忌日提醒、家人共建、年报导出 |
| 香积币 | 消耗型 | $0.99=600 / $4.99=3,300 / $9.99=7,000 / $19.99=15,000 | 大额档多送 16% |

**为什么不做**：广告（祭怀与佛前页面出现广告直接毁掉场景）、抽卡/福袋（宗教题材 + 概率机制是审核与舆论双重雷区）、实物电商（跨境物流与售后，一阶段不碰）。

**测算口径**（请按实际留存替换，不做承诺）：海外华人约 6,000 万，泛佛教兴趣人群更大但转化低。若 MAU 5 万、会员渗透 3%、年费 $39.99 → 年收入约 $6 万；牌位安奉是最抗周期的一档（一次性决策、年费续订、天然刚需于忌日场景），若 1.5% 的 MAU 安奉 1.5 位、客单 $12 → 年约 $1.35 万。**真正的杠杆不在定价，而在牌位续订率与会员年付转化**——这两项决定这盘生意是"卖图片"还是"卖长期记忆"。

**分成**：App Store / Google Play 首年 30%；年营收 < $1M 可申请 Small Business Program，降到 15%。定价时按 15% 测算净收入更稳。

## 四、海外合规与上架（这一版必须提前做）

1. **支付**：数字商品与订阅必须走 IAP（Apple 3.1.1 / Google Payments）。牌位、灯油、陈设、会员都属于数字内容，不能引导外部支付。护生捐助若定性为慈善，可走外部通道，但需在 App 内明确合作组织、用途与凭证——**定性必须写死，否则会被判为规避 IAP**。
2. **订阅披露**（3.1.2）：价格、周期、自动续订、取消方式必须在购买页可见；`屏_09` 已写"到期前 30 天提醒，不自动扣款"，这条与 Apple 要求一致（牌位选择手动续订，反而更少投诉）。
3. **账号与数据**（5.1.1(v) / Google Data safety）：必须提供 App 内注销；注销后 30 天内彻底删除。
4. **祭怀数据是敏感数据**：逝者姓名、生卒、照片、生平、家人留言。GDPR 下逝者本身不是 data subject，但**家属账号、留言、照片仍受保护**；加州 RUFADAA 涉及数字遗产访问权。技术底线：端到端加密、家人邀请制、可见性默认"仅家人"、支持一键导出 PDF 后删除。
5. **文案红线**：不承诺"超度""保佑""消业""开光"；不出现"功德无量，付款即可"的因果表述；供灯、上香统一表述为**文化表达**，页面底部已有 disclosure（`屏_05`、`屏_02`）。祭怀定位是**纪念空间（memorial）**，不是宗教法事服务。
6. **护生**：不写"放生"，不售卖活物，不做野外放归。池内是数字对象，池外是捐助。
7. **内容**：经藏文本来源必须先定。CBETA 是 CC BY-NC-SA 4.0，**禁商用**，上线前必须换公版底本（大正藏影印 + 自校）或取得授权，否则整个付费经藏都是侵权。

## 五、与国内版的关系：一套代码，两套开关

现有工程不必分叉。`uilib` 里加一个区域开关（`BuildConfig.REGION = CN | OVERSEAS`）：

| 能力 | 国内版 | 海外版 |
|---|---|---|
| 祭怀 | 关闭 | 开启（订阅） |
| 拜佛/供灯 | 关闭 | 开启 |
| 许愿树 / 护生池 | 关闭 | 开启 |
| 禅院 | 开启（纯文化） | 开启（含养成与陈设） |
| 支付 | 无 / 内购待定 | IAP（Google Play Billing / StoreKit） |
| 语言 | 简中 | 简中 / 繁中 / EN |
| Tab | 今日·经藏·山居·物选·我的 | 禅院·经藏·祭怀·善缘·我的 |

已有实现可直接复用：`DonateFragment`（功德币/贡献）改造成香积币与 IAP 入口；祭怀相关页面（牌位、定制场景、香烛、贡品）逻辑完整，只换支付与文案；`BuddhaFestivalService` 的佛历接口两端共用。
