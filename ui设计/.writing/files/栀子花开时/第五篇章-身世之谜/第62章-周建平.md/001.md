# 第六十二章 周建平

接下来的三天，我把所有能找到的关于周建平的公开资料都翻了一遍。

周建平，男，1980年生，沧阳市人。2005年进入沧澜大学管理学院攻读工商管理博士学位，2009年毕业。博士论文题目：《转型期中国民营企业的资本运作与制度创新》。

毕业后没有进入学术界，而是接手了父亲周德明的恒远地产集团，担任副总经理。同时成立了自己的投资公司——沧恒投资——专注于文化产业和科技领域的风险投资。

2010年，与沈亦寒结婚。

公开报道里的周建平是一个标准的"创二代"——不是简单地继承父业，而是在父辈的基础上开创新的领域。他出现在各种商业论坛和慈善晚宴上，照片里的他总是穿着剪裁精良的西装，面带微笑，举止得体。

沧阳市的媒体称他为"新生代企业家的代表"。沧澜大学的校友刊物称他为"母校的骄傲"。

但方驰的话一直在我的耳边回响——"小心周建平。那个人——比苏晴说的更可怕。"

一个被媒体包装成"精英"的人，一个被校友视为"骄傲"的人——如果他的背后藏着十二年前的血腥秘密，那这个人的伪装能力就太可怕了。

我需要更多的信息。公开资料能告诉我的有限。我需要接触到那个"圈子"——那个由校董、企业家和学术界精英组成的圈子。

而我进入那个圈子的桥梁——是我父亲。

这个想法让我感到一种说不清的不安。从小的教育告诉我，法律面前人人平等，真相高于一切。但当"真相"和"父亲"被放在天平的两端时，我才发现——天平并没有我想象中那么稳固。

元旦前一天，我回了家。

出门前，林琳在宿舍楼下等我。她穿着那件灰色的卫衣，头发扎成一个马尾，脸色比前几天好了一些。

"你确定要一个人去？"她问。

"确定。这种事——人多了反而不好。"

"你打算怎么问？"

"我不知道。"我诚实地说。"走一步看一步吧。"

林琳看了我一会儿，伸出手，帮我把衣领整理了一下。"别给自己太大压力。"她说。"不管结果怎样——你不是一个人在面对。"

我点了点头，转身走了。

走在冬天的街道上，风从背后推着我。我想起小时候，我爸总是牵着我的手走在这条路上。那时候他的手很大，很温暖，我觉得只要被他牵着，世界上就没有什么可怕的。

现在——我的手比他的大了。但温暖的那一端，已经不在了。

我家在沧阳市的南城区，一个中等档次的小区。三室一厅，装修简洁。客厅里挂着我妈精心挑选的十字绣——一幅"家和万事兴"的字样，金色的线在灯光下闪闪发光。餐桌上摆着一盆假花，花瓣上落了一层薄薄的灰。一切都很普通，很温馨。

普通到让我觉得——这种普通本身就是一种奢侈。

我爸坐在沙发上看电视，我妈在厨房里忙活。锅铲碰撞的声音和电视里新闻播报的声音混在一起，有一种让人安心的烟火气。这种烟火气是我在外面——在那个充满了死亡、谎言和秘密的世界里——最怀念的东西。

"小雨回来了？"我爸从电视前转过头，脸上带着笑。"瘦了。你妈说你电话里声音不对，是不是期末考得不好？"

"考得还行。"我在沙发上坐下来。沙发垫子发出熟悉的吱呀声。"就是复习累得慌。"

"累就多吃点。你妈炖了排骨汤。"

我妈从厨房里探出头来。"小雨，洗手吃饭。"

饭桌上，我们一家三口像平常一样吃饭、聊天。我妈说邻居家的孩子结婚了，婚宴摆了四十桌，光是喜糖就花了三千块。我爸说公司最近接了个大项目，是给恒远地产的一个楼盘供应建材。

恒远地产。

周德明的公司。

我的筷子微微停了一下，但没有人注意到。

"大项目？"我装作随意地问。

"嗯。恒远那边新开了一个楼盘，在南城区边上。建材全部由我们供应。"我爸说。"老周——周德明——亲自谈的。我们是老关系了。"

老关系。

"你们——关系很好？"

"做生意嘛，讲究的就是关系。"我爸说。"周德明这个人——怎么说呢——很讲义气。跟他做生意，放心。"

我没有再追问。但"讲义气"这三个字，在我的脑子里翻了好几个跟头。一个"讲义气"的人——会不会也"讲义气"地帮别人掩盖罪行？

饭吃到一半，我放下了筷子。

"爸，"我说，"我有个事想问你。"

"什么事？"

"你在沧澜大学当校董多少年了？"

我爸看了我一眼。"怎么忽然问这个？"

"我们课上讲到大学治理结构，我想了解一下校董的具体职能。"

"哦。"我爸点了点头。"我2006年开始当的。到现在快五年了。"

2006年。

2008年方苒事件发生的时候，我父亲已经是校董了。

"校董会一般讨论什么？"

"都是些宏观的事。"我爸说。"学校的发展规划、预算审批、重大人事任命之类的。我们不管教学，不管科研，就是在大方向上把把关。"

"2008年呢？那年有什么特别的议题吗？"

我爸的筷子停了一下。

只是一下。很短的一下。如果不是我一直在观察，根本不会注意到。

"2008年？"他重复了一遍。"太久了，记不清了。怎么了？"

"没什么。就是随便问问。"

"你们这些孩子，好奇心真重。"我爸笑了笑，继续吃饭。

但我注意到了——他的笑容和之前不太一样。之前的笑是放松的、自然的笑。现在的笑——多了一层什么东西。像是刻意加上去的。

"爸，你认识周德明吗？"

这一次，筷子停的时间更长了。

"恒远地产的周德明？"

"对。他也是校董。"

"认识。校董会上经常见面。"我爸的语气很平淡。"怎么了？"

"他的儿子周建平——你认识吗？"

"周建平？"我爸想了想。"好像听说过。是不是那个——在沧澜大学读过博士的？"

"对。"

"不太熟。"我爸说。"你怎么忽然问起这些人？"

"没什么。一个同学提到这个名字，我觉得耳熟。"

"哦。"我爸点了点头。"吃饭吧。排骨汤凉了就不好喝了。"

饭桌上恢复了正常的氛围。我妈给我夹了一块排骨，说"多吃点，看你瘦的"。我爸继续讲他那个大项目的细节。

但我心里已经有了答案。

我父亲——他知道一些事情。

他提到2008年时的犹豫，他听到周德明名字时筷子的停顿，他说到周建平时刻意表现出的陌生——这些都是信号。

一个无辜的人，在听到不熟悉的名字时，不会有这种反应。

只有知道些什么、但不愿意说出来的人，才会有这种微妙的、下意识的回避。

吃完饭，我在客厅里坐了一会儿。我爸回到沙发上看新闻，我妈在厨房里洗碗。

"爸。"

"嗯？"

"沧澜大学——这些年有没有出过什么事？"

我爸转过头看着我。他的眼神里有一种我从未见过的东西——不是愤怒，不是恐惧，而是一种复杂的、像是在衡量什么的表情。

"什么事？"

"比如——学生的安全事件。或者——意外。"

沉默。

电视里新闻播报的声音在客厅里回荡。

"小雨，"我爸终于开口，"你在学校——是不是遇到了什么事？"

"没有。就是随便问问。"

"随便问问？"我爸看着我，目光变得锐利。"你从小就不会'随便问问'。你要问什么，就直接问。"

我看着他。

"爸，2008年——真的什么都没发生过吗？"

沉默。

很长的沉默。

然后我爸叹了口气。

"小雨，"他说，"有些事情——不是你应该管的。"

"什么意思？"

"意思是——"他停顿了一下，"你好好读书，好好考试。毕业了找份好工作。别的事——不要管。"

"爸——"

"我说不要管。"他的声音忽然变得严厉。这是我从小到大第一次听到他用这种语气跟我说话。

我妈从厨房里走了出来。"怎么了？你们爷俩吵什么？"

"没什么。"我爸恢复了平静的语气。"小雨问学校的事，我跟他说了几句。"

我妈看了看我，又看了看我爸，没有追问。但她走过来，在我旁边坐下，轻轻拍了拍我的肩膀。

"小雨，你爸说得对。好好读书。别的事——别操心。"

她的语气很温柔，但我听出了底下的紧张。

她也知道。

我爸妈——他们都知道一些事情。

他们选择了沉默。

那天晚上，我睡在自己小时候的房间里。墙上还贴着我高中时的课程表，书桌上摆着我用过的课本和笔记本。一切都没有变。但我变了。

我躺在床上，盯着天花板。

天花板上有一道细小的裂缝，从灯座一直延伸到墙角。我小时候就注意到了这道裂缝，每次躺在床上都会看它。那时候我觉得它像一条河流，从源头流向远方。

现在我觉得它更像一条伤疤——一道被时间掩盖但没有真正愈合的伤疤。

我父亲知道。

我母亲也知道。

他们选择了沉默。

而沉默——在某种意义上——就是共谋。

但我不想指控他们。我不想把他们推向法律的审判。我只想知道——他们知道的到底是什么。

2008年，沧澜大学发生了什么？

方苒死了。苏晴离开了。陈向晚失踪了。

校董们在做什么？

我父亲——他在做什么？

我翻了个身，闭上眼睛。

脑子里的画面一个接一个地闪过：方苒日记里的文字，苏晴办公室里的眼泪，林琳站在警车旁无声哭泣的侧脸，方驰消失在冬青树阴影里的背影。

还有——周建平。

那个名字像一块磁铁，吸引着所有的线索向它聚拢。

周建平。2005级博士生。赵德厚的学生。周德明的儿子。沧恒投资的法定代表人。沈亦寒的丈夫。

如果方驰的推测是对的——如果周建平就是那个"好心的学长"——那他在这十二年里，从一个"创二代"变成了沧阳市的明星企业家。他的财富、他的地位、他的影响力——全都建立在一个血腥的秘密之上。

而那个秘密——就是方苒的死。

我忽然想起了一个细节。

今天吃饭的时候，我爸说周德明"讲义气"。一个"讲义气"的人——如果他的儿子犯了罪，他会怎么做？是送儿子去自首，还是动用一切资源来掩盖？

答案不言而喻。

如果周德明知道儿子的所作所为——而他几乎不可能不知道——那他就不仅仅是"沉默的旁观者"。他是帮凶。是共犯。是那张网的另一个核心节点。

而我父亲——作为周德明的生意伙伴和校董会同僚——他知道多少？他看到了多少？他选择了沉默——但这种沉默，是出于无知，还是出于恐惧，还是出于利益？

我不敢想下去。

因为每一个答案，都指向一个我不愿意面对的可能——我的父亲，可能不是一个无辜的人。

窗外传来一阵风声。树枝敲打着窗框，发出细碎的声响。

我想起小时候，有一次我犯了错——具体是什么错已经记不清了——我爸把我叫到面前，我以为他会打我。但他没有。他只是蹲下来，看着我的眼睛，说了一句话："小雨，做人最重要的事就是——做对的的事。即使很难。即使很痛。"

做对的的事。

即使很难。即使很痛。

爸，你现在还记得这句话吗？

我睁开眼睛，看着天花板上的那道裂缝。

明天——我要回学校。

明天——我要开始接近周建平。

明天——我要弄清楚，那个被媒体称为"新生代企业家代表"的人，到底是不是十二年前那个伤害了一个十八岁女孩的恶魔。

窗外的夜色很深。远处的路灯在黑暗中发出微弱的光。小区里有一只流浪猫在叫，声音凄厉而孤独，像是在为某个逝去的人哭泣。

我闭上眼睛，强迫自己入睡。

但我知道——这一夜，我不会做梦。

因为真相——比任何噩梦都更可怕。
