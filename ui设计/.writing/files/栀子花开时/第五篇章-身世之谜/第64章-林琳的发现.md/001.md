# 第六十四章 林琳的发现

从联谊会回来之后，我把见到沈亦寒的经过告诉了林琳。

她听得很认真。当我提到沈亦寒说"小心"的时候，她的眉头皱了起来。

"她和苏晴说了一样的话。"林琳说。

"对。"

"这说明——她们知道同样的事情。"

"或者——她们在害怕同样的东西。"

林琳沉默了一会儿。

"张小雨，"她忽然说，"苏晴被捕的时候，她的办公室——"

"怎么了？"

"她的办公室里有很多东西。电脑、文件、书——警方只带走了和案件直接相关的证据。但苏晴的私人物品——那些和案件无关的东西——应该还在办公室里。"

"你想去翻她的东西？"

"不是翻。"林琳说。"是找。苏晴给我留了东西——我能感觉到。"

"你怎么知道？"

"因为她是我的母亲。"林琳的声音很平静。"她做了那么多事——杀王建国，调查真相，保护证据——她不会没有给自己留后路。她被捕的时候很平静，像是早就准备好了。一个准备好了的人——会把最重要的东西放在一个安全的地方。"

"比如？"

"比如她的办公室。"

第二天下午，我和林琳去了银座大厦。

苏晴的公司还在运转——虽然法定代表人被捕了，但公司有完善的管理体系，日常运营不受太大影响。前台的女孩看到我们，表情有些复杂。

"你们是——沈总的——"

"她的朋友。"林琳说。"我们来拿一些她的私人物品。"

前台犹豫了一下，打了电话给公司的副总经理。副总经理是一个四十多岁的男人，戴着眼镜，看起来很疲惫。他下来见了我们，确认了林琳的身份后，同意让我们去苏晴的办公室。

"但请不要动公司的文件和电脑。"他说。"那些涉及公司运营。"

"我们只拿她的私人物品。"林琳说。

我们上了十六楼，走进苏晴的办公室。

办公室已经被整理过了。桌上的文件被收进了抽屉里，电脑被贴上了封条。但书架上的书还在，沙发上的靠垫还在，落地窗前的那盆绿萝还在。

一切都在，但一切都不一样了。

因为那个坐在这里的人——不在了。

林琳站在办公室的中央，环顾四周。她的表情很平静，但我能看出她的手在微微发抖。

"从哪里开始？"我问。

"书架。"林琳说。"苏晴——她喜欢把重要的东西藏在书里。"

"你怎么知道？"

"因为方苒的日记就藏在《唐诗三百首》里。"林琳走到书架前，开始一本一本地查看。

我也加入了。我们仔细地翻看每一本书——抖一抖，翻一翻，看看有没有夹着什么东西。

大部分书都是普通的商业和管理类书籍。有几本文学类的——《红楼梦》《围城》《平凡的世界》。还有一本——

《唐诗三百首》。

"这本——"林琳把书抽出来。"上次苏晴就是从这本书里拿出方苒的日记的。"

我接过来翻了翻。日记已经被警方作为证据带走了。但书的厚度——似乎有些不对。

"林琳，你来看看。"

林琳走过来。她接过书，掂了掂。

"比正常的厚。"她说。

她翻开书，从最后一页的夹层里——摸到了一个小小的东西。

一个U盘。

黑色的，很小的，和方驰给我的那个差不多大。

"找到了。"林琳说。

她看着那个U盘，手指轻轻摩挲着它的表面。

"她留给我的。"林琳轻声说。"她知道——总有一天我会来这里找。"

我们回到学校，在宿舍里把U盘插进了电脑。

弹出了一个密码输入框。

"加密的。"我说。

林琳看着那个密码框，沉默了一会儿。

"密码——"她喃喃道。"她会用什么做密码？"

"试试看你的生日？"

"她不知道我的生日。她在我出生后就离开了。"

"那——方苒的生日？"

林琳看了我一眼。然后她从口袋里掏出一个小本子——那是她记录调查线索的笔记本。她翻到某一页，找到了方苒的资料。

"方苒，1990年6月8日生。"

她在密码框里输入了"19900608"。

密码错误。

"试试'0608'。"

密码错误。

"试试'900608'。"

密码错误。

林琳靠在椅背上，皱着眉头。

"方苒的生日——她还会用什么形式？"

"想想苏晴和方苒的关系。"我说。"她们是最好的朋友。方苒的生日——苏晴不可能不知道。但密码的形式——"

"栀子花。"林琳忽然说。

"什么？"

"方苒最喜欢栀子花。栀子花的花语是——'永恒的爱与约定'。方苒的生日是6月8日——栀子花盛开的季节。"

"所以？"

"苏晴可能会用一种和栀子花有关的方式来记录方苒的生日。"林琳想了想。"栀子——zhizi——ZZ？"

她在密码框里输入了"ZZ0608"。

密码错误。

"或者——'栀子花开'的拼音首字母？"

"ZHKH？"

林琳输入了"ZHKH0608"。

屏幕闪了一下。

文件夹弹了出来。

"开了。"林琳的声音有些发颤。

我凑过去看。

U盘里有大量的文件。按类型分成了几个文件夹：

1. "方苒事件"
2. "录音"
3. "关系网"
4. "给林琳"

林琳的目光落在了第四个文件夹上。

"给林琳"。

她伸出手，鼠标悬停在那个文件夹上方，但没有点开。

"先看其他的。"她说。声音很平静，但我能听出那种平静下面的颤抖。

我们先打开了第一个文件夹——"方苒事件"。

里面有大量的文档：方苒日记的扫描件（比苏晴给我们看的更完整，包含了被撕掉的那几页的复印件）、当年校医院的检查记录、苏晴转学前的心理咨询记录、陈向晚失踪后警方的一些内部通报（不知道苏晴是怎么拿到的）。

最让我震惊的是——被撕掉的那几页日记的复印件。

"12月5日。他今天又来了。在图书馆等我。他说有话要跟我说。我去了。他——他带我去了一个地方。一个校外的公寓。他说那是他朋友的房子，没有人。我——"

后面的字迹变得极其潦草。

"12月6日。我去了医院。医生说——一切都还在。我不知道该怎么办。苏晴不在。我不敢告诉她。"

"12月8日。赵德厚来找我了。他说他知道了一切。他说——如果我告诉任何人，我不仅会被开除，我的家人也会受到牵连。他说——这是'年轻人之间的事'，不值得闹大。"

"赵德厚——他不仅掩盖了真相，他还威胁了方苒。"

我继续翻。

"12月15日。我写了一封信。这次不是投校长信箱。我要直接去找校董。校董里有一个——张——"

到这里，字迹就断了。

这一页的下面——是空白的。

方苒没有写完那个名字。

"张——"

张建国？

我的父亲？

我的手开始发凉。

"张小雨——"林琳看着我。

"我不知道。"我说。声音干涩得像是从石头里挤出来的。"我不知道她写的是不是我父亲。"

"但你在想——"

"我在想。"

林琳没有追问。她转回屏幕，继续看文件。

第二个文件夹——"录音"。

里面有十几个音频文件，文件名是日期。我随机打开了一个。

录音质量不太好，有明显的背景噪音。但两个人的对话还是能听清楚。

男声A："……事情已经处理了。那个女生不会再说出去。"

男声B："你确定？"

男声A："放心。王建国做事很干净。监控已经删了，门禁记录也改了。没有人会知道。"

男声B："赵老师，我——"

男声A："你什么都不用做。你只需要记住一件事——你现在的位置，你的前途，你的一切——都取决于你能不能守住这个秘密。"

录音到此结束。

"赵老师——赵德厚。"我说。"另一个男声——可能是王建国，也可能是——"

"也可能是那个学长。"林琳说。

我看了看录音的日期——2008年12月20日。方苒死后不到一周。

"苏晴是怎么录到这段对话的？"

"我不知道。但她一定在某个地方放了录音设备。"

我继续翻。第三个文件夹——"关系网"。

里面只有一张图片。

我点开它。

那是一张手绘的关系网图。画在一张白色的纸上，用不同颜色的笔标注了不同的人物和关系。

图的最上方写着："方苒事件——关系网"

图的中心——是一个用红色笔圈起来的名字。

我盯着那个名字，感觉心脏被什么东西紧紧攥住了。

周建平。

名字旁边用红色笔标注了四个字："一切的开始。"

从"周建平"这个名字出发，有无数条线向四周延伸：

——指向"赵德厚"，标注："导师/帮凶/掩盖真相"
——指向"王建国"，标注："执行者/清理现场"
——指向"王国强"，标注："后勤/监控门禁"
——指向"马玉芬"，标注："宿管/默许配合"
——指向"方苒"，标注："受害者/死亡"
——指向"苏晴"，标注："目击者/被迫沉默"
——指向"陈向晚"，标注："第二受害者/失踪"
——指向"周德明"，标注："父亲/资源提供者"
——指向"张建国"，标注："校董/知情者？"

在"张建国"的名字旁边，有一个问号。

苏晴不确定。

但在"周建平"的名字旁边——没有问号。

苏晴确定。

她确定周建平就是一切的开始。

我的手在发抖。

林琳的手也在发抖。

我们坐在那里，盯着屏幕上那张关系网图，感觉整个世界都在旋转。

"张小雨，"林琳终于开口，"你的父亲——在这张图上。"

"我知道。"

"他旁边有一个问号。"

"我知道。"

"但周建平——没有问号。"

"我知道。"

林琳转过头看着我。她的眼睛里有一种我从未见过的光——不是恐惧，不是愤怒，而是一种冰冷的、锋利的决心。

"张小雨，"她说，"周建平——就是那个'好心的学长'。"

"我知道。"

"他就是害了方苒的人。"

"我知道。"

"他就是——"

"我知道。"

我看着她。

"但现在——我们还不够。"

"不够？"

"关系网图只是苏晴的推测。我们需要更多的证据。直接的、无法否认的证据。"

林琳沉默了。

然后她看向第四个文件夹。

"给林琳"。

她伸出手，点开了那个文件夹。

里面只有一个文件。一个文本文件。文件名是："女儿"。

林琳点开了它。

文件里只有一段话：

"林琳，如果你看到了这个文件，说明你已经找到了这里。你是我的女儿。我把你送到别人手里，是我这辈子做的最难的决定。但也是唯一正确的决定。因为——我不能让你跟着我。我的路太危险了。你不一样。你应该有一个干净的人生。你应该活得比我好。比我勇敢。比我自由。不要恨我。但要记住——我爱你。从你出生的那一刻起，到现在，到永远。——妈妈"

林琳看着屏幕上的文字，一动不动。

然后她伸出手，轻轻地摸了摸屏幕。

像是在摸一个人的脸。

"妈妈。"她轻声说。

只有两个字。

但这两个字里，有十八年的等待，有十八年的疑问，有十八年的渴望。

眼泪终于落了下来。

一滴，两滴，三滴。

落在键盘上，落在桌面上，落在这个冬天的午后。

我坐在她旁边，没有说话。

因为在这个时刻——任何语言都是多余的。

窗外的阳光透过玻璃照进来，照在林琳的脸上，照在屏幕上的文字上。

那些文字在阳光里闪着微弱的光。

像是一个母亲穿越十二年的时光，对她从未拥抱过的女儿说的最后一句话。

"我爱你。"
