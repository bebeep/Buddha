# 第五十八章 陈向晚呢

第二天，我又去了苏晴的公司。

不是她约我的，是我自己去的。因为昨晚她最后说的那句话——"有一个人，后来成了赵德厚的学生"——像一根刺扎在我的脑子里，拔不出来。

我需要更多的信息。

但这一次，苏晴没有让我进办公室。

前台的女孩面带歉意地告诉我："沈总说今天不见客。"

"我不是客。"我说。"你告诉她，张小雨来了。"

女孩进去通报，很快回来了。

"沈总说——请您改天再来。"

我站在大厅里，看着电梯的方向。然后我掏出手机，给苏晴发了一条短信：

"王国强和陈向晚呢？"

三分钟后，回复来了："上来吧。"

我再次上了十六楼。这一次，苏晴在办公室里等我。她坐在办公桌后面，脸上的表情比昨天更冷了一些。

"你问了不该问的问题。"她说。

"什么问题？"

"你知道的。"

我在她对面坐下来。

"苏晴，王国强是第一个死的。他的死一直让我困惑。如果王建国是你杀的，赵德厚是别人杀的，那王国强呢？也是你杀的吗？"

苏晴摇头。

"王国强不是我杀的。"

"你确定？"

"我确定。"她说。"我回到沧阳市之后，只杀了王建国一个人。王国强——我甚至没有去找过他。"

"那他是谁杀的？"

"我不知道。但我知道王国强在方苒事件中扮演了什么角色。"

"什么角色？"

"王国强是当时的后勤处副处长。"苏晴说。"方苒出事的那栋宿舍楼——旧三号楼——是后勤处管理的。王国强负责那栋楼的监控和门禁。"

"你的意思是——"

"方苒出事的那天晚上，旧三号楼的监控恰好'故障'了。"苏晴说。"门禁记录也'丢失'了。这些'故障'和'丢失'，都是王国强安排的。"

"他帮那个人清除了证据。"

"对。和赵德厚一样，他也是帮凶。"

"所以有人替方苒报了仇。"

苏晴没有说话。

"苏晴，陈向晚呢？"

她的眼神闪了一下。

"陈向晚——"

"陈向晚是2009年失踪的。她是沧澜大学的学生，也是文学社的成员。她失踪之后再也没有出现过。警方定性为'离家出走'，但她的家人一直不信。"

"你怎么知道这些？"

"我在调查王建国的时候查到的。"我说。"陈向晚失踪的时间和方苒去世的时间相隔不到一年。她也是文学社的成员。我有一种感觉——她的失踪和方苒的死有关联。"

苏晴沉默了很久。

"陈向晚……"她终于开口，声音变得很低。"我有责任。但不是直接动手的人。"

"什么意思？"

苏晴站起来，走到窗前。她的背影在落地窗的映衬下显得格外单薄。

"陈向晚是方苒之后第二个被那个人伤害的女孩。"她说。"2009年初，也就是方苒去世几个月之后。"

"你怎么知道？"

"因为陈向晚找到了我。"

"找到你？你那时候不是已经转学了吗？"

"转学之后，我和陈向晚通过QQ联系过。"苏晴说。"她是方苒在文学社的学妹。方苒死后，她一直很害怕。她说她发现了一些方苒日记里的东西——关于那个学长的。她想弄清楚真相。"

"然后呢？"

"然后她也被盯上了。"苏晴的声音变得苦涩。"那个人发现陈向晚在调查方苒的事，就开始接近她。和对方苒一样——关心她，帮助她，给她希望。陈向晚比方苒更年轻，更天真，更容易被骗。"

"你为什么不阻止？"

"我阻止了。"苏晴转过身，看着我。"我告诉陈向晚离那个人远一点。我告诉她方苒发生过什么。我让她小心。"

"但她没有听？"

"她听了。但太晚了。"苏晴的声音低了下去。"陈向晚告诉我，那个人对她做了一些事。不是像方苒那样——她没有被侵犯。但那个人威胁她，说如果她把事情说出去，她和她家人都不会好过。"

"陈向晚害怕了。她想要离开沧澜大学，但她家里不富裕，退学意味着前功尽弃。她陷入了两难。"

"然后有一天，她告诉我——她决定不走了。她说她要留下来，收集证据，把那个人绳之以法。"

"她做到了？"

"没有。"苏晴的声音变得很轻。"2009年5月的一个晚上，陈向晚给我发了一条QQ消息。只有四个字——'他们知道了'。"

"然后？"

"然后她就消失了。"

"QQ号再也没有上线。手机关机。宿舍的人说她那天晚上出去之后就再也没回来。她的东西还在宿舍里——衣服、书、笔记本——但人不见了。"

"警方怎么说？"

"警方说是'离家出走'。"苏晴苦笑了一下。"她的父母从乡下来到学校，在校门口哭了一整天。他们说他们的女儿不会无缘无故失踪，一定是出了什么事。但警方没有找到任何线索。"

"你相信她是'离家出走'吗？"

"不信。"苏晴说。"陈向晚不是那种会不告而别的人。她有责任心，有家人，有未完成的学业。她不会就这样消失。"

"那你觉得她怎么了？"

苏晴看着我，目光里有一种深沉的悲伤。

"我觉得——她可能被'处理'了。"

"'处理'？"

"就像王建国说的——'处理'。"苏晴的声音冰冷。"方苒死了，陈向晚在调查她的死因。那个人不会允许一个知道太多的人活着。所以——"

她没有说下去。

"你觉得陈向晚被杀了？"

"我不确定。但我有责任。"

"什么责任？"

"如果当初我更强硬地劝她离开，如果我没有告诉她那些信息——如果她没有因为调查方苒的事而被那个人盯上——也许她不会失踪。"

苏晴的声音里有一种深沉的自责。

"张小雨，你知道最痛苦的是什么吗？不是你自己犯了错，而是你明知道危险在那里，却没有能力保护你想保护的人。"

我沉默了。

"苏晴，你说你'有责任但不是直接动手的人'。你的意思是——"

"我的意思是，陈向晚的失踪可能与我有关，但不是我的手。"苏晴说。"我没有伤害她。但我提供了信息，激发了她的勇气，也把她推向了危险。这是我的责任。"

"你觉得谁有能力'处理'陈向晚？"

"王建国。或者赵德厚。或者——"

"或者那个'好心的学长'。"

苏晴点了点头。

"他们三个——那个学长、赵德厚、王建国——是一个铁三角。学长负责'接近'目标，赵德厚负责'善后'，王建国负责'清理'。陈向晚发现了他们的秘密，他们不会放过她。"

"但王国强呢？"我问。"王国强也是铁三角的一部分吗？"

"王国强是外围。"苏晴说。"他负责后勤保障——监控、门禁、信息封锁。他不是核心成员，但他知道核心秘密。"

"所以四个死者——王国强、王建国、马玉芬、赵德厚——都和方苒事件有关。"

"对。"

"马玉芬呢？她扮演了什么角色？"

苏晴犹豫了一下。

"马玉芬是当时的宿舍管理员。"她说。"旧三号楼的宿管。方苒出事的那天晚上，是马玉芬'没有发现'异常。"

"她是故意的？"

"不确定。但马玉芬和赵德厚关系很好。赵德厚是中文系的教授，经常带学生到宿舍楼讨论课题。马玉芬帮他安排场地，他给马玉芬一些'好处'。"

"什么好处？"

"钱。或者更准确地说——赵德厚的课题组有一些'灵活经费'，其中一部分流向了马玉芬。"

"所以马玉芬也是被收买的。"

"至少是默许。"苏晴说。"方苒出事的那个晚上，马玉芬'恰好'不在值班室。监控'恰好'故障。门禁记录'恰好'丢失。这些'恰好'加在一起，就不是巧合了。"

我靠在椅子上，感觉脑子里的信息像一幅拼图，正在一块一块地拼合。

四个死者：王国强（后勤副处长，负责清除监控证据）、王建国（帮凶，负责"处理"现场）、马玉芬（宿管，默许或配合了当晚的安排）、赵德厚（核心帮凶，掩盖真相，截获求救信）。

他们都被杀了。

苏晴杀了王建国。

赵德厚是别人杀的。

王国强和马玉芬——是谁？

"苏晴，"我说，"你说过，杀赵德厚的人可能是一个'比我们都更早开始复仇的人'。那个人——会不会也杀了王国强和马玉芬？"

"有可能。"苏晴说。"但我不知道那个人是谁。"

"你能给我一些线索吗？"

苏晴想了想。

"有一件事。"她说。"王国强死的时候，现场留下了一些东西。警方没有公开，但我通过一些渠道知道了。"

"什么东西？"

"一朵栀子花。"

我的脊背一阵发凉。

"栀子花？"

"对。放在王国强的尸体旁边。和赵德厚现场留下的'四个'一样——这是一个签名。"

"同一个人在杀王国强和赵德厚？"

"很可能。"

"那马玉芬呢？"

"马玉芬的现场——"苏晴停了一下。"马玉芬的现场也有一样东西。一根白色的丝带。"

"丝带？"

"方苒最喜欢的东西。"苏晴的声音变得很轻。"方苒有一根白色的丝带，她总是系在头发上。她死的那天晚上，那根丝带断在了宿舍楼的楼梯上。"

"所以——杀王国强、马玉芬和赵德厚的人，用的是方苒的'符号'。栀子花、丝带、'四个'——这些都是方苒的故事里的元素。"

"对。"

"这意味着——杀人的人在用方苒的名义复仇。"

"或者说，"苏晴纠正我，"杀人的人认为自己是在替方苒讨公道。"

我沉默了。

"苏晴，最后问你一件事。"

"问。"

"陈向晚——你觉得她还活着吗？"

苏晴沉默了很久。

"我不知道。"她终于说。"但说实话——我不抱希望。"

她抬起头，看着我。

"张小雨，如果你要查下去，陈向晚的失踪是一个重要的线索。找到陈向晚——或者找到陈向晚失踪的真相——也许就能找到那个杀人的人。"

"为什么？"

"因为陈向晚是最后一个被那个人伤害的女孩。如果她还活着，她手里可能有我们需要的证据。如果她死了——"

苏晴的声音断了。

"如果她死了，那她的死就是压垮骆驼的最后一根稻草。是她的死——或者她的失踪——让某个人彻底崩溃，走上了复仇的路。"

我站起来。

"苏晴，谢谢你。"

"不用谢。"她说。"走吧。我说的已经够多了。"

我走到门口，停了一下。

"苏晴，你说你在保护谁。你不肯说出那个'好心的学长'的名字。但你今天告诉了我陈向晚的事，告诉了我铁三角的事，告诉了我杀人者的'签名'。你在给我线索——你在帮我查。"

"那为什么你还是不肯说那个名字？"

苏晴看着我，目光里有一种我从未见过的复杂情绪。

"因为那个名字——"她轻声说，"是最后一张牌。我不能太早打出去。"

"为什么？"

"因为一旦那张牌被打出去，就没有回头路了。"

她的目光越过我的肩膀，看向窗外的城市。暮色已经完全降临了，城市的灯光像一片沉默的星海。

"张小雨，"她说，"你回去想想——那个名字可能是什么。你自己去猜。猜到了，你就明白我为什么不说了。"

我看着她，看了很久。

然后我点了点头，转身走出了办公室。

走廊里很安静。我的脚步声在大理石地面上回响，一下一下，像心跳。

走到电梯口的时候，我停下来，回头看了一眼。

苏晴的办公室门关着。门缝里的灯光还亮着。

她还坐在那里。

一个人。

面对着窗外的万家灯火，独自守着那个她不肯说出口的名字。

那个名字——

我走进电梯，按下一楼。

在电梯下降的那几秒钟里，我的脑子里闪过一个念头。

一个让我几乎站不住脚的念头。
