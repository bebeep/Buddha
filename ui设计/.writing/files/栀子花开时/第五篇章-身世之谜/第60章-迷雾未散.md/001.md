# 第六十章 迷雾未散

苏晴被捕后的第三天，方驰联系了我。

不是通过短信，不是通过邮件，而是直接出现在了我的面前。

那天晚上，我从图书馆回宿舍。走到宿舍楼下的小路时，一个人从梧桐树的阴影里走了出来。

"张小雨。"

我停下脚步。

方驰站在我面前。

他瘦了很多。脸颊凹陷下去，颧骨突出，下巴上长了一层乱糟糟的胡茬。他穿着一件深色的棉衣，衣角有些脏，头发也乱蓬蓬的，像是好几天没有洗过。

但他的眼睛还是亮的。锐利的、警觉的、像一只受伤的狼。

"方驰。"我说。

"别叫那么大声。"他低声说。"我们找个安静的地方。"

我们走到宿舍楼后面的小花园里。这里有一排冬青树，冬天也不落叶，形成了一道天然的屏障。花园里有一张石桌和两个石凳，平时很少有人来。

方驰在石凳上坐下来，双手插在棉衣的口袋里。

"你看起来也不怎么样。"他说。

"你也是。"

他苦笑了一下。"逃亡的日子不好过。"

"方驰，赵德厚——"

"不是我杀的。"他打断我。"我说过。"

"我相信你。但警方不一定相信。"

"警方爱信不信。"方驰说。"我来找你不是为了说这个。我来找你，是因为——苏晴被捕了。"

"你怎么知道？"

"我当然知道。我一直在看着。"他看着我。"匿名举报信是我写的。"

"为什么？"

"因为苏晴——她该面对法律的审判。"方驰说。"她杀了王建国，这是事实。不管她的动机是什么，不管王建国做了什么——杀人就是杀人。法律不应该有例外。"

"你之前不是想替方苒报仇吗？"

"我是想报仇。我杀了王建国，这个我认。"方驰的声音变得低沉。"但报仇和包庇是两回事。苏晴是我的——她在某种意义上是我的恩人。当年方苒死后，是苏晴帮我联系了外面的资源，让我能继续上学。我不能看着她一直逃下去。"

"所以你举报了她。"

"对。她该面对法律。但——"

他停了一下。

"但其他人不该逃脱。"

"其他人？"

方驰看着我，目光变得锐利。

"张小雨，你听好了。我虽然恨所有与方苒之死有关的人，但我只杀了王建国一个人。其他人不是我杀的。"

"我知道。王国强、马玉芬、赵德厚——不是你和苏晴杀的。"

"对。"方驰说。"但我知道谁有能力做这一切。"

"谁？"

方驰沉默了一会儿。他抬起头，看着冬青树上方灰蒙蒙的天空。

"你查了苏晴的公司注册信息？"他问。

"查了。"

"你查了她的资金来源？"

"没有。我只查了工商信息。"

"那就是你遗漏的地方。"方驰说。"苏晴的公司——晴远商贸——500万的注册资本不是她自己的钱。她刚毕业不到一年，不可能有那么多钱。"

"那钱从哪里来？"

"这是关键。"方驰说。"我查了很久。那笔钱是通过三层壳公司转过来的。最终来源——是一家叫'沧恒投资'的公司。"

"沧恒投资？"

"对。沧恒投资的法定代表人叫周建平。"

周建平。

这个名字在我的脑子里闪了一下。

"周建平是谁？"

"这就是你要查的。"方驰说。"但我可以告诉你一些我已经查到的东西。"

他从口袋里掏出一个U盘，递给我。

"这里面有我的调查资料。包括沧恒投资的工商信息、资金流向、以及——"

他停顿了一下。

"以及周建平和苏晴之间的关系。"

我接过U盘。它很小，黑色的，握在手心里几乎感觉不到重量。但它里面的信息——可能比我所知道的一切都更重要。

"方驰，你为什么把这些给我？"

"因为我查不下去了。"方驰说。"我在逃亡。我不能去任何有监控的地方，不能上网，不能用真实的身份。我能做的已经做了。剩下的——要靠你了。"

"你为什么不交给警方？"

"警方？"方驰冷笑了一声。"张小雨，你觉得警方能查到这里吗？这个案子已经超出了普通刑事案件的范畴。这里面涉及的人——他们的关系、他们的资源、他们的影响力——不是几个刑警能撼动的。"

"那你觉得谁能？"

"你。"方驰看着我。"你是法学学生。你懂法律。你聪明，执着，而且——你有一个别人没有的优势。"

"什么优势？"

"你父亲。"

我的心猛地一沉。

"你父亲张建国是沧澜大学的校董。"方驰说。"如果周建平也在沧澜大学的权力网络里——你父亲就是你能接触到那个网络的桥梁。"

"你在暗示我父亲和这件事有关？"

"我没有暗示任何事。"方驰说。"但你应该去问你父亲——2008年，沧澜大学发生了什么。方苒的死，苏晴的离开，陈向晚的失踪——这些事件发生的时候，校董们在做什么。"

我沉默了。

"方驰，还有一件事。"我说。"苏晴不肯说出那个'好心的学长'的名字。她说那是'最后一张牌'。你知道那个人是谁吗？"

方驰的表情变了。

不是惊讶，也不是恐惧。而是一种更复杂的、像是在权衡什么的表情。

"我知道一些。"他终于说。"但我不确定。我需要更多的证据。"

"你能给我一些方向吗？"

方驰想了想。

"还有一件事。"他说。"我在监视苏晴的过程中，发现苏晴曾与一个人有过秘密接触。那人不是赵德厚也不是王国强，而是另有其人。"

"谁？"

"我跟踪过那人一次。"方驰说。"看到那人进了一栋高档别墅。那栋别墅的主人是——周建平的妻子，沈亦寒。"

沈亦寒。

又一个名字。

"沈亦寒是谁？"

"赵德厚的得意门生。"方驰说。"2009年毕业于沧澜大学中文系，硕士论文是赵德厚指导的。毕业后进入了一家文化公司，后来——嫁给了周建平。"

"赵德厚的学生嫁给了周建平？"

"对。"方驰说。"你不觉得这很奇怪吗？赵德厚是方苒事件的核心帮凶。他的学生嫁给了那个'好心的学长'——或者说，嫁给了那个'好心的学长'身边的人。"

"你觉得沈亦寒知道方苒的事？"

"我不知道。但这种关联——不能忽视。"

方驰把棉衣的拉链拉到最上面，裹紧了衣服。

"张小雨，我要走了。"

"去哪里？"

"不知道。先离开沧阳市。"他说。"警方在找我。我不能在这里待太久。"

"你——不打算自首？"

"不是现在。"方驰说。"等所有的真相都揭开之后，我会去。但不是现在。因为我还有事要做。"

"什么事？"

"找陈向晚。"

"陈向晚？你觉得她还活着？"

"我不知道。但我要找到答案。"方驰说。"如果她活着，她就是最重要的证人。如果她死了——她的死因就是指控那个人的最后一块拼图。"

他转身要走。

"方驰。"我叫住他。

"嗯？"

"你——保重。"

他回头看了我一眼。在路灯昏暗的光线下，他的脸上有一种说不清的表情——像是疲惫，又像是释然。

"你也是。"他说。"张小雨，小心周建平。那个人——比苏晴说的更可怕。"

然后他转身，走进了冬青树后面的阴影里。

我站在原地，看着他的背影消失在夜色中。

风从树梢间穿过，发出细碎的沙沙声。

我低头看着手里的U盘。它很小，很轻，几乎感觉不到重量。

但我知道，它里面的东西——可能改变一切。

我回到宿舍，把U盘插进电脑。

室友们都不在——李浩然去自习了，王建去了网吧，陈磊回家了。宿舍里只有我一个人，安静得能听到暖气管道里水流的声音。

文件夹弹了出来。里面有十几个文件，按日期排列。我点开最早的一个——

标题是："沧恒投资——股权穿透图"

下面是一行行密密麻麻的数据：公司名称、注册资本、股东信息、变更记录。方驰的调查做得很细致——每一层股权结构都标注了日期和金额，像是一张精密的蛛网。

我顺着数据往下查。

沧恒投资。法定代表人：周建平。注册资本：5000万。成立日期：2007年。

2007年。

周建平在2007年成立了一家投资公司。那时候他应该在读博士——2005年入学，2009年毕业。

一个在读博士，注册了一家5000万资本的公司。

钱从哪里来？一个二十七八岁的年轻人，就算他有再强的商业头脑，也不可能在读博期间攒够5000万。这笔钱——一定来自别处。

我继续往下看。资金流向图显示，沧恒投资的初始资金来自另一家公司——"恒远地产"。恒远地产的法定代表人是一个叫周德明的人。

周德明。

和周建平同姓。

父亲？

我打开浏览器，搜索"周德明 沧阳"。

搜索结果的第一条：

"周德明，沧阳市恒远地产集团董事长，沧阳市工商联副会长，沧澜大学校董。"

校董。

又是校董。

我父亲也是校董。

周德明是校董，我父亲也是校董。

周建平是周德明的儿子。

我的心跳加速了。我继续翻看U盘里的其他文件。

第二个文件是一份资金流向分析报告。方驰用图表展示了从恒远地产到沧恒投资、再到晴远商贸（苏晴的公司）的资金链条。

恒远地产 → 三层壳公司 → 沧恒投资 → 两层壳公司 → 晴远商贸

苏晴的500万注册资本——最终来源是恒远地产。是周德明的钱。

这意味着什么？周德明——或者周建平——在给苏晴的公司提供资金。为什么？是投资？是收买？还是——某种更复杂的关系？

第三个文件是一份人物关系简报。方驰用简洁的文字描述了周建平的核心关系网：

"周建平，1980年生。周德明之子。2005年进入沧澜大学管理学院读博（在职），导师关系：赵德厚（中文系教授，博士生导师）。2009年获博士学位。2010年与沈亦寒（赵德厚硕士生）结婚。"

导师是赵德厚。妻子是赵德厚的学生。

一个人，通过师生关系和婚姻关系，把学术圈和商业圈连接在了一起。

这就是苏晴说的"系统"。

这就是方驰说的"比苏晴说的更可怕"。

周建平——"好心的学长"？

我还不确定。但所有的线索都在指向同一个方向。

我关掉电脑，躺在床上，盯着上铺的床板。

窗外的风还在吹。远处的钟楼在夜色中沉默着，像一只闭上了眼睛的巨兽。宿舍里的暖气片发出轻微的咔嗒声，像是某种古老的钟摆在来回摆动。

苏晴被捕了。

方驰逃亡了。

但迷雾——远没有散。

在迷雾的深处，有一个名字正在慢慢浮现。

周建平。

这个名字——像一把钥匙，正在慢慢打开一扇我从未敢想象的门。

门后面是什么？

我不知道。

但我知道——我必须走进去。
