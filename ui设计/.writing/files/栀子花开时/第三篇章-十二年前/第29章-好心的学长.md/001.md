# 第二十九章 好心的学长

从清河县回沧阳市的最后一班大巴是下午五点半。

我们三个人坐在大巴的后排，谁也没有说话。车窗外的景色在暮色中渐渐模糊——收割后的田野、灰色的村庄、远处山丘上零星的灯火。车厢里暖气很足，玻璃窗上结了一层薄雾，我伸出手指在雾上画了一条线，透过那条线看外面的世界，一切都变成了扭曲的、拉长的影子。

方驰靠窗坐着，侧脸对着我。他的表情在昏暗的车厢里看不太清楚，但我能看到他的下颌线绷得很紧——那是咬紧牙关的表情。

林琳坐在我旁边，膝盖上放着她的帆布包，双手交叉放在包上，像是在抱着什么珍贵的东西。她的眼圈还有些红，但已经恢复了平静。

我在脑子里反复回放日记的内容。

方苒的文字像一把刀，一刀一刀地刻出了一个十八岁女孩从天堂坠入地狱的全过程。

2008年9月，她带着对大学生活的憧憬来到沧澜大学。她加入了文学社，认识了社长，认识了苏晴，一切都那么美好。

10月，社长开始接近她——先是公开场合的鼓励和表扬，然后是私下的约谈和帮助。一个有威望的学长对一个刚入学的小学妹表示关心和欣赏，这是多么自然、多么难以拒绝的事。

11月初，事情开始变质。社长以"聊文学"为名，把方苒约到校外的咖啡馆。然后，"他对方苒做了一件事"——方苒没有写出来，但我能猜到那是什么。

之后是第二次、第三次。每一次，社长都用"喜欢"来包装他的行为。每一次，方苒都告诉自己"是我误会了"。直到她无法再欺骗自己。

11月15日，方苒开始躲着社长。但社长找到了她，威胁她——"丢人的是你，不是他"。

这是一个精心设计的权力陷阱。社长利用自己的身份、年龄、经验和在社团中的权威，一步步地蚕食了一个十八岁女孩的心理防线。他先是用关怀获取信任，然后用侵犯制造恐惧，最后用威胁确保沉默。

而方苒——一个远离家乡、没有社会经验的女孩——在这个陷阱里，无处可逃。

她不敢告诉母亲。不敢告诉老师。不敢报警。甚至不敢告诉最好的朋友。

因为社长告诉她："没有人会相信你。"

这句话，是压垮她的最后一根稻草。

不是社长的侵犯本身——虽然那已经足够毁灭一个人——而是那种被剥夺了发声权利的绝望。当一个人连求救的能力都被夺走的时候，死亡就变成了唯一的出口。

12月15日，方苒选择了那个出口。

我闭上眼睛，深深地吸了一口气。

车厢里的暖气让我有些头晕。柴油机的嗡嗡声像一首低沉的安魂曲。

"你在想什么？"林琳轻声问。

"在想日记里的那些人。"我说。

"社长。"林琳的声音压得更低，"2008年文学社的社长。他——"

"他很可能就是侵犯方苒的人。"我接过话，"日记里的描述很清楚——社长，高个子，戴眼镜，比社员大好几岁。"

"和老陈描述的那个男生吻合。"

"对。但我们需要确认他的身份。"

林琳点了点头，从帆布包里掏出笔记本，翻到一页空白的纸，开始写。

"我们来整理一下日记里的关键人物。"她说，"第一，社长——侵犯者，身份待确认。第二，苏晴——方苒的闺蜜，知道内情，但很害怕。第三，'好心的学长'——12月12日出现，说能帮方苒，但方苒不确定能不能信他。"

"对。"我说，"这三个人是关键。"

"社长和'好心的学长'是两个人。"林琳分析道，"日记里社长用的是'他'或者'社长'，而'好心的学长'是另一个称呼。而且方苒说'万一是社长派来试探我的呢'——这说明'好心的学长'和社长不是一伙的，至少方苒是这么认为的。"

"那'好心的学长'是谁？"

"一个想帮方苒的人。"林琳想了想，"但方苒不信任他。也许是因为她当时已经不敢信任任何人了。"

"或者，"我说，"'好心的学长'的帮助是有条件的。也许他想帮方苒，但他自己的身份让他不能公开站出来。"

"比如？"

"比如他是赵德厚身边的人。"

林琳抬起头看着我。

"陈向晚？"

"不一定是陈向晚。但你想——如果有一个赵德厚的学生或者熟人，知道了社长对方苒做的事，想要帮忙，但他又不敢直接对抗赵德厚——"

"那他只能暗中帮助方苒，而不能公开站出来。"

"对。"

我们沉默了一会儿。

"但这只是推测。"林琳说，"我们不知道'好心的学长'是谁。日记里没有名字，没有更多线索。"

"也许苏晴知道。"

"苏晴失踪了。"

"不是失踪。是转学了。"我纠正道，"2009年2月，她从沧澜大学转走了。林琳，你之前说查到了她的一些线索？"

"嗯。"林琳翻着笔记本，"我在市图书馆查到的。苏晴转学后去了省内另一个城市——临江市。具体在哪所学校，我没查到。但我知道她最后已知的地址是临江市的一个社区。"

"你怎么知道的？"

"户籍迁移记录。"林琳说，"2009年的报纸上有一则公告，是关于沧澜大学学生户籍迁移的。苏晴的名字在上面，迁往临江市某区。"

"临江市。"我重复了一遍这个地名。

"对。离沧阳市大概三个小时车程。"

"我们去找她。"

"现在？"

"回学校之后，找个时间去。"

林琳点了点头。

大巴在傍晚六点半到达沧阳市长途汽车站。

下车的时候，天已经完全黑了。冷风从运河方向吹过来，像刀子一样刮在脸上。车站前的广场上灯火通明，公交车和出租车来来往往，嘈杂的人声和引擎声混在一起，构成了城市夜晚特有的喧嚣。

但在这种喧嚣里，我却感到一种深入骨髓的寒意。

不是因为冷。

是因为我知道，我们离真相越来越近了。而真相——往往比黑暗更冷。

"我先回宿舍了。"方驰说。他的声音在冷风中显得格外疲惫。

"好。"我说，"明天见。"

方驰转身走向公交车站。我和林琳往相反的方向走。

"张小雨。"走了几步，林琳回头叫住我。

"嗯？"

"那个'好心的学长'——"她犹豫了一下，"你有没有想过，他可能不是一个好人？"

"什么意思？"

"我的意思是——如果方苒已经处于极度脆弱的状态，任何出现在她生活中的'好人'都可能是另一种形式的利用。也许'好心的学长'确实想帮她，但也许——他的帮助本身就是一种控制。"

我沉默了。

林琳的话让我想到了一种可能性——如果"好心的学长"并不是一个纯粹的拯救者，而是一个有着自己目的的人呢？

如果他的"帮助"是另一种形式的接近呢？

如果方苒在日记最后写的"我做了决定"，与这个"好心的学长"有关呢？

这些想法让我不寒而栗。

"回去好好想想。"林琳说，"明天我们整理一下所有线索。"

"好。"

我们分开了。

我独自走在回学校的路上。校园南门外的街道在夜晚显得格外冷清，只有几盏路灯在寒风中散发着橘黄色的光。

路过一家便利店的时候，我进去买了一杯热咖啡。纸杯握在手里，温暖从掌心传遍全身。

我站在便利店门口，喝着咖啡，看着校园里来来往往的学生。

他们不知道方苒。不知道苏晴。不知道十二年前发生在这座校园里的故事。他们只是匆匆地走过，赶着去上课、去食堂、去图书馆。

而我——我站在这条时间的河流中，试图打捞一个已经被遗忘的真相。

一个女孩的死。一个被掩盖的罪行。一群选择了沉默的人。

我喝完咖啡，把纸杯扔进垃圾桶，快步走回宿舍。

宿舍里，徐浩然坐在桌前，面前摊着一堆零件——他在拆解一个旧闹钟。方驰不在。

"又出去了？"我问。

"嗯，吃完饭就走了。"徐浩然头也不抬，"他最近老往外跑。"

"可能有什么事吧。"

"也许。"徐浩然停下手里的活，看了我一眼，"你最近也很忙。"

"嗯。"

"你们在查的那个事——"他犹豫了一下，"有进展吗？"

"有一些。"

"小心点。"他说完这三个字，又低下头继续拆他的闹钟。

我坐到桌前，拿出手机，翻看今天拍的日记照片。

一页一页地看，从方苒入学第一天的快乐，到11月的恐惧，到12月的绝望。

最后停在12月12日那一页：

"那个好心的学长说他能帮我，但我不知道能不能信他。"

好心的学长。

你到底是谁？

你是方苒生命中出现过的最后一个试图帮助她的人吗？

还是——你是把她推向深渊的最后一双手？

我放下手机，看着窗外。

校园里的路灯在寒风中微微摇晃，树影在灯光下摇曳，像是一群沉默的鬼魂在跳着一支没有音乐的舞。

十二年前的这个季节，方苒也一定看过同样的路灯，同样的树影。

她那时候在想什么？

她是否也曾站在某个夜晚的校园里，手里握着一杯热咖啡，试图从温暖中汲取一点点继续活下去的勇气？

她是否也曾仰头看着天空，寻找一颗可以寄托心愿的星星？

她是否——在最后的那一刻——想起了她的母亲，想起了那个在清河县等着她回家的女人？

我不知道。

但我知道，她的故事还没有结束。

因为真相还埋在那个人的沉默里。

那个社长——那个高高瘦瘦、戴着眼镜、笑容自信的年轻人——他现在在哪里？

他是否还在这座校园里？

他是否还在用同样的方式，对待着另一个方苒？

我关上手机，躺到床上。

黑暗中，我听到了方驰回来开门的声音。他轻手轻脚地洗漱、上床。

"小雨，你睡了吗？"他轻声问。

"快了。"

"晚安。"

"晚安。"

宿舍里安静下来。

但我睡不着。

我的脑海里反复出现日记中的那些句子——

"他说他喜欢我。"

"我不知道该怎么办。"

"苏晴说帮我，但她好像也很害怕。"

"那个好心的学长说他能帮我，但我不知道能不能信他。"

"我做了决定。"

这些句子像一根根细线，编织成一张网，把我困在其中。

而网的中心，站着一个我还没有看清脸的人。

那个社长。

明天。

明天我一定要找到他的名字。
