# 第三十一章 文学社旧照

第二天上午没课，我决定再去一次文学社的活动室。

昨夜下了一场小雨，校园里的空气被洗得清冽透明。梧桐树的枝丫上挂着细小的水珠，在晨光中闪闪发亮，像是无数颗微型的钻石。地面上湿漉漉的，落叶被雨水打湿后紧紧贴在地面上，颜色变得更深了——深红、暗黄、焦褐，像是一幅被打翻了调色盘的水彩画。

那张2008年的合影我虽然已经拍过照片，但在手机的小屏幕上看不清楚细节。2010年的手机像素实在有限，放大之后照片就变成了一片模糊的色块。我想在自然光下重新审视那张照片，看看能不能发现更多线索。

文学社的活动室在文学院老楼二层，一间朝北的房间，光线不太好。走廊里弥漫着一股旧木头和灰尘混合的气味，脚下的木地板每踩一步都会发出吱呀的声响，像是在诉说这栋老建筑的年龄。

我推开门，房间里依然没有人。墙上那些照片和活动海报在日光灯下显得格外安静，像是一个被时间遗忘的角落。窗台上有一盆不知名的绿植，叶子有些蔫了，像是很久没有人来照料。

这个房间是文学社的"家"——过去是，现在也许还是。但自从王国强死后，这里就很少有人来了。死亡的阴影像一层看不见的薄膜，覆盖在房间的每一个角落，让空气都变得沉重。

我走到那张2008年的合影前，凑近了看。

照片上八个人。后排三个男生，前排两个女生、三个男生。

后排左边第一个：矮胖，戴棒球帽，表情憨厚。我不认识他，档案里也没有对应的人——他可能不是核心成员。

后排中间：一个中等身材的男生，圆脸，表情拘谨，双手背在身后。看起来有些紧张，像是被硬拉去拍照的。

后排右边：一个瘦高的男生，只露出半张脸，被前面的人挡了一部分。他的表情看不太清楚，但身形——

我眯起眼睛。

那个站在最后面的瘦高男生，他的站姿有些特别——身体微微侧向一边，像是在试图远离镜头。这种姿态通常出现在不情愿拍照的人身上。

前排左边两个女生——苏晴和方苒。方苒搂着苏晴的肩膀，两个人都在笑。

前排中间和右边是两个男生。其中一个戴着粗框眼镜，穿着格子衬衫，看起来像是典型的理工科学生。另一个——

另一个让我注意到了。

他站在前排的右边，身体挺直，双手自然下垂，面带微笑。他的笑容和后排那些男生的笑容不同——后排的男生要么紧张，要么拘谨，要么不情愿。但他的笑容是放松的、自信的，甚至带着一丝……优越感。

那种优越感不是傲慢，而是一种习惯了被仰望的人才会有的从容。

这就是周建平。

文学社社长。法学院博士生。赵德厚的学生。

我拿出手机，翻到之前拍的照片，和墙上的合影对比。手机上的照片因为像素低，放大后有些模糊。但基本轮廓还是能看清的。

周建平，高个子，戴金属框眼镜，头发梳得整齐。在合影中，他站在最前面的位置——不是偶然的。作为社长，他自然站在了C位。

我仔细看着他的脸。

那是一张看起来"正派"的脸——五官端正，眉目清晰，嘴角微微上扬，带着一种让人信任的微笑。如果不知道他的所作所为，任何人看到这张脸，都会觉得这是一个优秀的、值得信赖的年轻人。

但我知道。

方苒的日记知道。

那张正派的脸下面，藏着什么？

我把照片拍了下来，这次用手机的最大分辨率，尽可能拍清楚。

然后我离开了活动室，去找老陈。

老陈今天的值班室里多了一样东西——一台小收音机，正在播放一档戏曲节目。咿咿呀呀的唱腔在小小的房间里回荡，给这个寒冷的秋日午后增添了一丝暖意。

"陈叔，又来找您下棋了。"我笑着说。

"来来来。"老陈把棋盘摆好，"今天让你三先。"

"别，公平竞赛。"

我们下了两盘棋，我一胜一负。老陈下棋的时候话不多，但下完之后，他泡了两杯茶，我们开始聊天。

"陈叔，我给您看个东西。"

我掏出手机，翻到那张合影的照片，递给他。

"这是2008年文学社的合影。"我说，"我们已经查到了社长的名字——周建平。"

老陈听到"周建平"三个字的时候，端茶的手微微顿了一下。

"周建平。"他重复了一遍，声音很轻。

"您认识这个名字？"

老陈没有直接回答。他放下茶杯，戴上老花镜，凑近手机屏幕，仔细地看着那张合影。

他看了很久。

收音机里的戏曲唱完了一段，换成了评书。老陈一动不动地盯着照片，像是一个考古学家在审视一块出土的文物。

"这个。"他的手指停在了周建平脸上。

"对。这是周建平。社长。"

老陈的手指在照片上停留了几秒，然后慢慢移开。

"我……"他开口，又停住了。

"陈叔，"我放柔了声音，"您想起了什么？"

老陈摘下老花镜，揉了揉眼睛。

"我不太确定。"他说，"但这个人……我见过。"

"在哪里见过？"

"不是那天晚上。"老陈摇了摇头，"是更早。在方苒死之前。"

我的心跳加速了。

"什么时候？"

"大概是2008年11月。"老陈想了想，"有一天晚上，我值夜班，大概十点多。我巡逻到文学院附近的时候，看到一个人从文学院办公楼里出来。"

"什么人？"

"一个男生。高高瘦瘦的，戴眼镜。"老陈回忆着，"他手里拿着一些文件，像是刚从办公室里出来。他看到我，愣了一下，然后快步走了。"

"您觉得那个人是周建平？"

"身形很像。"老陈说，"但那天晚上太暗了，我没看清脸。只是感觉——"

他停了一下。

"感觉什么？"

"感觉他不太对劲。"老陈皱着眉，"他走路的姿势很急，像是在赶着离开。而且——他手里拿的那些文件，他抱得很紧，像是怕被人看到。"

"他从哪间办公室出来的？"

"我不确定。"老陈想了想，"好像是……赵教授的办公室那一层。"

赵德厚的办公室。

周建平在2008年11月的一个深夜，从赵德厚的办公室里拿着文件匆匆出来。

那是在方苒开始躲避社长之后。

那是在方苒死之前。

"陈叔，"我压住心中的激动，"您当时有没有看到文件上写了什么？"

"没有。太远了。"老陈摇了摇头，"但我有一个印象——那些文件好像是旧档案。牛皮纸的文件夹，很厚的那种。"

牛皮纸的旧档案。

周建平从赵德厚的办公室里取走了旧档案。

那些档案是什么？是方苒的？还是别人的？

或者——是某种"善后"的材料？

"陈叔，"我说，"您当年有没有把这些事告诉警察？"

"没有。"老陈苦笑了一下，"你上次问我为什么不说了。我说了——我怕。"

"但现在呢？"

老陈看着我，目光里有一种我从未见过的东西。那是一个老人在生命的暮年，终于决定不再沉默的决绝。

"现在？"他叹了口气，"现在我六十二了。还能活几年？如果这些事情我再不说，带到棺材里去，那我活着还有什么用？"

他的声音有些发颤。

"张小雨，"他看着我，"你帮我一个忙。"

"什么忙？"

"如果有一天事情查清楚了，你替我去方苒的坟上烧一炷香。告诉她——陈叔对不起她，陈叔晚了十二年才说出来。"

我的鼻子一酸。

"陈叔，"我说，"不用等那一天。等事情查清楚了，我陪您一起去。"

老陈点了点头，没有再说话。

我走出值班室的时候，天色已经暗了。

校园里亮起了路灯，橘黄色的光在寒风中微微摇晃。远处的教学楼只剩下零星几扇窗户还亮着灯，像是一只只困倦的眼睛在黑暗中半睁半闭。

我站在路灯下，掏出手机，给林琳发了一条短信："重大发现。周建平——2008年文学社社长，博士生，赵德厚的学生。老陈还看到了他11月深夜从赵德厚办公室拿文件。明天见面详谈。"

林琳很快回复："好。明天老地方。另外——我有苏晴的新线索了。"

苏晴的新线索。

我把手机揣回口袋，站在路灯下想了很久。

周建平。赵德厚。2008年11月的深夜。牛皮纸的旧档案。

这些碎片在我的脑海中旋转、碰撞、组合，像是一幅拼图正在慢慢成形。

周建平和赵德厚之间的关系，远比"导师和学生"更复杂。

他们是共犯。

一个在明处侵犯，一个在暗处善后。

而方苒——一个十八岁的女孩——就这样被这两个人碾碎了。

她是一粒尘埃，被权力的巨轮碾过，无声无息地消失在时间的缝隙里。

没有人替她说话。没有人站出来保护她。没有人——

除了苏晴。但苏晴也选择了沉默。

除了那个"好心的学长"。但他也许来得太晚了。

我裹紧外套，快步走向宿舍。

一路上，我的脑海里反复出现老陈的话——

"他手里拿着一些文件，像是刚从办公室里出来。"

"那些文件好像是旧档案。牛皮纸的文件夹，很厚的那种。"

那些档案里记载着什么？是方苒的个人信息？是文学社的活动记录？还是——某种可以用来威胁或控制方苒的材料？

或者——那些档案是赵德厚用来"善后"的工具？是掩盖真相的道具？

我不知道。

但我知道一件事——

真相不会永远被掩埋。

它终会破土而出。

就像冬天过后，栀子花终会再次开放。
