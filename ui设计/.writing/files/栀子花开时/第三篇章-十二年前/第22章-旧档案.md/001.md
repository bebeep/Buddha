# 第二十二章 旧档案

第二天是周六，天刚蒙蒙亮我就醒了。

宿舍里很安静，方驰的床铺整整齐齐，不知道是早起出去了还是一夜没睡。徐浩然裹在被子里发出均匀的呼吸声，床头柜上的电子钟显示才七点半。

我轻手轻脚地起床洗漱，换了件厚一点的外套。十月底的沧阳市已经凉意透骨，尤其是一早出门，风从运河方向吹过来，带着水汽和枯叶的腥气，直往脖子里灌。

从学校到沧阳市图书馆要坐四十分钟的公交车，穿过大半个城区。我在校门口买了两个包子，一边啃一边等车。2010年的沧阳市还没有修地铁，公交线路也不算发达，从大学城到老城区，几乎要横跨整座城市。

七点五十，17路公交车准时到达。我上了车，找了个靠窗的位置坐下。车厢里大多是赶早的老人，拎着菜篮子去早市，或者带着孙辈去医院排队。车窗外的城市在晨光中慢慢醒来——早餐摊的蒸汽、环卫工人的扫帚、行道树上最后几片倔强的黄叶。

四十分钟后，我在市图书馆站下车。

沧阳市图书馆坐落在老城区的文庙街上，紧邻着那座有六百年历史的文庙。图书馆本身是一栋八十年代的苏式建筑，灰色的水刷石外墙，绿色的铁皮大门，门楣上刻着郭沫若题写的馆名。每次来这里，我都有一种走进时光隧道的感觉——外面的城市在飞速变化，而这里的时间似乎是凝固的。

林琳已经在门口等我了。

她穿着一件深蓝色的风衣，头发扎成马尾，背着一个鼓鼓囊囊的帆布包。看到我从公交车上下来，她朝我挥了挥手，脸上带着一种压抑着兴奋的表情。

"你来得挺早。"我走过去。

"我六点半就到了，图书馆八点开门，我在门口等了半小时。"她看了看我的脸，"你昨天看到我的短信就睡了吧？"

"嗯，怎么了？"

"我找到了一些东西。"她压低声音，"很重要的东西。进去说。"

八点整，图书馆准时开门。我们穿过安静的大厅，上了二楼，来到报刊阅览区。这个区域在图书馆的最里面，是一个狭长的房间，两侧是靠墙的书架，摆满了装订成册的旧报纸和期刊。中间一张长桌，几盏绿色的台灯散发着柔和的光。

这个时间段几乎没有人来，整个阅览室只有我们两个读者和一个戴着老花镜的管理员。

林琳从帆布包里掏出一个笔记本，翻开，推到我面前。

"你看。"

笔记本上密密麻麻写满了她的字迹——工整、细密，像蚂蚁排队一样整齐。她做了大量的摘录和整理，按时间顺序排列。

"过去两周，我把2008年到2009年的《沧阳日报》《沧阳晚报》和《沧澜大学校报》全部翻了一遍。"她指着笔记本上的记录，"大部分关于沧澜大学的报道都是常规的新闻——学术会议、招生信息、校园活动。但是，有几条信息值得注意。"

她翻到第一页，指着一段摘录：

"2008年12月17日，《沧阳晚报》第三版：'本市某高校一名学生于本月15日在校外住所不幸身亡。据悉，该生系因个人原因离世，相关部门已介入处理。校方表示将妥善处理善后事宜。'"

"就这一条。"林琳说，"没有名字，没有具体学校，没有任何细节。'因个人原因离世'——这是很明显的委婉说法。"

"方苒。"我说。

"对。2008年12月15日，方苒死在她租住的房子里。官方说法是自杀，但报道用的是'因个人原因离世'，连'自杀'两个字都不敢写。"林琳的手指移到下一段，"这说明什么？说明当时的报道是被控制过的。学校肯定打了招呼，要求淡化处理。"

我点点头，这和我之前的推测一致。

"但这不是最重要的。"林琳翻到下一页，"你往下看。"

下一段摘录来自2009年2月的《沧澜大学校报》：

"经学校教务处批准，以下同学因个人原因办理转学手续：文学院2008级学生苏晴，转入省内某高校继续学业。特此公告。"

"苏晴。"我念出这个名字。

"对，苏晴。"林琳的眼睛亮了起来，"方苒的闺蜜，文学社的成员，2008年9月和方苒一起入学的大一新生。2008年12月15日方苒死了，两个月后的2009年2月，苏晴就转学离开了沧澜大学。"

"没有任何公开说明？"

"没有。校报上就这一句话，'因个人原因'。没有原因说明，没有去向——连转入哪所学校都没写。这在正常的转学公告里是很少见的。一般转学公告至少会写明转入学校和专业，但苏晴这条什么都没有。"

我沉默了一会儿。

方苒死了，苏晴走了。两个人之间一定有什么联系。

"还有一件事。"林琳翻到笔记本的最后一页，声音压得更低了，"我在苏晴转学前的最后一期《沧澜大学校刊》上——也就是2009年1月号——找到了苏晴发表的一篇作品。"

"什么作品？"

"一首诗。"

她把笔记本推到我面前，最后一页上抄录着那首诗的全文。

标题是——《沉默的栀子》。

我的手微微一颤。

栀子花。又是栀子花。

我低头看那首诗。诗不长，只有四节，但每一行字都像浸透了某种深沉的悲痛：

"你走的那天/栀子花还没有开/我把你的名字/写在起雾的窗玻璃上/然后看着它/一点一点消失"

"他们说你是自己走的/他们说是你的选择/但我知道/那天的风那么大/你一个人/怎么站得稳"

"我把嘴闭紧/把眼睛闭上/把想说的话/一颗一颗咽回去/像咽下/一颗苦涩的药"

"等栀子花开的时候/我会去看你/带一束白色的花/放在你喜欢的地方/然后/继续沉默"

我把那首诗看了两遍，每看一遍，后背的寒意就重一分。

这不是一首普通的诗。

"你走的那天/栀子花还没有开"——方苒死于2008年12月15日，栀子花的季节是五六月。方苒走的时候，确实不是栀子花开的时候。

"他们说是你的选择"——"他们"说方苒是自杀，是"自己的选择"。但苏晴不信。

"我把嘴闭紧"——苏晴选择了沉默。但她为什么沉默？是被迫的，还是自愿的？

"等栀子花开的时候/我会去看你"——苏晴承诺会去看方苒，但2009年2月她就转学离开了。她到底有没有去看过方苒？

"这首诗……"我抬起头看林琳，"你怎么看？"

"我觉得这不是一首普通的悼念诗。"林琳的表情很严肃，"你看第二节——'但我知道/那天的风那么大/你一个人/怎么站得稳'。这句话的潜台词是：方苒不是自己选择走的，她是被什么东西推倒的。苏晴不信方苒是自杀。"

"但苏晴选择了沉默。"

"对。'我把嘴闭紧/把眼睛闭上。'"林琳停顿了一下，"但问题是——她为什么要沉默？一个刚失去最好朋友的人，为什么会选择沉默？"

"被威胁了？"

"有可能。但也有另一种可能——"林琳压低了声音，"她知道真相，但那个真相太可怕了，她不敢说出来。"

"或者，她觉得自己也有责任。"我说。

林琳看了我一眼，没有反驳。

我们沉默了一会儿。阅览室里只有翻页的沙沙声和暖气管道里偶尔发出的咕噜声。窗外的阳光透过老式木窗框照进来，在桌面上画出一格一格的光影。

"我还有一个发现。"林琳从帆布包里又掏出一叠复印纸，"这是2008年10月到12月的《沧澜大学校报》。我翻了这三个月的所有版面，发现了一个有趣的现象。"

她把复印纸铺在桌上，指着其中一期校报的一则短讯：

"2008年11月20日，校文学社在文学院报告厅举办年度诗歌朗诵会，活动取得圆满成功。"

下面附了一张照片——模糊的黑白照片，拍的是诗歌朗诵会的现场。照片上能看清几个站在台上朗诵的学生，但台下观众的脸都看不清。

"注意这个。"林琳指着照片角落里的一个模糊身影，"你看这个人。"

我凑过去看。照片的右下角，有一个模糊的人影，似乎正从门口离开。那个人穿着深色的外套，身形修长，低着头，看不清脸。

"这有什么特别的？"我问。

"这个人每次文学社的活动照片里都有。"林琳把另外几期校报的照片并排放在一起，"10月15日的读书分享会，11月5日的文学创作讲座，11月20日的诗歌朗诵会——每次都有这个人，在角落，低着头，要么在进要么在出。"

"你确定是同一个人？"

"身形和姿态都一样。我比对过了。"林琳说，"但我不确定这是谁。照片太模糊了。"

我盯着那个模糊的身影看了很久。一个每次都出现在文学社活动中、却总是待在角落、低着头不想被注意到的人——这个人要么是性格内向的普通成员，要么——是在暗中观察着什么。

"还有一件事。"林琳把笔记本翻回第一页，"我把所有找到的信息整理了一个时间线。你看——"

她在纸上画了一条横线，标注了几个关键节点：

"2008年9月——方苒、苏晴入学沧澜大学，加入文学社。"
"2008年10月-11月——正常的大学生活，文学社活动频繁。"
"2008年12月15日——方苒死亡。"
"2008年12月17日——《沧阳晚报》简短报道，措辞含糊。"
"2009年1月——苏晴在校刊发表《沉默的栀子》。"
"2009年2月——苏晴转学离开，没有任何公开说明。"

"从方苒入学到死亡，只有三个月。"林琳用笔点了点时间线上的那个空白区间，"10月到12月初，这两个月里一定发生了什么。苏晴的诗暗示她知道一些事情，但她选择了沉默，然后离开了。"

"两个月。"我重复着这个数字。

一个刚入学的女大学生，在短短两个月内从正常走向绝望，最终在12月15日结束了自己的生命。而她的闺蜜在两个月后也选择了逃离。

这中间，到底发生了什么？

"我还有一个问题想不通。"我皱着眉说，"如果方苒是因为'个人原因'自杀，为什么学校要如此大力度地封锁消息？一个学生的正常自杀，为什么要控制媒体报道？为什么要把苏晴的转学信息压到最低限度？"

"除非——"林琳看着我，"方苒的死不是'个人原因'。除非她的死牵涉到了学校里的某些人，某些有权力、有能力封锁一切的人。"

我们四目相对，都从对方的眼睛里看到了同样的东西——一个越来越清晰的、令人不安的推测。

"我们还需要更多的信息。"我说，"报纸上的信息太少了，都是被过滤过的。我们需要找到当事人的说法。"

"当事人的说法……"林琳沉吟了一下，"方苒的家人？"

"方苒的母亲。"我说，"但在那之前，我们需要先弄清楚苏晴去了哪里。她是除方苒之外，最了解内情的人。"

"可是她2009年就转学了，现在2010年，过了快两年了。"

"总会有痕迹的。"我说，"我们先从方苒这边入手。"

林琳点了点头，开始收拾桌上的资料。

就在这时，阅览室门口传来一阵脚步声。那个戴老花镜的管理员走了过来，手里拿着一本厚厚的册子。

"你们两个小同学，"管理员推了推眼镜，"在看旧报纸？"

"是的，老师。"林琳礼貌地回答。

"你们在找什么？"

林琳犹豫了一下，看了我一眼。我微微点头。

"我们在找2008年底关于沧澜大学的一些旧闻。"我说。

管理员的表情变了一下。不是惊讶，而是一种更微妙的东西——像是某根被触动了的旧弦。

"2008年底……"他喃喃地说，"那一年啊……"

"老师，那一年有什么特别的事吗？"我试探着问。

他看了我们一眼，又看了看四周，确认阅览室里只有我们三个人，然后压低了声音：

"你们要是查沧澜大学2008年的事，我劝你们一句——有些事，不知道比知道好。"

说完，他把那本厚册子放在桌上，转身走了。

我和林琳对视了一眼。

"他什么意思？"我低声问。

"我不知道。"林琳摇了摇头，但她的眼神告诉我，她和我一样，心里已经有了某种预感。

管理员的话像一颗石子投入了平静的水面，涟漪一圈一圈地扩散开来。

有些事，不知道比知道好。

可是我们已经知道了太多。

我们已经知道了一个叫方苒的女孩在2008年12月15日死去。我们已经知道了她的闺蜜苏晴在两个月后仓皇逃离。我们已经知道了一首叫《沉默的栀子》的诗里藏着不敢说出口的真相。

我们已经无法假装不知道了。

我把林琳整理的资料小心地收好，和她一起走出了图书馆。

文庙街上的梧桐树比校园里更老更高，树冠遮天蔽日，落叶铺了厚厚一层。远处传来文庙里悠扬的钟声，那是整点报时的声音，沉闷而悠长。

"下一步怎么办？"林琳问。

"去找方苒的老家。"我说，"方苒是沧阳市下面一个县城的人。我想去她家看看。"

"怎么去？"

"坐长途汽车。周末就行。"

林琳想了想，点了点头。

"但我们需要一个了解情况的人带路。"她说。

我想了想，脑海中浮现出方驰的脸。

方驰。

他说他老家就在沧阳市下面的县城。

"我有一个人选。"我说。

"谁？"

"我室友，方驰。"

林琳微微皱了皱眉："他？可靠吗？"

我沉默了一瞬。方驰这段时间的表现一直很积极，积极到有时候让我觉得不太自然。但我还没有发现任何实质性的问题。

"应该没问题。"我说。

但说出这句话的时候，我心里有一个很小的声音在说——

真的没问题吗？

风吹过来，卷起地上的梧桐叶。远处文庙的钟声又响了一下，像是在回答什么，又像是在警告什么。
