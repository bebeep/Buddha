# 第二十六章 方苒的老家

第二天上午，我和林琳在图书馆门前的长椅上碰面。

我把老陈告诉我的事一五一十地说了——那个深夜从方苒住处走出来的男生，高瘦，戴眼镜，手里拿着一朵白花。林琳听完，沉默了好一会儿。

"如果老陈说的是真的，"她终于开口，"那方苒的死就不是简单的自杀。那个男生是关键。"

"对。我在文学社的合影里看到一个高个子男生，看起来像是社长。老陈看了照片，说感觉像。"

"感觉像。"林琳重复了一下这三个字，语气里带着一丝保留，"这不够确定。"

"我知道。但这是我们目前唯一的线索。"

"那个社长的名字查到了吗？"

"还没有。2008年的文学社记录不全，校刊上也没有完整的成员名单。"

林琳想了想："我们需要找到方苒的更多资料。她的日记、信件、或者任何她留下的文字。如果她生前记录了什么，那就是最直接的证据。"

"问题是——去哪里找？"

"去她家。"林琳看着我，"去方苒的老家。"

我点了点头。这也是我一直在想的事。

"方驰说他老家就在沧阳市下面的县城，离方苒的老家不远。"我说，"他建议我们周末去一趟。"

"方驰也去？"

"他说他可以带路。"

林琳微微皱了皱眉。自从上次饭馆的事之后，她对方驰的态度变得谨慎了许多。

"你觉得他可靠吗？"她问。

"我不确定。"我决定说实话，"但他是方苒的弟弟。"

林琳的眼睛猛地睁大了。

"什么？"

"方驰。"我压低声音，"他的真名可能不叫方驰。他姓方，他老家在方苒老家附近。我怀疑他就是方苒的弟弟。"

"你怀疑？你不确定？"

"没有确凿的证据。但很多细节对不上——他对方苒的事太了解了，他加入调查太积极了，他对文学社的照片反应太大了。"

林琳沉默了。她低头看着地面上的落叶，用脚尖无意识地拨弄着。

"如果我们直接问他——"

"不。"我打断她，"现在不能问。如果他真的是方苒的弟弟，那他隐瞒身份一定有他的原因。我们现在还不知道他的目的是什么——是为了找到真相，还是为了别的什么。"

"比如？"

"比如报复。"

这三个字从嘴里说出来的时候，我自己都打了个寒颤。

一个失去姐姐的弟弟，十二年后来到姐姐死亡的大学，隐姓埋名，接近可能知道真相的人，调查姐姐死亡的真相——如果他的目的不是正义，而是复仇呢？

"那我们还要带他一起去？"林琳问。

"带。"我说，"因为他有方苒老家的地址。没有他，我们可能连方苒家在哪里都找不到。而且——"

我停了一下。

"而且什么？"

"而且我想看看，到了方苒的老家，他会有什么反应。"

林琳看了我一眼，没有再说什么。

我们决定周六出发。

接下来的几天里，我一边上课一边整理手头的线索。方驰的表现一切如常——上课、吃饭、打球、聊天，看不出任何异常。但每当我注意他的时候，总会发现一些微小的、不协调的细节。

比如，他偶尔会走神。那种走神不是普通的发呆，而是一种很深的、仿佛被什么东西拽走了的恍惚。每次走神回来，他都会下意识地看一眼手机，像是在确认什么。

比如，他对方苒的事表现出一种超出"调查伙伴"的关切。他从不主动问细节，但每次我和林琳讨论案情的时候，他总是在旁边安静地听着，眼神专注得近乎贪婪。

比如，有一次我半夜醒来上厕所，发现方驰不在床上。我看了看手机——凌晨两点。他过了将近一个小时才回来，身上带着一股夜晚的凉气。

我没有问他去了哪里。

但我在心里记下了。

周六早上七点，我们三个人在学校南门外的长途汽车站碰面。

方驰背着一个大双肩包，穿了一件深色的夹克，看起来精神很好。他手里拿着两张车票。

"到清河县，两个半小时。"他把一张票递给我，"八点的车。"

清河县。方苒的老家。

林琳也到了，背着她那个永远鼓鼓囊囊的帆布包，里面不知道装了什么。她跟方驰打了个招呼，表情平静，但我看得出她在暗中观察他。

"你们先去吧。"方驰把车票递给我们之后说，"我顺路回一趟家，我爸妈住在县城东边。我回去看看他们，大概一个小时后在方苒家附近跟你们碰面。"

"你老家在清河？"林琳问。

"嗯，就在县城。"方驰笑了笑，"世界很小吧？"

他从口袋里掏出一张纸条，递给我。

"这是方苒家的地址。老城区幸福路17号，三楼。她妈妈应该还住在那里。"

我接过纸条，看了一眼——幸福路17号。

"你之前去过方苒家？"我问。

方驰的表情微微变了一下。那个变化很短暂，像一片云飘过水面，投下一瞬的阴影就消失了。

"没有。"他说，"但我打听过。"

"打听过？"

"嗯。我来沧澜大学之前，就想找到姐姐的……"他停了一下，似乎在斟酌用词，"找到她待过的地方。所以我提前打听过她家的地址。"

姐姐。

他说了"姐姐"。

不是"方苒"，不是"那个女生"，而是"姐姐"。

这个称呼从一个室友嘴里说出来，荒诞而刺耳。但方驰的语气那么自然，那么理所当然，好像他天生就该叫方苒"姐姐"。

我和林琳交换了一个眼神。

"那你先去家里看看。"我说，"我们在幸福路等你。"

"好。一个小时后见。"

方驰转身走向另一个方向的公交车站。我看着他的背影消失在清晨的人流中，然后和林琳一起上了去清河县的大巴。

大巴是一辆老旧的宇通客车，座椅上的布套洗得发白，车窗上有一道裂缝用透明胶带粘着。车里的暖气不太足，冷风从窗缝里钻进来，带着柴油机的味道。

八点整，大巴准时出发。

从沧阳市到清河县走的是省道，路况不算好，大巴在蜿蜒的公路上摇摇晃晃，像一艘在波浪中颠簸的小船。窗外的景色从城市渐渐变成了郊区，又从郊区变成了乡村——收割后的稻田、光秃秃的杨树、灰色的村庄、远处隐约可见的山丘。

2010年的中国，高铁还没有覆盖到所有的县城。从沧阳市到清河县，只能坐这种慢悠悠的长途大巴，在省道上一站一站地颠簸。

林琳坐在我旁边，靠着车窗，看着外面不断后退的风景。

"你在想什么？"我问。

"在想方苒。"她说，"她十二年前也是坐这条路来沧澜大学的吧？一个十八岁的女孩，从县城来到城市，带着对大学生活的憧憬。然后——"

她没有说下去。

"然后不到一个学期，她就死了。"我替她说完了。

我们沉默了一会儿。

"你觉得方驰——"林琳开口，又停住了。

"你觉得呢？"我反问。

"我觉得他不像是在演。"林琳斟酌着说，"如果他是方苒的弟弟，那他对姐姐的感情是真的。他加入调查，不是为了害我们，而是为了找到真相。"

"你确定？"

"不确定。但我的直觉是这样。"她转过头看着我，"你呢？"

我想了想。

"我也觉得他的感情是真的。"我说，"但感情真不代表行为对。一个人可以出于最纯粹的感情，做出最危险的事。"

林琳没有回答。

大巴在一个小站停了下来，上来了几个拎着菜篮子的老人。车厢里弥漫着一股混合了柴油、汗水和橘子皮的气味。

我靠在座椅上，闭上眼睛，脑海里浮现出方苒在合影中的样子——圆圆的脸，灿烂的笑，扎着马尾辫，看起来像一个无忧无虑的高中生。

十二年前，她十八岁。和我现在一样大。

她怀着怎样的心情来到沧澜大学？对大学生活有什么期待？她加入文学社的时候，是因为热爱文学，还是因为想交朋友？她第一次看到校园里的梧桐树时，有没有掏出手机拍一张照片？

这些问题永远不会有人回答了。

因为她在十八岁那年的冬天，死在了一间租住的小房间里。

大巴在十点半到达清河县汽车站。

清河县比我想象中小得多。汽车站只有一排低矮的平房，门口停着几辆三轮车和摩托车。站前是一条宽阔但冷清的马路，两边是三四层的旧楼房，底楼开着各种小店铺——五金店、裁缝铺、早餐摊、手机贴膜摊。

空气里有一股淡淡的煤烟味。十月底的北方小县城，已经开始烧暖气了。

"走吧。"我背起包，"幸福路应该不远。"

我们出了汽车站，沿着主街往北走。清河县的城区很小，从汽车站到老城区，步行也就十几分钟。街道两旁的建筑大多是八九十年代的风格——水刷石外墙、绿色铁皮窗框、阳台上挂满了衣服和被单。

路上的人不多。偶尔有几辆电动车从身边驶过，发出嗡嗡的电机声。一个老太太坐在街边的矮凳上剥毛豆，旁边放着一台老式的收音机，正在播放评书。

这就是方苒长大的地方。

一个安静的、缓慢的、几乎被时间遗忘的小县城。

从这里走出去的女孩，带着对大世界的向往，来到了沧澜大学。然后，她就再也没有回来。

幸福路在老城区的北面，是一条不宽不窄的街道，两旁种着法国梧桐——和沧澜大学校园里的一样，只是更老、更矮、更沧桑。路面的柏油已经开裂，缝隙里长出了枯黄的杂草。

17号是一栋六层的居民楼，红砖外墙，水泥台阶，楼道口的铁门锈迹斑斑。楼前有一小块空地，停着几辆自行车和一辆三轮摩托车。

我们站在楼下，抬头看了看。三楼的窗户上挂着碎花窗帘，窗台上放着几盆已经枯萎的花。

"就是这里了。"我说。

林琳深吸了一口气。

"你紧张吗？"我问。

"有一点。"她诚实地说，"我们要去见一个失去了女儿十二年的母亲。我不知道该怎么开口。"

"实话实说。"我说，"我们是方苒的同学，我们想知道真相。"

"她会告诉我们吗？"

"我不知道。但我们要试。"

我们走上水泥台阶，穿过昏暗的楼道，来到三楼。楼道里有一股陈旧的潮气，混合着炖菜和樟脑丸的味道。

301室的门是一扇老式的防盗门，铁质的，上面贴着一个倒着的"福"字，已经褪成了粉红色。

我抬手敲了敲门。

一下，两下，三下。

没有回应。

我又敲了三下。

几秒钟后，门后传来一阵缓慢的脚步声。很轻，像是穿着棉拖鞋在地板上蹭。

然后，门开了一条缝。

一张脸出现在门缝里。

那是一个中年女人的脸。头发花白，面容憔悴，眼角的皱纹像是刀刻的一样深。她穿着一件暗红色的棉袄，领口竖起来，遮住了半张脸。

她的眼睛——那双眼睛让我心头一颤。那是一双被悲伤浸泡了太久的眼睛，瞳孔里有一种灰蒙蒙的光，像是冬天结了冰的湖面。

"请问……"我开口，"您是方苒的母亲吗？"

她的身体微微僵了一下。

"你们是……"

"我们是方苒在沧澜大学的同学。"我说，"我叫张小雨，她叫林琳。我们是法学大一的新生。"

方苒的母亲没有说话。她透过门缝看着我们，目光在我和林琳之间来回移动，像是在确认什么。

然后，她的眼圈红了。

"你们……你们是苒苒的同学？"她的声音沙哑而颤抖。

"是的。"

她沉默了几秒钟。然后，她慢慢地、像是用尽了全身力气一样，把门打开了。

"进来吧。"她说。

我们跟着她走进了这个家。

客厅不大，摆设很简单——一张旧沙发，一个茶几，一台老式的显像管电视机。墙上挂着一幅放大的照片——

照片里是一个年轻女孩，圆圆的脸，灿烂的笑，扎着马尾辫。

方苒。

照片里的方苒永远定格在了十八岁。她的笑容那么明亮，那么无忧无虑，和客厅里弥漫的悲伤形成了刺目的对比。

"坐吧。"方苒的母亲指了指沙发，"我去倒水。"

她走进厨房，我听到水壶放在灶台上的声音，然后是煤气灶点火的"啪"的一声。

林琳在我旁边坐下来，轻轻握了握我的手。她的手很凉。

我看着墙上方苒的照片，心里涌起一股说不清的情绪。

十二年了。

这个母亲在这个房子里独自生活了十二年，每天面对着女儿的照片，每天回忆着那个再也回不来的冬天。

而真相——真相被埋在了沧澜大学的某个角落里，被权力、恐惧和沉默层层覆盖，像一具被深埋的尸骨。

方苒的母亲端着两杯水走出来，放在茶几上。

"你们怎么找到这里的？"她坐下来，声音平静了一些，但双手还在微微颤抖。

"方苒的事……我们知道一些。"我斟酌着措辞，"我们在学校里发现了一些线索，觉得方苒的死可能不是自杀。所以我们想来了解一下情况。"

方苒的母亲听到"不是自杀"四个字的时候，整个人像被电击了一样。她的手猛地攥紧了膝盖上的棉袄下摆，指节发白。

"你们……你们也觉得不是？"她的声音突然尖利了起来，像是一根绷了十二年的弦终于被拨动了。

"我们还在调查。"我说，"但我们发现了很多疑点。"

方苒的母亲看着我，眼泪终于从那双灰蒙蒙的眼睛里流了出来。

"我就知道。"她喃喃地说，"我就知道不是自杀。我的苒苒……她那么爱笑，那么坚强，她不会自杀的……"

她用手背擦了擦眼泪，深吸了一口气，努力让自己平静下来。

"你们想知道什么？"她问。

"一切。"我说，"关于方苒的一切。"

她点了点头，站起来，走向走廊尽头的一间房间。

"这是苒苒的房间。"她推开门，"十二年了我没有动过里面的任何东西。"

我跟着她走到门口，往里看了一眼。

房间不大，但收拾得很整齐。一张单人床，铺着淡蓝色的床单。一张书桌，上面摆着几本大学课本和一个文具盒。一个书架，放着高中时代的教科书和一些文学名著。窗台上放着一个小花瓶——花瓶里什么也没有，但我能想象，在栀子花开的季节里，这里一定插着几朵白色的栀子花。

一切都保持着十二年前的样子。

像是一个被时间凝固了的房间。

像是一个母亲用十二年的等待，为女儿保留的一个永远不会再有人住进去的巢。

"你们看吧。"方苒的母亲站在门口，声音轻得像风，"她所有的东西都在这里。"

我走进房间，林琳跟在后面。

我开始仔细地、一件一件地翻看方苒留下的东西。
