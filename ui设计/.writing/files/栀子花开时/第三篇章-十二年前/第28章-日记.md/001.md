# 第二十八章 日记

离开方苒家之后，我和林琳在清河县的街道上走了一段路。

天色已经暗了下来，路灯亮起了昏黄的光。街道上的行人更少了，偶尔有几个骑着自行车的人从身边经过，车轮碾过柏油路面发出沙沙的声响。远处传来一阵炒栗子的香味，混合着煤烟和冬天的寒意。

"你觉得日记在哪里？"林琳问。

"我也在想这个问题。"我说，"方苒的母亲说她从初中就开始写日记，每天都写。但箱子里没有日记本，房间里也没找到。"

"学校寄回来的遗物里也没有。"

"对。那只有两种可能——要么日记不在她家里，要么日记被藏起来了。"

"被谁？"

"被方苒自己。"我想了想，"一个正在经历某种可怕事情的女孩，她可能会把日记藏在一个不容易被发现的地方。如果她担心有人翻看她的日记——"

"或者，"林琳接过话，"日记还在她的租住房里。学校寄回来的只是部分遗物。"

我们站在街角，讨论着下一步怎么办。方驰还没有出现——他说一个小时后碰面，现在已经过了两个多小时了。

"再等等。"我说。

我们又等了十几分钟，方驰终于出现了。他从街道的另一头走过来，步伐匆匆，脸上带着一种说不清的表情——像是刚经历了一场情绪上的风暴，正在努力恢复平静。

"抱歉，来晚了。"他走到我们面前，微微喘着气，"家里多聊了一会儿。"

"没事。"我看着他，"你还好吗？"

"还好。"他点了点头，但眼圈微微有些发红。

我没有追问。

"我们准备回方苒家。"我说，"我觉得房间里可能还有我们没找到的东西。"

"什么东西？"

"日记。"

方驰的表情变了一下。

"方苒的日记？"

"对。她母亲说她有写日记的习惯，但我们没找到。"

方驰沉默了几秒。

"那我们回去找找。"他说。

我们三个人原路返回，来到幸福路17号。方苒的母亲看到我们回来，有些意外。

"阿姨，我们想再看一下方苒的房间。"我说，"可能有一些东西我们之前漏看了。"

"好，你们去看吧。"方苒的母亲叹了口气，"我去给你们切点水果。"

我们走进方苒的房间。

这次我换了一种方式寻找——不是翻箱倒柜，而是站在房间中央，环顾四周，试图从一个十八岁女孩的视角来思考：如果我要藏一本日记，我会藏在哪里？

书桌上的东西都翻过了。书架上的书也检查了。床底下只有那个纸箱。衣柜里除了衣服什么都没有。

还剩下哪里？

我的目光落在书桌上那几本大学课本上。之前我在那本《宪法学》里找到了一张纸条。也许——

我走到书桌前，把那几本课本一本一本地拿起来，仔细地翻看。

《法理学导论》——没有。
《宪法学》——之前找到了纸条，但没有日记。
《大学英语》——

我翻开《大学英语》的封面，用手指摸了摸书脊的内侧。

书脊的厚度不对。

一本普通的《大学英语》课本，书脊应该是一厘米左右。但这本课本的书脊明显更厚——大概有两厘米。

我把课本翻开，检查封面和第一页之间的夹层。

在封面内页和第一页之间，有一个被精心制作的隔层——两张硬卡纸粘合在一起，中间形成了一个扁平的暗格。

我小心地用手指探进去，摸到了一个薄薄的、纸质的小本子。

"找到了。"我说。

林琳和方驰都凑了过来。

我把那个小本子从暗格里取出来。

那是一本A6大小的笔记本，封面是淡紫色的，上面印着一朵小小的栀子花。笔记本很薄，大概只有五六十页，但因为被塞在课本的暗格里，纸页已经被压得很紧实。

我深吸一口气，翻开了第一页。

扉页上，方苒用她工整的字迹写着：

"方苒的日记。2008年9月1日开始。"

下面还有一行小字：

"如果我有一天不在了，希望看到这本日记的人，能替我说出真相。"

我的手指微微发颤。

方苒在写这本日记的时候，就已经预感到了什么吗？

"如果我有一天不在了。"

一个十八岁的女孩，在日记的扉页上写下这样的句子，像是在做某种预兆性的交代。

我开始一页一页地翻看。

日记从2008年9月1日开始，也就是方苒入学的第一天。

"9月1日。今天来沧澜大学报到了。学校好大，比高中大了十倍不止。宿舍是四人间，我的床位靠窗，能看到外面的梧桐树。室友人都很好。苏晴是隔壁床的，她也是文学社的，我们聊了一晚上，发现都喜欢席慕蓉的诗。"

"9月5日。今天去参加了文学社的招新。文学社好多人，社长是个很热情的人，高高瘦瘦的，戴眼镜，说话很好听。他说欢迎新社员，以后大家就是一家人了。"

"9月10日。第一次文学社聚会。社长组织了一个诗歌朗诵会，我朗诵了一首席慕蓉的《一棵开花的树》。社长说我读得很好，还鼓励我以后多参加社团活动。我好开心。"

"9月20日。和苏晴去市区逛了一天。沧阳市好繁华，有好多商场和电影院。苏晴买了一本书，我什么都没买——生活费要省着花。"

"10月5日。国庆假期没有回家。和苏晴在校园里待了几天，去图书馆看了好几本书。大学生活真好，每天都可以看自己喜欢的书。"

"10月15日。文学社读书分享会。社长分享了他读的一本小说，讲得特别好。我越来越觉得社长是一个很厉害的人。"

"10月28日。今天社长单独找我谈话。他说看了我写的诗，觉得我很有才华，建议我多写一些。他还说可以帮我推荐到校刊上发表。我好感动。"

到这里为止，日记的语气都是轻快的、明亮的，充满了大一新生对未来的憧憬和期待。方苒的文字干净利落，带着一种少女特有的天真和热忱。

但从11月开始，一切都变了。

"11月3日。今天社长又找我谈话了。这次不是在社团活动室，而是在校外的咖啡馆。他说想跟我聊聊文学，聊聊人生。我很紧张，但也很期待。他比我大好几岁，懂得很多，跟他聊天能学到很多东西。"

"11月8日。社长今天对我做了一件……我不知道该怎么写。他……他……算了，我写不出来。我告诉自己那只是一个意外。社长不是那样的人。一定是我误会了。"

我的手停在了这一页上。

"社长今天对我做了一件……"

她没有写出来。

但我能猜到。

"11月12日。又发生了。这次不是在咖啡馆，是在他的宿舍。他说有一份重要的资料要给我看，让我去他宿舍拿。我去了。然后……然后他……他说他喜欢我。他说他和别人不一样，他是真的喜欢我。我不知道该怎么办。"

"11月15日。我开始躲着社长。不去社团活动了，看到他的消息也不回。苏晴问我怎么了，我不敢告诉她。我觉得丢人。我觉得是我自己的错。"

"11月20日。社长找到了我。在教学楼后面的小路上。他拦住我，说我不应该躲着他。他说如果我们之间的关系被别人知道了，丢人的是我，不是他。他说没有人会相信一个大一女生的话。他说让我想清楚。"

"11月25日。苏晴发现了。她看到我哭，一直追问，我 finally 告诉了她。她听完之后脸都白了。她说这是不对的，她说要去告诉老师。我说不要。我说求你不要告诉任何人。苏晴说她理解，但她的眼神告诉我——她也很害怕。"

"12月1日。社长说如果我不继续跟他好，他就要把我们的事告诉所有人。他说他会说是我主动的。他说没有人会相信我。我该怎么办？我该怎么办？"

"12月5日。他又来了。在我租住的地方。他说最后一次给我机会。我锁了门不让他进来，他在外面站了很久才走。我缩在床角，一整夜没有睡。"

日记到这里，字迹开始变得潦草而凌乱，有些地方的墨水洇开了——是泪水的痕迹。

"12月8日。苏晴说帮我想想办法。但她也好像很害怕。她说那个人很有权势，得罪了他我们都不会有好结果。我不知道她说的'权势'是什么意思。但我知道——我完了。"

"12月10日。给妈妈打了电话。不敢说。什么都不能说。妈妈说注意身体。我说知道了。"

"12月12日。那个好心的学长说他能帮我。他说他有证据可以对付社长。但我不知道能不能信他。万一是社长派来试探我的呢？我已经不敢相信任何人了。"

最后一页。

"12月14日。我做了决定。"

只有这六个字。

我做了决定。

什么决定？

第二天，12月15日，方苒死了。

日记到此戛然而止。

我合上日记本，双手在微微发抖。

林琳的眼眶红了。方驰站在旁边，脸色铁青，双拳攥得紧紧的，指节发白。

"社长。"林琳用几乎听不到的声音说，"文学社的社长。"

"对。"我的声音也在发颤，"方苒的日记里反复提到'社长'。这个人对她做了……做了那种事。然后威胁她，控制她。"

"那个'好心的学长'是谁？"林琳翻到12月12日那一页，"方苒说'那个好心的学长说他能帮我'——这个人是誰？"

"不知道。日记里没有写名字。"

"还有——'他又来了'。"林琳指着12月5日那一页，"'他'在方苒租住的地方外面站了很久。这个'他'应该就是社长。"

"对。"

"那老陈看到的那个深夜从方苒住处出来的男生——"

"可能就是社长本人。"我说，"12月15日晚上，老陈看到一个男生从方苒的房子里出来。而方苒的日记说，12月5日'他'来过她的租住处。如果'他'在12月15日晚上也去了——"

我没有说下去。

因为接下来的推论太残酷了。

如果那个社长在12月15日晚上去了方苒的住处，然后从里面匆匆离开——那么方苒的死，就发生在他离开之后。

他是最后一个见到方苒活着的人。

房间里安静得只剩下墙上闹钟的滴答声。

方驰终于开口了。他的声音很低，低到像是从胸腔深处挤出来的。

"我要找到那个社长。"

他的语气不是在提议，而是在宣告。

我看着他。他的眼睛里有一种我从未见过的东西——不是悲伤，不是愤怒，而是一种更深的、更冷的、更危险的情绪。

那是一个弟弟在得知姐姐死亡真相之后的反应。

"我们需要先弄清楚社长是谁。"我说，"日记里没有写名字。"

"2008年的文学社社长。"林琳擦干眼泪，恢复了冷静，"这个名字一定在学校的记录里。社团注册信息、活动记录、校刊的编辑名单——总会有记载。"

"我们回学校查。"我说。

我把日记本小心地用纸巾包好，放进了自己的背包里。

"原件要还给方苒的母亲。"我对林琳说，"我们先拍照留底。"

我们用手机的摄像头，一页一页地拍了日记的内容。2010年的手机像素不高，拍出来的文字有些模糊，但勉强能看清。

拍完之后，我把日记本放回那个淡紫色的封套里。

我们走出方苒的房间时，方苒的母亲正坐在客厅里发呆。电视开着，但没有声音，屏幕上闪烁着模糊的画面。

"阿姨，"我走到她面前，"我们找到了一些东西。"

我把日记的事告诉了她。

她听完之后，沉默了很久。然后她站起来，走到墙上方苒的照片前，伸手摸了摸相框。

"苒苒，"她轻声说，"妈妈会替你讨回公道的。"

她的声音很平静，但那种平静比任何哭喊都更让人心碎。

我们离开的时候，天已经完全黑了。清河县的路灯稀稀落落的，有些路段甚至没有路灯，只有远处居民楼里透出的微弱灯光。

方驰走在最前面，步伐很快。我和林琳跟在后面，谁也没有说话。

走到汽车站附近的时候，方驰突然停下来，转过身。

"张小雨。"他的声音在黑暗中显得格外清晰。

"嗯？"

"不管那个社长是谁，"他说，"我一定要让他付出代价。"

他的眼睛里映着远处路灯的微光，像两颗冰冷的星星。

我点了点头。

但我的心里，有一个声音在说——

代价。

什么样的代价？

法律的代价，还是别的什么？

我看着方驰转身继续往前走的背影，忽然觉得，这个案件中最危险的人，也许不是那个隐藏在暗处的社长。

而是走在我前面的这个，以弟弟之名追查真相的人。
