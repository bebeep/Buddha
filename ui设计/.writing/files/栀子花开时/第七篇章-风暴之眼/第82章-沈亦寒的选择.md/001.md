# 第八十二章 沈亦寒的选择

第二天中午，我坐在食堂里，面前的饭菜几乎没动。

林琳坐在我对面，同样心不在焉地拨弄着碗里的米饭。食堂里人来人往，嘈杂的人声像一层厚厚的幕布，将我们和周围的世界隔开。

"你真的要去？"林琳压低声音问。

"要去。"

"万一是陷阱呢？"

"所以我不会一个人去。"我看了看手表，"马队那边我已经说过了，他会安排人在老图书馆附近待命。我负责进去，他们负责外围。"

林琳点了点头，但还是不放心："小雨，我总觉得这件事没那么简单。那条短信……"

"我也有同样的感觉。"我说，"但不管怎样，这是一条线索。我们不能放过任何可能性。"

下午两点四十分，我来到了老图书馆附近。

这栋建筑已经被封锁了将近两周，黄色的警戒线还围在周围，门口贴着"危险建筑，禁止入内"的告示。但警戒线已经被剪断了几处，显然有人来过。

我躲在梧桐树后面，环顾四周。几个穿着便衣的警察分散在周围，有的假装在看手机，有的在散步。马国栋在一辆停在路边的车里，通过对讲机与我保持联系。

"看到了吗？目标位置。"耳机里传来马国栋的声音。

"看到了。"我低声回答。

两点五十五分，一个人影出现在老图书馆门口。

那是一个女人。

她穿着一件深灰色的风衣，头发用一条丝巾包着，戴着一副大框墨镜。她站在门口，左右张望了一会儿，然后从口袋里掏出手机，看了看时间。

我的手机震动了一下——是那条匿名号码发来的消息："我到了。"

我深吸一口气，从梧桐树后面走了出来。

她看到我，身体明显僵了一下。然后她摘下墨镜，露出一张我从未见过但又莫名熟悉的脸。

四十岁左右的年纪，保养得很好，但眼角的细纹和微微发青的眼圈出卖了她——她很久没有好好睡过了。

"你是张小雨？"她的声音有些沙哑。

"是。你是？"

她犹豫了一下，然后说："我叫沈亦寒。"

我的心猛地跳了一下。

沈亦寒。周建平的妻子。

我努力控制住自己的表情，不让她看出我的震惊。但脑海中已经飞速运转起来——周建平的妻子为什么要约我见面？她知道些什么？还是她来替周建平试探我？

"你看起来很惊讶。"她淡淡地笑了笑，那笑容里有一种说不清的苦涩。

"确实有些意外。"我选择了一个中性的措辞。

"我们换个地方说话。"她看了看周围，"这里不安全。"

"去哪里？"

"前面那条巷子有一家茶馆，很安静。"

我点了点头，同时对耳机轻声说："马队，她叫沈亦寒，周建平的妻子。她要去前面巷子里的茶馆。"

"收到。我们跟着。保持距离。"

茶馆确实很安静。下午三点多，几乎没有什么客人。老板是个上了年纪的老人，给我们泡了一壶碧螺春就自顾自地去了柜台后面打瞌睡。

沈亦寒坐在我对面，双手捧着一杯茶，但并没有喝。她低着头，似乎在组织语言。

我等了一会儿，没有催促她。

"你知道我为什么找你吗？"她终于开口了。

"我猜不到。"

她抬起头，直视着我的眼睛。那是一双很美的眼睛，但此刻布满了血丝，像两颗蒙了尘的红宝石。

"因为我不想再这样活下去了。"

她的声音很轻，但每个字都像是从胸腔深处硬生生挖出来的。

"张小雨，我嫁给周建平十五年了。十五年前，他是我心目中的英雄——白手起家，年轻有为，对我温柔体贴。我以为我嫁给了爱情。"

她停顿了一下，嘴角泛起一丝自嘲的笑。

"但婚后第三年，我第一次发现他不对劲。他经常半夜接电话，然后出门。他的车上有不属于我的香水味。他的银行账户有大额的不明转账。我开始怀疑他外面有人。"

"后来呢？"

"后来我查了。"她的声音变得更低，"我请了私家侦探跟踪他。结果发现，他不是什么出轨——他在外面做的事情，比出轨可怕一万倍。"

我的心沉了下去。

"你知道他做了什么？"

沈亦寒从随身的包里拿出一个信封，推到我面前。

"这里面是我这些年收集的一些东西。银行流水、通话记录、还有一些……照片。"

我没有急着打开信封，而是看着她："你收集了这么多年，为什么不报警？"

她的眼神瞬间变得痛苦起来。

"因为我不敢。"她的声音开始颤抖，"你知道周建平是什么样的人吗？他不是一个普通的罪犯。他是一个控制狂。他控制着我的一切——我的朋友、我的家人、我的社交、我的一切经济来源。如果我敢背叛他，他会让我生不如死。"

"但你还是来了。"

"是的，我还是来了。"她深吸一口气，"因为有些事情，比生不如死更可怕。"

"什么事？"

她沉默了很久。茶馆里只有老式挂钟的滴答声，每一秒都像是在倒计时。

"张小雨，你知道周建平为什么那么自信吗？为什么他觉得自己可以控制一切？"

"为什么？"

"因为他有一个保险箱。"

我的注意力瞬间集中起来。

"什么保险箱？"

"在他别墅的地下室里。"沈亦寒说，"那个保险箱是特制的，从德国进口的，密码加指纹双重锁定。他从来不让我靠近那个房间。结婚十五年，我只进去过一次——那是我们结婚第一年，他喝醉了，无意中提到了那个房间。我好奇，趁他睡着偷偷进去看了一眼。"

"你看到了什么？"

"保险箱很大，半人高，嵌在墙里。但我没有密码，也没有打开。我只是看了一眼就出来了。但第二天，他发现有人进过那个房间——虽然我没有碰任何东西，但他就是知道了。他勃然大怒，那是他第一次打我。"

她下意识地摸了摸自己的脸颊，仿佛那一巴掌的疼痛穿越了十五年的时光，依然清晰。

"从那以后，我再也没有靠近过那个房间。但他每个月都会进去一次，有时候会待很长时间。有一次我半夜醒来，听到地下室传来奇怪的声音——像是在哭，又像是在笑。"

"你觉得保险箱里有什么？"

沈亦寒看着我，眼神变得异常认真。

"我不知道确切的内容。但根据我这些年对他的观察，那个保险箱里装的是他最重要的东西。比钱重要，比权力重要。那是他的……"

她搜索着合适的词语。

"那是他的'灵魂'。"

这个比喻让我不寒而栗。

"你怀疑里面有什么？"

"日记。"她说，"他有写日记的习惯。年轻时候他就写，后来做了生意还在写。他曾经跟我说过一句话——'人最大的敌人是自己的记忆，所以要把一切都记下来。'当时我觉得他说得有道理，现在回想起来……"

"一个把自己的罪行记录下来的人。"我接上了她的话。

"对。"她点了点头，"一个自恋到极点的人。他觉得自己永远不会被抓，所以他敢把一切都写下来。他享受那种'掌控一切'的感觉，包括掌控自己的犯罪记录。"

我沉默了。

如果沈亦寒说的是真的，那这个保险箱里的东西将是整个案件的关键——周建平自己的犯罪记录。

"你为什么现在告诉我这些？"我问，"你刚才说，你不敢背叛他。"

沈亦寒的眼眶红了。

"因为昨天，他跟我说了一句话。"

"什么话？"

"他说：'亦寒，如果有一天事情败露了，你就是我的替罪羊。所有的罪名都会落到你头上。你信不信？'"

她的泪水终于滑落下来。

"他不是在威胁我。他是在陈述一个事实。他有这个能力。他可以伪造证据，可以买通证人，可以把所有的罪名都推到我身上。而我……我没有任何自保的手段。"

"所以你选择先出手。"

"是的。"她擦了擦眼泪，"与其坐以待毙，不如主动出击。我帮你们找到保险箱，你们帮我换取法律保护。这是我的条件。"

我看着她，心中五味杂陈。

这个女人，在周建平身边生活了十五年，被控制、被威胁、被打骂，但她并没有完全被打垮。在最关键的时刻，她选择了反抗。这需要巨大的勇气。

"我不能代表警方给你承诺。"我诚实地说，"但我可以保证，你的配合会被记录在案。在法律上，主动提供关键证据的证人，会得到相应的保护。"

她点了点头，似乎对我的回答很满意。

"还有一件事。"她从包里又拿出一样东西——一把钥匙。

"这是什么？"

"别墅的备用钥匙。"她说，"周建平有两套钥匙，一套随身携带，一套放在书房抽屉里。我趁他不注意，偷偷配了一把。地下室的门也需要钥匙才能打开。"

我接过钥匙，感受到金属的冰凉。

"沈女士，"我认真地说，"你知道你在做什么吗？一旦你交出这些东西，就再也没有回头路了。周建平会知道是你。"

"我知道。"她的声音反而平静了下来，"我已经没有回头路了。从嫁给他那天起，我就走上了一条不归路。现在，我只是选择了另一个方向。"

她站起来，把风衣的领子竖起来。

"张小雨，还有一件事我要提醒你。"她走到茶馆门口，突然回过头来，"周建平很危险。不是那种拿着刀追你的危险，而是那种让你身边的人一个个消失的危险。你要小心。不只是小心他，还要小心他身边的人。"

"你指的是谁？"

她没有回答，只是深深地看了我一眼，然后转身走进了巷子里。

我坐在茶馆里，看着她的背影消失在转角处。阳光从窗户照进来，落在桌上那个信封上。

我打开信封，里面是一叠整理得整整齐齐的文件——银行流水、通话记录、几张模糊的照片。照片上是周建平与一些我不认识的人在某个场所会面。

这些材料虽然不能直接证明周建平的罪行，但它们勾勒出了一张复杂的关系网——周建平这些年到底在经营着什么。

我拿起手机，拨通了马国栋的电话。

"马队，我有一个重大发现。"

"说。"

"周建平的别墅里有一个保险箱。他的妻子沈亦寒愿意配合警方找到它。"

电话那头沉默了几秒钟。然后马国栋说："你确定这个消息可靠？"

"我确定。她现在有充分的动机背叛周建平——周建平威胁要让她当替罪羊。"

"好。我立刻向督察组汇报。如果情况属实，我们今晚就申请搜查令。"

挂了电话，我长长地呼出一口气。

事情正在起变化。周建平的反击虽然凶猛，但他忽略了一个致命的变量——他身边的人。他以为可以用恐惧控制所有人，但恐惧是一把双刃剑。当恐惧达到极限时，它就不再是枷锁，而是炸药。

沈亦寒就是那颗被点燃的炸药。

走出茶馆时，阳光已经变得柔和了。三月底的沧阳市，春天终于有了一点温暖的意思。梧桐树上冒出了更多的新芽，嫩绿色的，在微风中轻轻摇曳。

我走在回学校的路上，脑海中不断回放着沈亦寒的话。

"你要小心。不只是小心他，还要小心他身边的人。"

她说的"他身边的人"是谁？是指周建平的手下？还是指某个我还没有意识到的人？

还是说——她指的是我身边的某个人？

一阵冷风吹过，我不由得打了个寒颤。

回到宿舍，林琳正在等我。我把和沈亦寒见面的经过告诉了她。她听完后，沉默了很久。

"小雨，你觉得她说的是真的吗？关于保险箱的事。"

"我觉得是真的。"我说，"她的恐惧是真实的。一个被恐惧逼到绝路的人，不会在这种时候撒谎。"

"那如果保险箱里真的有周建平的日记……"

"那就是一切的关键。"

我们对视了一眼，都从对方眼中看到了同样的东西——希望。

但希望的另一面，是更大的危险。

因为从这一刻起，周建平将不再只是对付我和林琳。他会把矛头对准沈亦寒。

而一个被逼到绝路的周建平，会比任何时候都更加危险。

那天晚上，我收到了马国栋的消息：搜查令已经获批。明天一早，警方将对周建平的别墅进行搜查。

我放下手机，望着窗外的夜空。月亮被云层遮住了，只有几颗星星在远处闪烁。

明天。

一切将在明天揭晓。

我闭上眼睛，心中默念：方苒，如果你在天有灵，请保佑我们。这一次，不要再让真相被掩埋了。
