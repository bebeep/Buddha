# 第八十七章 逮捕

四月二日，清晨。

我站在沧澜大学的梧桐大道上，看着几辆警车从校门口驶入。

警车的警灯没有闪，也没有鸣笛。它们安静地行驶在清晨的校园里，像一群沉默的猎手。车窗上映着初升的朝阳，金色的光芒在车身上流淌。

阳光透过梧桐树的枝叶洒下来，斑驳的光影落在我身上。那些光影在我脸上、身上、手上跳跃着，像是一场无声的电影。

我想起了入学第一天的那个下午。

去年九月，我拖着行李箱，站在这条梧桐大道的尽头。阳光也是这样的——透过树叶洒下来，在地上画出一片片金色的光斑。那时候的我还不知道，这条看似普通的校园道路，将引领我走进一个怎样的深渊。

那时候的我还不知道方驰，不知道林琳，不知道方苒，不知道周建平。

那时候的我只是一个十八岁的少年，带着对大学生活的憧憬和对未来的期待，踏入了沧澜大学的校门。

而现在，我站在这里，看着警车驶向一个亿万富翁的别墅，去执行一张逮捕令。

一年。

仅仅一年的时间，我的生活被彻底改变了。

"小雨。"

林琳的声音从身后传来。我转过头，看到她穿着那件我熟悉的白色卫衣，头发扎成了马尾。她的脸色有些苍白，但眼神坚定。

"你确定要去？"她问。

"确定。"

"我跟你一起。"

我摇了摇头："你留在学校。如果事情有什么变化，我需要有人跟马队联系。"

她犹豫了一下，然后点了点头。

"小心。"她说。

"你也是。"

我走向警车，拉开车门坐了进去。马国栋坐在驾驶座上，旁边是一个我不认识的便衣警察——督察组的人。

"准备好了？"马国栋问。

"准备好了。"

"按照计划，我们先到别墅。周建平目前还在'协助调查'阶段，但督察组已经拿到了正式的逮捕令。到了那里，我们会宣读逮捕令，然后把他带走。"

"他会反抗吗？"

马国栋冷笑了一下："周建平这种人，不会用蛮力反抗。他会用法律——他的律师团队会在第一时间出现。但逮捕令是检察院签发的，他的律师再厉害，也拦不住。"

警车驶出了校园，拐上了通往东郊的公路。

我透过车窗看着外面的城市。四月的沧阳市，到处都是春天的气息。路边的花坛里开满了各种颜色的花——红色的月季、黄色的迎春、紫色的丁香。行人穿着轻便的衣服，在人行道上悠闲地走着。

没有人知道，在这座城市的某个角落，一场正义的审判即将开始。

二十分钟后，我们到达了周建平的别墅。

别墅门口已经停了好几辆车。除了之前见过的警车，还有几辆不起眼的黑色轿车——那是督察组和检察院的人。

沈亦寒站在警戒线外面，身边有两个女警陪着。她看到我，微微点了点头。她的表情很平静——一种做出了重大决定之后才会有的平静。

马国栋下了车，跟在场的人简短地交流了几句，然后向我招了招手。

"走吧。"

我们走进别墅。

客厅里，周建平坐在沙发上。

他穿着一件深蓝色的睡衣，头发有些凌乱，但坐姿依然端正。他的面前放着一杯茶，茶水已经凉了——从杯壁上凝固的水渍来看，他至少在这里坐了一个小时。

他的律师陈文渊坐在他旁边，正在低声说着什么。看到我走进来，陈文渊抬起了头，眼神锐利如刀。

"马队长，"陈文渊站了起来，"我的当事人是配合调查的证人，不是嫌疑人。你们有什么权力——"

"陈律师，"马国栋打断了他，从口袋里拿出一份文件，"这是沧阳市人民检察院签发的逮捕令。周建平涉嫌故意杀人罪、强奸罪，现依法对其实施逮捕。"

客厅里瞬间安静了。

周建平抬起头，看着马国栋手中的逮捕令。他的表情没有变化——没有震惊，没有愤怒，没有恐惧。他只是静静地看着，像是在看一份普通的商业文件。

然后他笑了。

那个笑容让我脊背发凉。

"周建平，"马国栋的声音庄严而冷静，"根据《中华人民共和国刑事诉讼法》相关规定，你现在因涉嫌故意杀人罪、强奸罪被依法逮捕。你有权保持沉默，你所说的每一句话都将作为呈堂证供。你有权聘请律师——"

"我知道我的权利。"周建平平静地说。

他站起来，整了整睡衣的领子。然后他看向陈文渊："陈律师，接下来就看你的了。"

陈文渊的表情很严肃。他点了点头，没有说话。

两个警察走上前，给周建平戴上了手铐。金属碰撞的声音在客厅里回荡，清脆而冰冷。

周建平低头看了看手铐，然后抬起头，目光越过所有人，落在了我的身上。

那一刻，我们的目光交汇了。

他的眼神里没有恨意，没有威胁，甚至没有愤怒。只有一种……审视。像是在重新评估一个他曾经判定为"不足为虑"的对手。

"张小雨。"他叫了我的名字。

"是我。"

"你赢了这一局。"

"不是我赢了。"我说，"是真相赢了。"

他微微一笑："真相？年轻人，你以为你找到了真相？你找到的只是我让你找到的东西。"

这句话像一根刺，扎进了我的心里。

但我没有让它在脸上表现出来。

"是不是，法庭上见。"我说。

他被带走了。

走出别墅的时候，阳光正好。四月的阳光温暖而明亮，照在身上有一种让人昏昏欲睡的慵懒。但此刻，没有任何人感到轻松。

周建平被送进了一辆警车。车门关上的那一刻，我看到他透过车窗最后看了一眼自己的别墅——那栋他花了数千万打造的白色宫殿。

然后警车启动了，缓缓驶离。

我站在别墅的院子里，看着警车消失在公路尽头。

结束了吗？

不，还没有。

逮捕只是开始。真正的战斗在法庭上。

"张小雨。"

一个声音从身后传来。我转过身，看到一个穿着深色西装的中年男人。他戴着金丝眼镜，头发梳得一丝不苟，整个人散发着一种精英气质。

"我是省厅督察组的组长，李卫国。"他伸出手。

我握了握他的手："李组长。"

"你做的事情，我们都看在眼里。"他的声音低沉而有力，"你整理的那份案件分析报告，对我们的工作帮助很大。"

"我只是做了应该做的事。"

"不，"他摇了摇头，"很多人应该做的事，没有人去做。你做了。这很不容易。"

他顿了顿，然后说："还有一件事——你父亲张建国，今天也会被传唤。他需要配合调查。"

"我知道。"

"你还好吗？"

我想了想："还好。"

他点了点头，没有多说什么，转身走向了督察组的车。

我站在院子里，看着一辆辆车驶离。最后，只剩下我和几个负责收尾的警察。

"该回去了。"马国栋走到我身边，拍了拍我的肩膀，"今天的事情，你做得很好。"

"马队，"我叫住了他，"我能去看方驰吗？"

他看了我一眼："等逮捕的消息正式公布之后。我帮你安排。"

"谢谢。"

回到学校的时候，已经是中午了。

林琳在校门口等我。看到我下车，她快步走了过来。

"怎么样？"

"逮捕了。"

她长长地呼出一口气，像是放下了一个背负了很久的包袱。

"然后呢？"

"然后是审判。"我说，"案件会移交给检察院，然后起诉，然后开庭。这个过程可能需要几个月。"

"几个月……"

"是的。但最关键的部分已经完成了。证据确凿，嫌疑人归案。剩下的就是法律程序了。"

我们走在回宿舍的路上。梧桐大道上的树叶比刚入学时茂密了许多，阳光透过层层叠叠的绿叶，在地上洒下细碎的光斑。

"小雨，"林琳突然说，"你有没有想过，这一切结束之后，你要做什么？"

我愣了一下。

做什么？

这个问题我从来没有认真想过。从入学到现在，我的生活被案件填满了——调查、推理、冒险、挣扎。我几乎没有时间思考"之后"的事情。

"还没想过。"我诚实地说。

"也许你应该想想。"她微笑着说，"你才十八岁。人生还很长。"

十八岁。

是的，我十八岁。一个普通的十八岁大学生，应该操心的是期末考试、社团活动、实习机会。而不是连环杀人案和十二年前的冤案。

但生活没有给我选择的余地。

"你呢？"我问她，"你想做什么？"

"我想当律师。"她说，"一个真正的律师。不是陈文渊那种替坏人脱罪的律师，而是帮助受害者讨回公道的律师。"

"很好的理想。"

"你不觉得太天真吗？"

"不。"我摇了摇头，"天真的不是理想，是那些认为理想不可能实现的人。"

她看着我，眼睛亮了起来。

然后她笑了。那个笑容在四月的阳光下显得格外灿烂，像是一朵刚刚绽放的花。

那一刻，我突然觉得，也许这一切都是值得的。

不是因为结果，而是因为在这个过程中，我遇到了值得守护的人，找到了值得坚持的事。

但我知道，在审判到来之前，还有最后一件事要做。

我要去看方驰。

我要去告诉他——周建平被捕了。真相即将大白。

他等了这么久，终于等到了这一天。
