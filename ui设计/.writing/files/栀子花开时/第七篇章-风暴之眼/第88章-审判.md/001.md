# 第八十八章 审判

五月十五日，沧阳市中级人民法院。

我坐在旁听席的第三排，手里攥着一支笔和一个笔记本。笔尖在纸上留下了一串串无意义的线条——那不是文字，只是紧张情绪的发泄。

法庭比我想象的要大。高大的穹顶下，国徽悬挂在正中央，庄严而肃穆。审判台上方是"沧阳市中级人民法院"的烫金大字，在灯光下熠熠生辉。

旁听席几乎坐满了人。媒体记者、法律界人士、沧澜大学的师生代表，还有一些我不认识的普通市民。这个案件在过去一个多月里持续发酵，已经从一桩地方案件演变成了全国关注的焦点。

周建平的律师陈文渊果然没有让人失望。他坐在辩护席上，西装笔挺，神态从容，像一位即将上场的指挥家。

公诉席上坐着省检察院的两位检察官——主诉检察官叫刘志明，四十多岁，面容刚毅，据说曾办理过多起重大案件。

九点整，审判长宣布开庭。

全场起立。

审判长宣读起诉书的声音在法庭里回荡，每一个字都清晰而有力。

"……被告人周建平，男，1983年生，沧阳市建辉实业集团有限公司董事长。因涉嫌故意杀人罪（四起）、强奸罪，经沧阳市人民检察院提起公诉……"

周建平站在被告席上。他穿了一件深灰色的囚服，头发剃短了，但整个人的气质依然与普通囚犯不同。他的背挺得很直，目光平静，甚至在起诉书宣读到他名字的时候，嘴角还微微上扬了一下。

那种表情让我想起了日记里的那句话——"掌控一切"。

即使站在被告席上，他依然觉得自己掌控着一切。

起诉书的內容我已经烂熟于心——

第一项指控：2008年6月15日，被告人周建平在沧澜大学校园内，对被害人方苒实施强奸，导致方苒死亡。

第二项指控：2023年9月16日，被告人周建平在沧澜大学旧图书馆内，故意杀害被害人王国强。

第三项指控：2023年10月8日，被告人周建平在沧澜大学化学楼实验室内，故意杀害被害人陈向晚。

第四项指控：2023年12月10日，被告人周建平在沧阳市滨河区某公园内，故意杀害被害人的马玉芬。

第五项指控：2023年12月20日，被告人周建平在其公司办公室内，故意杀害被害人赵德厚。

五项指控。四条人命（方苒案为强奸致死）。一起强奸。

时间跨度十五年。

法庭里安静得能听到空调的嗡嗡声。

公诉人刘志明开始陈述案情。他的声音沉稳有力，逻辑清晰，将十五年前的方苒事件到去年的四起命案，串联成了一条完整的证据链。

"审判长、审判员，本案的证据包括：第一，被告人周建平的亲笔日记，详细记录了其犯罪行为的全过程；第二，被告人妻子沈亦寒提供的银行流水、通话记录等旁证材料；第三，法医鉴定报告，确认了各被害人的死因与被告人的供述一致；第四，现场勘查报告及物证鉴定；第五，多名证人的证言……"

他每念一条证据，我都感觉心里的一块石头落下一分。证据链是完整的，无懈可击的。

然后，陈文渊开始辩护。

他的辩护策略完全在我的意料之中——他没有否认案件本身，而是试图从证据的合法性入手，动摇整个案件的基础。

"审判长，辩护人对公诉机关指控的部分事实没有异议。但辩护人需要指出的是，本案的关键证据——所谓'被告人的日记'——其获取过程存在严重的程序瑕疵。"

他站了起来，走到法庭中央。

"第一，该日记的搜查虽然持有搜查令，但搜查令的范围是'周建平别墅内的所有物品'。辩护人要问——一本私人日记，是否属于'物品'的范畴？日记属于公民的隐私权保护范围，对其进行搜查和扣押需要更加严格的法律程序。"

"第二，日记的真实性存疑。一本没有任何第三方认证的私人笔记本，任何人都可以在上面写下任何内容。辩护人不能排除这本日记是他人伪造的可能性。"

"第三，关于被告人的供述——日记中的内容不等于被告人的当庭供述。被告人在日记中写下的文字，可能出于多种目的，包括文学创作、心理宣泄等。不能简单地将其等同于犯罪自白。"

陈文渊的辩护精彩而犀利。每一个论点都切中了法律的要害。我不得不承认，这是一个真正的高手。

但我并不担心。

因为公诉人刘志明显然也预料到了这些论点。

"关于辩护人提出的第一点，"刘志明站了起来，"搜查令的合法性已经在庭前会议中得到了确认。搜查令明确授权搜查'与案件相关的一切物品和文件'。日记作为记录犯罪行为的物证，属于搜查范围。"

"关于第二点，日记的真实性将通过笔迹鉴定予以确认。我们已经委托了国家级鉴定机构对日记的笔迹、墨水、纸张进行了全面鉴定。鉴定结果表明，日记的所有页面均为同一人所写，书写时间与日记标注的日期一致。"

"关于第三点，日记中的内容并非孤证。日记中记录的犯罪细节与法医鉴定、现场勘查、证人证言等多项证据高度吻合。这种程度的吻合，不可能是伪造的。"

法庭上的交锋持续了整整一周。

每一天都是一场智力的角斗。陈文渊试图在证据链中找到哪怕一个微小的裂缝，而刘志明则用铁一般的事实将这个裂缝一一封堵。

作为案件的"民间调查员"，我被允许在旁听席上旁听，但不能参与庭审。我只能看着，听着，在笔记本上记录着。

第二周的周三，法庭传召了关键证人——沈亦寒。

她走上证人席的时候，整个法庭都安静了。

她比上次见面时瘦了很多，但精神状态反而好了。她穿着一件素色的衣服，头发整齐地扎在脑后，脸上没有化妆。

刘志明开始询问。

"沈女士，请你向法庭描述一下，你是何时、如何发现你丈夫的保险箱的。"

沈亦寒的声音清晰而稳定。她讲述了十五年的婚姻生活，讲述了那个地下室的秘密，讲述了周建平的威胁和控制。

"你为什么要背叛你的丈夫？"陈文渊在交叉询问中问道。

"我没有背叛他。"沈亦寒平静地说，"是他先背叛了我们的婚姻，背叛了法律，背叛了所有他伤害过的人。我只是选择了不再沉默。"

"你是否与张小雨等人串通，故意构陷你的丈夫？"

"没有。"

"那你为什么在结婚十五年后突然选择站出来？是不是因为你们的婚姻出现了问题，你想通过这种方式报复他？"

沈亦寒沉默了几秒钟。然后她说："陈律师，我在这个法庭上说的每一句话都是事实。我的动机是什么并不重要。重要的是——那些被害人是真实存在的。方苒、王国强、陈向晚、马玉芬、赵德厚——他们是真实的人。他们死了。而杀死他们的人，就站在那个被告席上。"

她的声音在最后微微颤抖了一下，但很快就恢复了平静。

旁听席上有人低声抽泣。

审判继续。

第二周的周五，法庭传召了另一个关键证人——方苒的母亲。

她是一个五十多岁的农村妇女，穿着一件洗得发白的蓝色外套，头发花白，背微微驼着。她走上证人席的时候，脚步蹒跚，像是一阵随时会被风吹倒的枯草。

法庭里安静得可怕。

"请您向法庭描述一下，2008年您接到学校通知时的情形。"刘志明的声音比平时柔和了许多。

"那天……"她的声音沙哑而颤抖，"我正在地里干活。村长跑来告诉我，说学校来了电话。我跑到村委会接电话，学校的人告诉我，我女儿……我女儿死了。"

她停顿了一下，用手背擦了擦眼角。

"他们说她是自杀。我不信。我的苒苒不会自杀。她从小性格坚强，成绩又好，马上就要考大学了。她为什么要自杀？"

"后来呢？"

"后来我去学校。他们给了我一些钱，说是什么'人道主义补偿'。我不要钱，我要见我女儿。他们不让我看。他们说……他们说遗体已经火化了。"

她的声音越来越高，越来越尖锐。

"我连女儿最后一面都没见到！我连她的遗体都没看到！他们就告诉我，她是自杀，让我签字，让我拿钱走人！"

法庭里响起了低低的哭泣声。

"后来呢？"刘志明等了一会儿，才继续问。

"后来我回了家。但我没有放弃。这些年，我一直在打听。我去过学校，去过公安局，去过信访办。没有人理我。他们都说'案子已经结了'。可是我不信。一个母亲不相信自己的女儿会自杀。"

"直到去年，有人告诉我，有人在调查我女儿的死。"

她看向了我。

那一刻，我的眼眶热了。

"张小雨。"她叫了我的名字，"谢谢你。谢谢你没有忘记我的苒苒。"

我低下头，泪水无声地滑落。

审判还在继续。

但在那一刻，法庭上的一切——法律的辩论、证据的交锋、程序的博弈——都变得不那么重要了。

重要的是，一个母亲终于有机会在法庭上为她死去的女儿说话。

重要的是，十五年前被掩盖的真相，终于见了光。

重要的是，正义虽然迟到了，但它终于来了。

庭审持续了两周。最后一天的最后陈述环节，刘志明站在公诉席上，声音铿锵有力：

"审判长、审判员，本案事实清楚，证据确实充分。被告人周建平在长达十五年的时间里，实施了一系列严重的犯罪行为。他强奸了一名无辜的女大学生，导致其死亡。他为了掩盖罪行，先后杀害了四名知情者。他的犯罪手段残忍，犯罪动机卑劣，犯罪后果极其严重。

"辩护人试图从程序角度为被告人开脱，但法律不会因为程序的瑕疵就放过一个杀人犯。正义的实现需要程序的保障，但程序不是犯罪的保护伞。

"公诉人建议，对被告人周建平依法从严惩处。"

陈文渊做了最后的辩护。他的声音依然沉稳，但我听出了一丝疲惫。

"审判长，我的当事人有权获得公正的审判。无论他做了什么，法律赋予他的辩护权利不应该被剥夺。我请求法庭在量刑时，充分考虑所有的情节，做出公正的裁决。"

最后，审判长问周建平是否有最后陈述。

周建平站了起来。

他环顾了一下法庭，目光扫过公诉席、辩护席、证人席，最后落在了旁听席上——落在了我的身上。

"我没有话说。"他平静地说。

然后他坐下了。

没有忏悔，没有辩解，没有求情。

只有沉默。

审判长宣布休庭，择期宣判。

走出法庭的时候，阳光刺得我睁不开眼。五月的阳光比四月更加炽烈，照在身上有一种灼烧的感觉。

林琳在法院门口等我。

"怎么样？"她问。

"结束了。等宣判。"

"你觉得结果会是什么？"

我看了看天空。天空很蓝，蓝得没有一丝杂质。

"法律会给一个公正的结果。"我说。

但我心里知道，无论判决结果如何，有些东西是永远无法弥补的。

方苒的生命无法重来。王国强的生命无法重来。陈向晚的生命无法重来。马玉芬的生命无法重来。赵德厚的生命无法重来。

五个人的生命，永远地消逝在了时间的长河中。

法律能做的是惩罚罪犯、伸张正义。但法律不能复活死者，不能抚平伤痛，不能填补那些永远的空缺。

这是法律的局限，也是法律的尊严。

它不承诺完美，但它承诺公正。

而公正，已经是人类能做到的最好的事情了。
