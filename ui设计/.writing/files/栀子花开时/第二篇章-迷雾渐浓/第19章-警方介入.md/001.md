# 第十九章 警方介入

市公安局成立了专案组。

这个消息是周一早上通过学校官方渠道发布的。专案组由刑警支队队长马国栋亲自负责，成员包括市局刑侦大队的精干力量和分局的配合人员。公告的措辞很官方——"高度重视"、"全力侦破"、"确保校园安全"——但这些冠冕堂皇的话背后，我能读出一种紧迫。

两起命案。两个死者。两种身份——一个是学生，一个是行政管理人员。在同一所校园里，在不到一个月的时间内，先后被以相同的手法杀害。

这不是一起普通的案件。这是一起会引起社会关注的案件。

那天早上，校园里的气氛明显和以前不一样了。校门口多了两个穿便衣的警察，站在花坛旁边，目光锐利地扫视着每一个进出的人。教学楼和宿舍楼之间的主要路口也增加了巡逻的保安，两个人一组，步伐整齐，表情严肃。

食堂里的电视从平时播放新闻频道变成了循环播放学校的公告。公告的内容和官方通知差不多，但画面上反复出现的"市公安局专案组"几个字，让每一个吃饭的学生都感受到了事态的严重性。

我端着餐盘坐在食堂的角落里，一边机械地往嘴里塞着米饭，一边观察着周围人的反应。大部分学生的脸上写着三种表情——恐惧、好奇、或者麻木。恐惧的是那些胆子小的女生，她们三三两两地坐在一起，说话的声音压得很低，时不时紧张地回头看一眼。好奇的是那些男生，他们兴奋地讨论着各种猜测，像是在谈论一部悬疑电影的情节。麻木的是那些大四的学生——他们见多了世事，对这种事情已经不太容易动感情了。

马国栋。

这个名字我是在王国强死后第一次听到的。当时他负责询问我——因为我在旧图书馆附近出现过。那次问话持续了大约四十分钟，在马国栋的办公室里。他的办公室在市局三楼，一间不大的房间，桌上堆满了文件和烟灰缸。

马国栋四十多岁，身材中等，微微发福。他的脸棱角分明，皮肤被岁月和日晒打磨成了粗糙的暗褐色。头发剪得很短，几乎贴着头皮，像一层灰色的绒布。他的眼睛不大，但非常锐利——不是那种咄咄逼人的锐利，而是一种沉默的、耐心的、像猎人等待猎物一样的锐利。

他不爱笑。整个问话过程中，他的嘴角始终保持着一条直线，只有偶尔在笔记本上记录的时候，眉头会微微皱一下。

那次问话的内容很简单——我为什么去旧图书馆，什么时候去的，看到了什么，和王国强是什么关系。我如实回答了（当然隐去了调查的部分），他记录完毕后让我签了字，然后让我走了。

但现在，他来了。

带着专案组，来到了沧澜大学。

周二下午，我收到了辅导员的短信——马国栋要约谈所有与受害者有关联的人员，包括我。

"又是我？"我问辅导员，"上次不是已经问过了吗？"

辅导员是一个刚毕业两年的年轻老师，戴着厚厚的近视镜，脸上还带着学生气。他看了看我，表情有些为难。

"这次情况不一样了。"他说，"两起案件并案侦查，需要重新核实所有相关人员的情况。你配合一下。"

我点了点头。

约谈的地点安排在了法学院一楼的一间会议室里。会议室被临时改造成了专案组的工作间——桌上摆着几台笔记本电脑，墙上贴着一张校园地图，上面用红色标记标注了两个案发现场的位置。

马国栋坐在桌子的一端，面前摊着一个厚厚的笔记本。他比上次看起来更疲惫了——眼下的黑眼圈更深了，下巴上的胡茬也更密了。但他那双眼睛依然锐利，像两把没有入鞘的刀。

"张小雨，"他翻看着笔记本上的记录，"法学院大一新生。王国强案发生后，你曾作为相关人员接受过询问。"

"是。"

"王建国案发生后，你又出现在了案发现场附近。"

"我住在附近的小礼堂方向的宿舍楼。"我说，"早上听到动静出来看的。"

"嗯。"他不置可否地应了一声，"张小雨，我有一个问题想问你。"

"请说。"

"你为什么对这两起案子这么上心？"

他抬起头，目光直直地看着我。那种目光不是质问，而是一种审视——像是在用X光扫描我的每一个毛孔。

"我是法学专业的学生，"我说，"对刑事案件有天然的 curiosity——"

"curiosity？"他挑了挑眉毛，"你还会用英文词。"

"习惯。"

"嗯。"他低下头，在笔记本上写了几个字。然后又说，"好奇心不要太重。这不是你们学生该掺和的事。"

"我没有掺和。"

"没有？"他从桌上的文件堆里抽出一张纸，"这是保卫处的巡逻记录。10月8日晚上——王国强遇害的那天——你在晚上十一点二十三分刷卡进入了旧图书馆附近的教学楼B栋。但你的宿舍在宿舍楼A栋，距离B栋有八百米。你为什么要去那里？"

我的心跳加速了。但我努力保持着镇定。

"我去B栋的自习室上晚自习。"

"上到几点？"

"大概十一点。"

"然后呢？"

"然后我出来散步。"

"散步？"马国栋的嘴角微微动了一下，不知道算不算笑，"十一点多，在旧图书馆附近散步？"

"那天晚上月亮很好。"我胡诌了一个理由。

马国栋盯着我看了很久。那种沉默比任何质问都更有压迫力——它让你自己填充那些空白，让你的想象力替你编造出最坏的可能。

"张小雨，"他终于开口了，声音低沉而平稳，"我干这行二十年了。我见过很多聪明人。聪明人有一个共同点——他们总觉得自己能比别人看得更远。但有时候，看得太远反而会掉进坑里。"

"我不明白您的意思。"

"你明白。"他说，"我的意思是——如果你知道什么，就告诉我。如果你不知道什么，就别再往那边凑了。这两起案子不是闹着玩的。凶手还在外面。"

"您认为凶手还会动手？"

他没有回答这个问题。只是合上了笔记本，站起身来。

"今天就到这里。"他说，"但我会继续关注你的。"

"为什么？"

"因为你每次都在不该出现的地方出现。"他说，"一次是巧合，两次是巧合，三次——"

他没有说下去。但我知道他想说什么。

三次就是嫌疑。

我站起身来，准备离开。走到门口的时候，马国栋忽然又开口了。

"张小雨。"

我转过身。

他坐在桌子后面，手里转着一支铅笔。那双锐利的眼睛透过镜片看着我，像是在衡量什么。

"你学过法律，"他慢慢说道，"应该知道一个道理——在法律面前，聪明不是优势，证据才是。"

"我不太明白您的意思。"

"你会明白的。"他说，然后低下头继续翻看文件，像是已经把我忘了。

我走出会议室，后背已经湿透了。

走廊里，我看到了几个正在等待约谈的人——有学生，有老师，有行政人员。他们的表情各异，有的紧张，有的茫然，有的面无表情。

我穿过走廊，走上楼梯。在一楼的拐角处，我差点和一个人撞上。

那个人穿着一件深蓝色的风衣，戴着一副细框眼镜，手里抱着几本书。她看起来二十三四岁的样子，长发披肩，五官清秀但算不上出众。她身上有一种安静的气质——不是内向的那种安静，而是一种经历了某些事情之后沉淀下来的安静。

"对不起。"她说，声音很轻。

"没事。"我说。

她匆匆走下了楼梯。我回头看了一眼她的背影——她走进了会议室，也就是专案组的临时工作间。

陈向晚。

我认出了她。虽然我之前没有见过她本人，但我在法学院的网站上看到过她的照片——赵德厚的研究生，法学方向的优秀学生。

她也被约谈了。

我站在楼梯口，看着会议室的门关上。

马国栋在调查过程中走访了赵德厚——这是我知道的。现在他又约谈了陈向晚。这意味着警方的调查范围正在扩大，从受害者的人际关系向外延伸。

这是好事。

但也是坏事。

好事是因为警方的资源远超过我们三个学生。他们有能力调取监控、查验DNA、分析通讯记录——这些都是我们做不到的。

坏事是因为——如果警方的调查触及了某些人不想被触及的角落，那些人的反应可能会变得更加激烈。

而更加激烈的反应，意味着更加危险的局面。

我走出法学院大楼的时候，看到了方驰。他站在楼门口的花坛旁边，手里拿着一瓶矿泉水，看起来像是在等人。

"被约谈了？"他问。

"嗯。"

"问了你什么？"

"老问题。为什么出现在案发现场附近。"

"你怎么说的？"

"散步。"

方驰笑了一下。"马国栋信了吗？"

"你觉得呢？"

"他当然不信。"方驰拧开瓶盖喝了一口水，"但他没有证据。只要他没有证据，他就只能警告你，不能拿你怎么样。"

"你也被约谈了？"

"没有。我是后勤处的志愿者，和王建国没什么直接关系。但他在调查过程中问了一些关于校刊编辑部的问题——主要是关于王国强的。"

"他问了什么？"

"王国强最近在做什么选题，有没有和人发生过矛盾，有没有什么反常的举动。"方驰说，"我都照实说了。"

"你说了多少？"

"该说的说了，不该说的没说。"他看了我一眼，"你放心，我没有提我们的调查。"

我点了点头。

"不过有一件事挺有意思。"方驰说。

"什么？"

"马国栋在问话的时候，特别问了一句——'王国强有没有提过方苒这个名字？'"

我的心猛地一缩。

"警方也知道方苒了？"

"看来是。"方驰的表情变得凝重，"这意味着他们查到的东西比我们想象的多。"

"或者——"我慢慢说道，"意味着有人把方苒的事告诉了警方。"

"谁会？"

"不知道。但如果有人主动把方苒的名字提供给警方，那这个人的目的就很明确了——他想让警方把两起案件和方苒联系起来。"

"为什么？"

"因为如果警方知道了方苒的存在，他们就会去查方苒的事。而方苒的事一旦浮出水面——"

"当年掩盖真相的人就暴露了。"方驰接上了我的话。

我们对视了一眼。

"你是说——有人故意借凶手的刀，来揭开当年的真相？"

"这只是一种可能。"我说，"另一种可能是——凶手本人就是在为方苒复仇。而那个把方苒的名字透露给警方的人，可能是凶手的同伙。"

"或者——是同一个人。"方驰说。

这个想法让我不寒而栗。

如果凶手和"爆料者"是同一个人——那这个人的计划就远比我们想象的精密。他不仅在杀人，还在操控整个事件的走向。他杀了王国强，杀了王建国，然后又把方苒的名字推到了警方面前——

他在下一盘很大的棋。

而我们，只是棋盘上的几颗棋子。

那天晚上，我在宿舍里给林琳发了一条短信。用的是我们新约定的暗语——"图书馆"代表案件，"书"代表线索，"还书"代表结束调查。

"马国栋约谈了我。他知道我们出现在案发现场附近。另外，他也知道了'方苒'这个名字。"

林琳的回复来得很快："他也约谈了陈向晚。我在窗外看到了。"

"你觉得警方能查出什么？"

"他们会查到赵德厚。"她说，"只是时间问题。"

"然后呢？"

"然后就看赵德厚会不会说了。"

"他不会说的。"

"不一定。"林琳说，"当压力足够大的时候，每个人都会做出不同的选择。"

我放下手机，躺在床上。

徐浩然已经睡了，床头灯关了，整个宿舍陷入了黑暗。只有方驰的床上传来轻微的响动——他还在翻来覆去，没有入睡。

"方驰，"我低声说，"你睡了吗？"

"没有。"他的声音从黑暗中传来。

"你在想什么？"

沉默。然后他说："在想马国栋。"

"为什么？"

"因为他是一个变量。"方驰说，"我们的调查是按照我们自己的节奏在进行的。但警方的介入打乱了这个节奏。现在多了一股力量——一股我们控制不了的力量——在介入这件事。"

"你不觉得这是好事吗？警方有资源，有能力——"

"是好事，也是坏事。"他说，"警方的介入意味着事情会变得更公开。而有些事情，一旦公开了，就收不回来了。"

"你到底在担心什么？"

方驰沉默了很久。

"我在担心，"他终于说，声音轻得几乎听不见，"真相出来之后，没有人能全身而退。"

他说完这句话，就不再说话了。

我听着他的呼吸声在黑暗中起伏，心里有一种说不清的感觉。

方驰。

你到底知道什么？

你到底在害怕什么？

窗外的风在呜咽，像是一个失去方向的孩子在黑暗中哭泣。

远处的校园广播站正在播放一首老歌——是朴树的《那些花儿》。

"那些花儿，在哪里呢？她们已经被风吹走，散落在天涯……"

歌声在夜风中飘荡，穿过窗户的缝隙，落在我的耳边。

那些花儿。

方苒。

你也是那些花儿中的一朵吗？

你在哪里？

你——真的已经消失了吗？

还是说，你一直就在我们身边，只是我们还没有认出你来？
