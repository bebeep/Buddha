# 第三章 旧图书馆

开学第二周的周三下午，我只有一节课，结束后离晚饭还有两个小时。

方驰去了辩论社的新人培训，徐浩然泡在新图书馆的自习室里——新图书馆是前几年刚建成的，一栋现代化的玻璃幕墙建筑，里面有空调、有电梯、有自动售货机，是沧澜大学为数不多的拿得出手的设施。

但我那天不想去新图书馆。

原因很简单：赵德厚教授在课上提到了一本参考书，是民国时期一位法学家的著作，叫做《法理探微》。他说这本书在沧澜大学图书馆有馆藏，建议有兴趣的同学去翻翻。我这个人有一个毛病——或者说习惯——一旦有人提到一本书，我就必须立刻找到它。这不是什么优点，更像是一种强迫症。

新图书馆的藏书大多是近年采购的，古籍和旧书都搬到了旧图书馆。旧图书馆在校园的西北角，一栋建于上世纪五十年代的苏式建筑，红砖外墙，拱形窗户，屋顶是灰色的水泥瓦。据说新图书馆建成之后，旧图书馆本来要改造成行政办公楼，但因为经费问题一直搁置，就这么半废弃地留着，只有少数几个研究室和特藏室还在使用。

我沿着一条长满青苔的石板路走向旧图书馆。路的两旁是高大的雪松，树冠遮天蔽日，把这条路笼罩在一片幽暗的绿色之中。空气中有一种潮湿的、带着泥土和落叶气息的味道，像是某种被遗忘的地方的呼吸。

旧图书馆的大门是一扇厚重的木门，铜制的门环已经氧化成了暗绿色。门虚掩着，我推门进去，铰链发出刺耳的嘎吱声。

门厅里光线昏暗，只有几盏应急灯还亮着，发出惨白的光。地面上铺着水磨石地板，有些地方已经碎裂了，裂缝里长出了细细的青苔。正对门的是一座旋转楼梯，铸铁的栏杆上积了厚厚的灰尘。空气中弥漫着一种陈旧纸张特有的气味——干燥、微酸、带着一丝甜，像是时间本身的味道。

一楼的阅览区已经空了，书架上的书被搬走了大半，剩下的也大多落满了灰尘。我沿着指示牌找到了法学类旧书的区域，在第三排书架上找到了赵德厚提到的那本《法理探微》。书的封面是深蓝色的布面烫金，已经褪色成了灰蓝色，但保存得还算完好。

我翻了几页，发现这本书的内容比想象中有趣得多。它不是那种枯燥的学术著作，而是用一种近乎散文的笔法来探讨法理学的基本问题。作者的文字有一种老派的优雅，每一句话都像是反复锤炼过的。

我看得入了神，不知不觉过了大约一个小时。

在这段时间里，我完全沉浸在了书的世界中。作者用一种近乎散文的笔法探讨了"法律与道德"的关系，认为法律不仅是规则体系，更是一种文明的表达。他写道："法律是人类为自己建造的牢笼，也是人类为自己点燃的灯火。它约束我们的兽性，也照亮我们的理性。"这段话让我想起了父亲说过的"控制"，但比父亲的说法更加深邃。

我在书页的空白处用铅笔做了不少标记——我从不直接在书上写字，这是父亲教我的习惯，"书是别人的朋友，你不能在朋友身上乱画。"

翻到书的最后一页时，我发现了一张夹在书页里的旧书签。那是一张泛黄的纸片，上面用钢笔写着一行字："沧澜大学图书馆藏，1986年入藏。"纸片的背面还有一行更小的字，几乎看不清了，我凑到灯下仔细辨认，勉强认出了几个字——"珍本室……二楼……"

珍本室？旧图书馆二楼有珍本室？

我把书签放回书里，把那本《法理探微》合上，放回书架上，准备找时间再去二楼看看。

直到图书馆里的灯忽然暗了一下——那是傍晚六点的自动调光，提醒人们天快黑了。

我合上书，准备离开。

那是一种很轻微的声响，从二楼传来的——像是有人在翻动什么东西，又像是有人在来回走动。声音断断续续的，夹杂在老旧建筑本身的嘎吱声和风声里，如果不是我恰好在那个瞬间安静下来，几乎不可能注意到。

我站在原地，屏住呼吸听了一会儿。

声音又出现了。确实是脚步声，很轻，但在空旷的旧图书馆里格外清晰。

我犹豫了一下。理智告诉我应该离开——一个新生，在傍晚时分独自待在一栋半废弃的建筑里，听到楼上有不明声响，正常人的反应应该是赶紧走人。但我的好奇心比理智更强。

我放轻脚步，走上了旋转楼梯。

楼梯的每一级台阶都会发出不同的声响，我不得不小心翼翼地选择落脚的位置。有些台阶踩中间会响，有些踩边缘会响，我花了大约两分钟才走完半层楼梯，速度比正常走路慢了十倍。

二楼的走廊比一楼更暗。走廊两侧是一间间的研究室和特藏室，门上大多挂着锁。应急灯在这里只有一盏还亮着，在走廊的尽头投下一个昏黄的光圈。

我沿着走廊慢慢走，脚步声被我刻意压到了最低。

声音是从走廊左侧倒数第二间房间里传出来的。

那扇门上挂着一把铜锁，但锁没有扣上，只是虚挂在锁扣上。我凑近门上的玻璃窗——那是一块巴掌大的方形玻璃，嵌在木门的上部，边缘已经开裂了——往里看。

房间里的灯亮着。

那是一间不大的研究室，大约二十平方米，四面墙上都是书架，架子上堆满了旧书和档案盒。房间中央有一张长桌，桌上散落着一些文件和纸张。

一个男生正站在书架前，背对着门，在翻找什么东西。

他穿着一件深灰色的卫衣，帽子戴在头上，身形偏瘦，个子中等偏高。他的动作很急切，一本一本地抽出书架上的书，翻看几眼，又放回去，然后继续翻下一本。他的呼吸声很重，在安静的房间里清晰可闻。

我注意到一个细节——他的手在发抖。

不是因为冷。那种抖法我认识，是紧张、焦虑、甚至是恐惧的抖法。我见过人在极度紧张时的状态，那是一种无法用意志控制的生理反应。

他在找什么？

我正准备推门进去问个究竟，那个男生忽然停下了动作。他像是感觉到了什么，猛地转过头来，目光正好对上了门上的玻璃窗。

我们的视线隔着那块脏兮兮的玻璃相遇了。

那是一张年轻的脸，大约二十岁出头，五官还算端正，但此刻因为紧张而显得有些扭曲。他的眼睛很大，瞳孔在灯光下收缩成了两个黑点，嘴唇抿成了一条线。

他看到了我。

我们都僵住了。大约持续了三秒钟——那三秒钟在我的记忆里被拉得很长，像是一段被放慢了的胶片。

然后他做了一个让我意外的举动。

他没有开门出来，而是转身走向了房间的另一端。那里有一扇窗户，窗户旁边似乎还有一扇门——一扇通往隔壁房间或者后走廊的门。他快步走过去，推开了那扇门，身影消失在了门后。

我听到了那扇门关上的声音，然后是急促的脚步声，越来越远，最后消失在建筑的深处。

我站在门外，愣了大约十秒钟。

然后我推开了那扇虚掩的门。

研究室里的灯还亮着。桌上的文件和书架上被翻乱的书都还在，但那个男生已经不见了。我走到他刚才打开的那扇门前，发现那是一扇通往后走廊的小门，门上有一个简易的门闩，从里面可以锁上，但从外面只是虚掩着。后走廊的尽头有一扇窗户，窗外是一楼的地面——大约三米高。窗户旁边的墙壁上有一根落水管，管子很粗，看起来足够结实。

他是从落水管爬下去的。

我站在后走廊里，看着那根落水管上残留的新鲜鞋印，心里涌起一种复杂的感觉。

奇怪。

太奇怪了。

一个男生，在一间锁着的房间里翻找东西，看到我之后不是出来解释，而是从后窗逃跑。这说明了什么？他在找的东西是不能被人看到的？还是说他出现在这个地方本身就是不能被人知道的？

我回到那间研究室，环顾四周。书架上的书被翻得乱七八糟，有些书甚至掉在了地上。桌上的文件我大致翻了翻，大多是一些旧报纸的剪报和复印的资料，看不出什么名堂。但我注意到桌上有一本摊开的笔记本，上面写满了密密麻麻的字，笔迹潦草，像是匆忙间记下的。

我凑近看了几行。

"……12·15……方苒……赵……掩盖……证据……王……善后……"

这些词像是某种密码，没头没尾的，我完全看不懂它们在说什么。但"方苒"这两个字引起了我的注意——这个名字听起来像是一个女生的名字。

我把笔记本放回原处，没有带走。不是因为我不想了解更多，而是因为我有一种直觉——这些东西不属于我，我还没有权利去看。

这种直觉后来被证明是对的，但也是错的。

我离开旧图书馆的时候，天已经完全黑了。校园里的路灯亮了起来，橘黄色的光线在法国梧桐的树冠下投下一个个光圈。远处传来食堂的嘈杂声和碗筷碰撞的叮当声，那是人间烟火的声音。

我走在回宿舍的路上，脑子里反复回想着刚才的场景。那个男生的脸、他颤抖的手、他逃跑时慌乱的脚步声，以及桌上笔记本里那些没头没尾的文字——这些画面像碎片一样在我的脑海里旋转，拼不成一幅完整的图画。

我决定暂时把这件事放一放。也许那个男生只是在做某种私人的研究，不想被人打扰。也许他有充分的理由从后窗逃跑——比如他违规使用了研究室，怕被管理员发现。也许一切都没有我想象的那么复杂。

但我的直觉告诉我，事情没有那么简单。

回到宿舍，方驰已经回来了，正坐在床上用笔记本电脑看视频——那是2010年流行的土豆网，缓冲速度慢得像蜗牛爬。徐浩然也回来了，坐在书桌前写字，钢笔在纸上发出沙沙的声响。

"你去哪儿了？"方驰头也不回地问。

"旧图书馆，找本书。"

"那个鬼地方？"方驰终于放弃了缓冲中的视频，转过头来，"听说那里闹鬼，你去的时候没遇到什么奇怪的事吧？"

"没有。"我说。

我犹豫了一下，没有把在旧图书馆遇到的事情告诉他们。不是因为不信任，而是因为我还没有理清头绪，不想在信息不完整的情况下做出判断。

那天晚上，我躺在床上的时候，手机震动了一下。是QQ消息。

"林间有琳"发来一条消息："你好，你是张小雨吧？赵德厚教授的课你坐第几排？"

我愣了一下，回复道："第三排。你是？"

"我坐你隔壁教室的第一排。我叫林琳。"

我看着这条消息，忽然笑了。原来她也注意到了我。

"你在旧图书馆吗？"她又发来一条消息。

"刚回来。怎么了？"

"没什么，就是想问问你觉得赵教授的课怎么样。"

"很好。他推荐了一本参考书，我去旧图书馆找了。"

"旧图书馆？那个地方有点吓人。"

"还好。"

"你一个人去的？"

"嗯。"

她过了很久才回复。我盯着屏幕上"对方正在输入"的提示，看着它出现了又消失，消失了又出现，反复了好几次。

最后她发来的是："那你要小心。"

我看着这三个字，觉得有些莫名其妙，但又觉得她说的"小心"可能不只是指旧图书馆的"闹鬼"传闻。

"你也在旧图书馆遇到过什么吗？"我试探着问。

这一次她回复得很快："没有。只是听人说过一些事。"

"什么事？"

"改天再说吧。晚安。"

然后她的头像就灰了。

我盯着手机屏幕看了很久，直到屏幕自动暗下去。窗外的蝉鸣还在继续，方驰的呼噜声已经开始了，徐浩然那边的台灯还亮着。

旧图书馆。那个男生。笔记本上的文字。

"方苒"。

这个名字像一根细小的刺，扎进了我的意识里，不痛，但无法忽视。

我闭上眼睛，在黑暗中默默地把这些碎片排列在一起。但无论我怎么排列，都拼不出一幅完整的图画。

缺少了太多太多的碎片。

而我不知道的是，那些缺失的碎片，有些已经被时间永远地抹去了。有些，还藏在某个人的心里，等待着被发掘。

那天夜里我又做了那个梦。白色的花海，栀子花的香气，以及花海尽头那个模糊的身影。

但这一次，我隐约看清了他的脸。

他的脸上有一种表情，不是恐惧，不是愤怒，而是一种绝望——一种深入骨髓的、无法挽回的绝望。

我在凌晨四点醒来，窗外的天空还是黑的。

我拿起手机，看了一眼时间，然后打开了QQ空间。

林琳的空间里多了一条新的日志，发布时间是凌晨三点五十七分——也就是三分钟前。

日志只有一句话：

"旧图书馆的灯，今晚又亮了。"

我的后背一阵发凉。
