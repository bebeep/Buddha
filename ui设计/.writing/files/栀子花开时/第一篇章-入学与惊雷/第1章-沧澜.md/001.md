# 第一章 沧澜

九月的沧阳市像一口蒸笼，热气从柏油路面升腾，扭曲了远处的天际线。

我拖着行李箱走出沧阳火车站的时候，迎面扑来的热浪让我下意识地眯起了眼睛。空气潮湿而沉重，像一块温热的湿毛巾捂在脸上。汗水几乎是在一瞬间就浸透了我的T恤后背。

站前广场上人头攒动，拉客的出租车司机举着纸板牌子，卖矿泉水的小贩推着塑料箱穿梭其间，几个穿着各大学校文化衫的迎新志愿者举着KT板在人群里搜寻目标。广场中央有一座喷泉，已经干涸了，池底积着落叶和烟头。喷泉旁边立着一块巨大的广告牌，上面是沧阳市的旅游宣传画——烟雨江南，水墨沧阳。画面上的城市诗意而朦胧，跟眼前这个嘈杂、拥挤、汗味弥漫的火车站广场判若两个世界。

我低头看了一眼手中皱巴巴的录取通知书——沧澜大学，法学院，法学专业。纸已经被汗水浸软了，边角卷起来，但上面的字迹还清晰。

这是我第一次来到沧阳。

在此之前，这座江南城市对我而言只是地图上的一枚图钉，是父亲张建国有意无意提起过的一个名字。"沧澜大学的法学很好，"他在饭桌上说过不止一次，筷子夹着一块红烧肉，目光却越过我看向某个我无法触及的地方，"你去了就知道了。"

他说这话时的语气，不像是在建议，更像是在安排。

我叫张小雨，十八岁，刚刚从北方一座工业城市的高考战场上全身而退。成绩还算体面，够得上沧澜大学的门槛。父亲说这是缘分，我觉得这更像是某种精密的计算——他这辈子做的每一件事都像是计算过的。但我没有反驳。十八年来，我已经学会了在父亲面前保持沉默。沉默不是妥协，是一种自我保护。

火车站的广播在播报列车到站信息，女声机械而疲倦。我掏出那部诺基亚6300，看了一眼时间——下午两点十五分。屏幕上有一条未读短信，是父亲发来的："到了打电话。"

三个字，没有标点。这就是张建国的风格。

我回了一条"到了"，把手机塞回裤兜，拉着行李箱汇入了站前的人流。

出租车排队处大约有二三十人在等。我排了大约二十分钟，终于坐进了一辆绿白相间的出租车。司机是个四十多岁的中年人，脖子上挂着一串佛珠，后视镜上系着一个褪了色的平安符。

"去哪儿？"他从后视镜里打量我。

"沧澜大学。"

"新生？"

"嗯。"

他点了点头，像是确认了什么似的，打了表，车子缓缓驶出火车站。

沧阳市比我想象中更旧。出租车穿过老城区的时候，我看到街道两旁种满了法国梧桐，粗壮的树干上剥落的树皮露出灰白色的内里，像某种古老的疤痕。树冠在头顶交织成一片绿色的穹顶，阳光透过层层叠叠的叶片洒下来，在路面上投下斑驳的光影。这些梧桐树至少有几十年的树龄了，枝干遒劲，根系隆起，把人行道的砖块拱得高低不平。

"这些树是民国时候种的，"司机似乎看出了我的好奇，"沧阳别的不行，就是树老。"

我没有接话，只是把脸贴在车窗上，看着这座城市在我眼前徐徐展开。老式的筒子楼和新式的玻璃幕墙交替出现，街边的小店放着那个年代流行的网络歌曲——慕容晓晓的《犯错》从一家理发店的音箱里传出来，旋律廉价而洗脑。一个穿校服的男孩骑着自行车从我窗前掠过，车后座夹着一摞书，铃铛叮叮当当地响。

一切都显得平凡而真实。

我那时候还不知道，这座城市的平静表象之下，埋藏着多少不为人知的秘密。

出租车在一条宽阔的林荫道上行驶了一段之后，司机忽然说："到了。"

我抬头望去，看见了两根粗壮的石材门柱，上面爬满了常春藤。门柱之间是一道铸铁大门，门楣上嵌着四个鎏金大字——"沧澜大学"。字体是行楷，笔力遒劲，据说是某位已故的书法大家手笔。大门后面是一条长长的甬道，两侧种满了银杏树，甬道的尽头隐约可见一栋红砖建筑的轮廓。

这就是沧澜大学了。

我付了车费，拖着行李箱下了车。九月的阳光依然毒辣，行李箱的拉杆被晒得发烫。我深吸了一口气，空气里有桂花的余香和泥土的潮气，混合着一种我说不上来的味道——后来我才知道，那是栀子花凋谢后留在空气中的最后一缕气息，虽然十月已至，某些角落里的栀子花却开得反常地迟。

校门口热闹得像集市。到处是新生和家长，拖着大包小包，脸上带着那种特有的表情——兴奋、忐忑、茫然，以及一种对未知的隐隐期待。几顶红色的迎新帐篷搭在校门内侧，上面印着各学院的名称。法学院的位置比较偏，帐篷下只坐着一个戴眼镜的学姐，百无聊赖地翻着一本杂志。

"你好，我是法学院的新生，来报到。"我把录取通知书递过去。

学姐抬眼看了看我，接过通知书核对了一下，在一张表格上勾了我的名字，然后递给我一张校园地图和一个信封。"宿舍在北区七号楼，材料在信封里，自己去办吧。"

我说了声谢谢，正准备离开，身后传来一阵嘈杂声。

我回过头，看见一个女生正跟门卫争论着什么。她个子不高，扎着马尾辫，穿一件洗得发白的蓝色T恤和牛仔裤，脚上是一双帆布鞋，鞋面上沾着泥点。她面前是两个鼓鼓囊囊的编织袋，还有一个旧款的黑色行李箱，箱角磕掉了一块漆。

"我真的是新生，录取通知书在这儿。"她的声音不大，但很坚定。

门卫是个五十多岁的大叔，脸上的表情介于不耐烦和同情之间。"姑娘，我不是不信你，但规定就是规定，得有接新生的车才能进校园，你一个人拿这么多东西……"

"我可以自己拿。"

"不是拿不拿得动的问题——"

我犹豫了一下。理智告诉我，这不关我的事。我一向不喜欢介入陌生人的事务，从小到大都是如此。但那个女生说话时的神情让我停下了脚步——她的嘴唇微微抿着，下巴抬起来的角度带着一种倔强，像是在说：我不需要帮助，但我需要公平。

我走回去，对门卫说："师傅，她是我同学，我们一起的。能不能通融一下？"

门卫看了看我，又看了看她，叹了口气："行吧行吧，进去吧。"

她转过头看了我一眼。那是一双很亮的眼睛，瞳仁是深褐色的，在阳光下几乎呈现出琥珀色。她的目光里有一丝意外，但更多的是警惕——像是习惯了不轻易接受陌生人的善意。

"谢谢。"她拎起一个编织袋，动作干脆利落。

"我帮你拿一个吧。"

"不用。"她几乎是没有犹豫地拒绝了，然后似乎觉得语气太硬，又补了一句，"我能行。"

我没有坚持。我们一前一后走进了校园。

甬道很长，两侧的银杏树还没有到变黄的季节，满树都是浓密的绿。阳光透过树叶在地面上投下细碎的光斑，随着微风轻轻晃动。远处传来广播站的声音，放的是一首老歌——老狼的《同桌的你》，旋律悠悠荡荡地在校园里飘。

她走在前面，步伐很快，编织袋的带子勒在她的肩膀上，把T恤的肩带压出一道深深的凹痕。她的行李箱有一个轮子不太灵光，在石板路上发出咯噔咯噔的声响。

走到一个岔路口的时候，她停下来，回头看了我一眼。

"法学院往哪边走？"

我展开校园地图看了看："左边，行政楼后面那栋灰色的小楼。不过宿舍在北区，要先往右走。"

"你是法学院的？"

"嗯。"

"我也是。"她说这话的时候，嘴角微微上扬了一下，算是今天第一次露出接近微笑的表情。

"那走吧，我先去宿舍放东西。"我说。

她点了点头，没有再说什么。我们沿着右边的路走了一段，到了北区宿舍楼的分岔口。她朝我点了点头，算是告别，然后拖着她的行李向左边的女生宿舍走去。

我看着她的背影消失在拐角处，心里莫名地想：这个女生，好像不太一样。

但我没有多想。新生报到的混乱很快把这个短暂的插曲冲淡了。

北区七号楼是一栋六层的旧楼，红砖外墙，铁框窗户，走廊里弥漫着一股消毒水和霉味混合的气息。我拖着行李箱爬上四楼，找到了416房间。门是虚掩的，我推门进去，看见房间里已经摆好了两张铁架床，靠窗的那张床上堆着被褥和一个巨大的行李箱。

一个男生正坐在床上打电话，声音很大。他穿着一件黑色的篮球背心，胳膊上晒出了明显的分界线，皮肤黝黑，国字脸，浓眉大眼，看起来比实际年龄要大一些。

"……对对对，到了，挺好的，嗯，放心吧妈，我不会吃亏的。"他看到我进来，扬了扬下巴算是打招呼，然后继续对着电话说，"不累，这点路算什么。行了行了，挂了啊，信号不好。"

他挂了电话，从床上跳下来，朝我伸出手："方驰，东北人。你是张小雨吧？"

我愣了一下："你怎么知道？"

"哈哈，你是最后一个没到的，辅导员在QQ群里说了，有个叫张小雨的南方人，让我们等等。"他用力握了握我的手，手劲大得惊人，"你来得正好，就剩你对面那张床了。"

方驰。我在心里记住了这个名字。

他确实是个自来熟。不到十分钟，他已经把我的行李箱搬上了床架，把自己的零食分了一半给我，并且详细地介绍了他从网上搜集到的关于沧澜大学的各种信息——哪个食堂好吃，哪个老师好过，哪栋教学楼有空调。

"对了，咱们还有一个室友，叫徐浩然，安徽的，据说也是个学霸。"方驰一边说一边拆一包薯片，"还没到，估计快了。"

徐浩然是在傍晚时分到的。

他推门进来的时候，我和方驰正在打牌——用的是方驰从家里带来的一副扑克牌，纸角已经卷了。徐浩然个子中等，偏瘦，戴一副银框眼镜，镜片后面的眼睛很安静。他穿着一件格子衬衫，扣子扣到了最上面一颗，手里提着一个帆布袋，袋子上印着一行小字——后来我凑近看了，是某本法学期刊的名称。

"你们好。"他推了推眼镜，声音不大。

"来了来了！"方驰跳下床，"就等你了，快来打牌。"

"不了，我先收拾一下。"他微微一笑，算是打了招呼，然后安静地把自己的东西归置到柜子里。他的动作很仔细，每一本书都按照高矮排列在书架上，文具放进笔袋，笔袋放进抽屉，抽屉里还垫了一块干净的布。

我注意到他带了不少书，除了教材之外，还有几本厚厚的法学专著——博登海默的《法理学》，以及一本已经翻得很旧的《刑法学》。

"你暑假就预习了？"我问他。

他点了点头："之前就读过一些，想再温习一下。"

方驰在旁边夸张地叹了口气："你们两个学霸是要逼死我吗？"

我们都笑了。那是我在沧澜大学的第一个晚上，窗外的蝉鸣声此起彼伏，远处传来校园广播站放的音乐——周杰伦的《烟花易冷》，旋律在夜色里显得格外悠远。宿舍里的灯是那种老式的白炽灯，光线昏黄而温暖。

我躺在硬邦邦的床板上，掏出手机。屏幕上有一条新短信，还是父亲发来的："安顿好了？"

我回了一个"嗯"。

过了几分钟，他又发来一条："好好学。"

依然是没有标点。我把手机扣在枕头旁边，盯着天花板上的一道裂缝发呆。裂缝从墙角延伸到灯座附近，像一条干涸的河流。

方驰已经打起了呼噜，声音洪亮而有节奏。徐浩然那边的灯还亮着——他在床头夹了一个小台灯，正捧着一本书看。我侧过身，看到他读的是一本英文原版的法学著作，书页已经泛黄了。

我闭上眼睛，听着窗外的蝉鸣和远处若有若无的广播声，心里涌起一种奇异的感觉。这种感觉很难描述——像是站在一扇门的门槛上，身后是已经走过的十八年，面前是一片完全未知的世界。

我那时候想，大学生活大概会像这九月的夜晚一样，平静、温暖、波澜不惊。

我错了。

后来的很多事情告诉我，从踏入沧澜大学的那一刻起，我就已经走进了一张巨大的网。只是那时候的我还太年轻，看不见那些隐藏在暗处的丝线——它们细如蛛丝，却坚韧无比，足以把一个人的命运牢牢缚住。

那天晚上我做了很多梦。梦里有一片白色的花海，栀子花的香气浓烈得让人窒息。花海的尽头站着一个模糊的身影，我看不清他的脸，但我知道他在看着我。

我在凌晨三点醒来的时候，浑身是汗。

窗外的蝉鸣不知什么时候停了，校园安静得像一座空城。只有走廊尽头的水龙头在滴水，一滴一滴，打在铁质的水池里，发出清脆而空洞的声响。

我翻了个身，重新闭上眼睛。

明天还有报到手续要办，还有新的教室要去，还有新的面孔要认识。

明天——

明天一切都会开始。

而我不知道的是，有些东西已经开始很久了。在我出生之前，在我来到这里之前，有些故事就已经在沧澜大学的角落里悄悄展开。那些故事像埋在地下的根系，盘根错节，沉默生长，等待着某一天破土而出。

那一天不会太远了。
