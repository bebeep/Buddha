# 第七十二章 方驰被捕

三月十二日，星期六。

凌晨四点，我被一阵急促的敲门声惊醒。

不是普通的敲门——是那种带着紧迫感的、不容拒绝的砸门声。我翻身坐起来，心脏在胸腔里猛烈地跳动着。宿舍里一片漆黑，只有窗外的路灯透过窗帘投射进来一小块橘黄色的光。

"张小雨！开门！"是宿管阿姨的声音，但语气完全不同于平时的和蔼——带着一种紧张和慌乱。

我穿上外套，打开门。门外站着宿管阿姨和两个穿便衣的男人。

"张小雨同学？"其中一个男人亮出了证件，"市公安局刑侦支队。我们需要你配合调查。"

"什么事？"

"关于方驰的案件。请跟我们走一趟。"

方驰。

我的心沉了一下。

我没有反抗。我穿好衣服，跟着他们走出了宿舍楼。走廊里的灯全亮着，刺眼的白炽灯光让我眯起了眼睛。几个宿舍的门开了一条缝，有人在暗中窥视。

楼下停着一辆黑色的轿车。我上了后座，车子发动了，驶入了凌晨空旷的街道。

"方驰怎么了？"我问。

"被抓了。"开车的警察说，"今天早上凌晨两点，在城南的一个城中村出租屋里。"

"他受伤了吗？"

"没有。他很配合。"

我松了一口气，但随即又紧张起来。方驰被捕意味着什么？他手里的笔记本、他调查的信息、他掌握的所有证据——这些东西现在都在警方手里了。

车子在市公安局的大楼前停下。我被带进了一间询问室——不是审讯室，是一间比较普通的房间，有一张桌子、几把椅子，墙上挂着一面钟。

等了大约二十分钟，马国栋队长推门走了进来。

他看起来比上次见面时更疲惫了。眼袋很深，胡子拉碴，衬衫的领口没有扣好。他把一叠文件放在桌上，然后坐在我对面，用一种审视的目光看着我。

"张小雨，"他说，"你知道方驰为什么被抓吗？"

"不知道。"

"他在你的宿舍楼下出现过。有人看到了他。"

"我没有见过方驰。"

"真的？"

"真的。"

马国栋盯着我看了几秒钟，然后从文件堆里抽出一个笔记本——方驰的笔记本。

"这是从方驰的出租屋里搜出来的。"他说，"里面记录了大量的调查信息——关于周建平、关于方苒事件、关于三年前的连环杀人案。有些信息的来源非常详细，包括一些只有内部人员才知道的细节。"

他翻开笔记本，指着其中一段话："这里写着——'张小雨，法学大一，正在协助调查。'你觉得这说明了什么？"

我的心跳加速了，但我的表情没有变。

"这说明方驰知道我在调查。"我说，"但知道一个人在调查和协助一个人调查是两回事。"

"你们没有联系过？"

"方驰通过加密邮件和我讨论过一些学术问题。"

"学术问题？"马国栋的眉毛挑了起来，"关于什么的学术问题？"

"关于刑法中的证据规则。"我说，"方驰对法律很感兴趣。我们讨论的是——在什么情况下，间接证据可以构成完整的证据链。"

马国栋看着我，眼神里有一种我读不懂的东西。他可能不相信我的话，但他也没有直接反驳。

"张小雨，"他放下笔记本，身体前倾，"我直说了。方驰是一个在逃的犯罪嫌疑人。他涉嫌故意杀人——王建国案。你现在和他有了接触，不管是什么形式的接触，都会让你陷入非常被动的局面。"

"马队长，我只是在调查真相。"

"真相？"马国栋苦笑了一下，"你以为你是侦探小说里的主角？你以为靠一个十八岁的大一学生就能破案？"

"那您呢？"我直视着他的眼睛，"您破了什么案？王建国案结了吗？陈向晚案结了吗？马玉芬案结了吗？赵德厚案结了吗？"

马国栋的脸色变了。他的嘴唇抿成了一条线，太阳穴上的青筋微微跳动。

"张小雨，"他的声音变得很低，很危险，"你不知道你在说什么。"

"我知道。"我说，"我在说——这些案件至今没有一个被侦破。不是因为缺乏线索，而是因为有人在阻挠调查。王国强的案件被定性为入室盗窃，但监控录像恰好在那天晚上'故障'了。陈向晚的案件被定性为意外，但她的论文和笔记表明她在调查一个非常重要的案件。马玉芬的案件至今悬而未决。赵德厚的案件——"

"够了。"马国栋打断了我。

沉默。

然后他叹了口气，靠回了椅背上。

"你说得对。"他承认，声音里带着一种深深的疲惫，"这些案件确实有很多疑点。但我不是不想破案——我是破不了。上面有人压着，不让我查。我能做的只是尽量保全证据，等待时机。"

"什么时机？"

"一个足够强大的证据出现的时机。"他说，"一个让上面无法再压下去的时机。"

他看着我，眼神忽然变得认真起来。

"张小雨，方驰的笔记本里有很多信息。有些是有价值的，有些是——危险的。我需要知道，你手里还有什么？"

我沉默了。

"我知道你手里有东西。"马国栋说，"苏晴在审讯中提到过一个U盘。她说她把U盘交给了一个'信任的人'。那个'信任的人'——是你吗？"

我没有回答。

"张小雨，"马国栋的声音变得温和了一些，"我理解你的心情。你还年轻，有正义感，想为死去的人讨回公道。但你要明白，法律不是靠冲动和热情来运行的。它需要证据，需要程序，需要时机。如果你手里的证据不够扎实，或者提交的方式不对，不仅帮不了忙，反而会打草惊蛇。"

"那您的建议是？"

"把你知道的一切都告诉我。"他说，"让我来处理。我有渠道，有资源，有——虽然有限但确实存在的——权力。你一个人做不了这些事。"

我看着他。在这个疲惫的、胡子拉碴的中年男人身上，我看到了一种真诚的、但被现实反复碾压过的正义感。他不是不想破案——他是被束缚了手脚，在夹缝中艰难地维持着平衡。

"马队长，"我说，"我需要时间。"

"多少时间？"

"两周。"

他想了想，然后点了点头。

"两周。"他说，"两周之后，如果你没有拿出足够的东西，我就必须按照程序来——包括没收你手里的所有材料。"

"公平。"

我站起来，准备离开。走到门口的时候，马国栋叫住了我。

"张小雨。"

"嗯？"

"方驰的笔记本里有一句话——'如果有一天我不在了，请张小雨继续。'你觉得他为什么写这句话？"

我回过头看着他。

"因为他知道，这条路不会那么容易走。"我说。

马国栋点了点头，没有再说什么。

我走出了市公安局的大楼。外面的天已经亮了，三月的阳光照在灰色的水泥墙面上，反射出一种刺眼的白光。街上的行人匆匆忙忙地走着，没有人注意到，在这栋大楼里，一场关于真相和谎言的博弈正在进行。

手机响了。是林琳。

"方驰被抓了。"她说，声音里带着明显的焦虑，"你没事吧？"

"没事。他们只是问了我一些问题。"

"方驰怎么样？"

"被捕了。但他应该没有受伤。"

"那他的笔记本——"

"在警方手里。"

沉默。

"那我们之前的计划——"

"不变。"我说，"方驰被捕了，但我们手里的东西还在。U盘、陈向晚的录音、刘教授的证词、沈亦寒的话——这些都不在方驰的笔记本里。"

"但方驰的财务记录——"

"我抄了一份。"我说，"在书店见面的时候，我把关键的内容都抄了下来。方驰给我的笔记本也在我这里。"

林琳沉默了一会儿，然后说："你比我想象的更谨慎。"

"跟你学的。"

她轻轻笑了一声。但笑声很短，很快就被焦虑取代了。

"张小雨，"她说，"两周。马国栋给了我们两周。"

"对。两周之内，我们必须把所有证据整理成一条完整的证据链。否则——"

"否则一切都会白费。"

"不会白费的。"我说，"方苒不会白死的。"

挂了电话，我站在市公安局门前的台阶上，看着面前的城市。沧阳市在三月的阳光中显得既熟悉又陌生——那些高楼大厦、那些车水马龙、那些行色匆匆的人群，一切都和昨天一样。但在这层平静的表象之下，暗流正在涌动。

两周。

十四天。三百三十六个小时。

足够吗？

我不知道。但我知道，这是我最后的机会了。
