# 第七十一章 周建平的反击

三月十日，星期四。

周建平的反击比我们预想的来得更快、更猛烈。

早上八点，我接到了晴光文化传媒行政部的电话。对方用一种客气但坚决的语气通知我，原定于本月下旬的"沧澜大学-晴光文化青年交流项目"因"合作方战略调整"而取消。这个项目是法学院的重要实践平台，我和林琳都报名参加了。

"战略调整？"我追问。

"是的，非常抱歉给您带来不便。"对方的声音毫无感情，像一台自动应答机器。

我挂断电话，心里清楚得很——这根本不是什么"战略调整"，这是周建平在向我们施压。他知道有人在调查他，他要让我们知道，他有力量切断我们和学校之间的资源纽带。

九点，我去上刑法课。走进教室的时候，我发现讲台上放着一封信。白色的信封，没有署名，和几天前那封警告信一模一样。

我拆开信封。里面是一张白色的卡片，上面只有一句话：

"回头是岸。"

我把卡片放进口袋里，坐到了教室的最后一排。林琳坐在旁边，看了我一眼。

"又来了？"她低声问。

"嗯。"

"这次说了什么？"

"回头是岸。"

她抿了抿嘴唇，没有说话。

下课后，我去了法学院的教学楼公告栏。匿名信不只是放在了我的教室——它出现在了法学院的每一个公告栏上。内容大同小异，都是警告"某些人"不要"多管闲事"。

但最让我担心的不是这些信。信只是恐吓，说明周建平在试探我们的反应。真正让我警觉的是另一件事。

中午吃饭的时候，我的室友李伟告诉我，有两个陌生人早上来过宿舍楼，在走廊里转了一圈。宿管阿姨说他们是"来找人的"，但李伟觉得他们更像是在"踩点"。

"他们长什么样？"我问。

"一个高个子，戴墨镜，穿黑色夹克。另一个矮一点，胖一些，穿灰色运动服。"李伟说，"他们问宿管阿姨，张小雨住在哪个房间。"

我的筷子停在了半空中。

"他们问了我在哪个房间？"

"对。宿管阿姨没有告诉他们，说需要登记证件。但那两个人在走廊里转了好一会儿才走。"

有人在监视我。

我放下筷子，强迫自己冷静下来。周建平在反击——这是意料之中的事。一个经营了这么多年的权力网络的人，不会坐以待毙。他会动用一切资源来保护自己：金钱、人脉、威胁、甚至暴力。

但我不打算退缩。

下午，我在图书馆见到了林琳。她的脸色不太好，眼圈下面有明显的疲倦痕迹。

"昨晚没睡好？"我问。

"没怎么睡。"她说，"不是因为那些警告信。是因为——"她犹豫了一下，"昨晚我回宿舍的时候，发现门口放着一束花。"

我的心猛地一沉。

"什么花？"

"栀子花。"

白色的栀子花。放在宿舍门口。

"花是新鲜的。"林琳的声音平静得近乎冷漠，但我能听出平静下面的颤抖，"还带着水珠。说明放上去的时间不久。"

"你碰了花吗？"

"没有。我拍了照片就把它放在了走廊的窗台上。"

"你报告宿管了吗？"

"报告了。宿管说会查监控。"

"监控能看到什么吗？"

"不知道。"

我沉默了。栀子花——方苒最喜欢的花——现在变成了一种威胁的信号。有人用栀子花来告诉我们：我们知道你们在做什么，我们知道你们在哪里，你们随时可能像方苒一样。

"林琳，"我说，"你害怕吗？"

她看着我，眼睛里有一种我从未见过的东西——不是恐惧，而是一种冰冷的、坚硬的决心。

"我害怕。"她说，"但我更生气。"

"生气？"

"他们用栀子花来威胁我。"她的声音低了下去，但每一个字都像是从牙缝里挤出来的，"栀子花是方苒最喜欢的花。方苒死了。他们用方苒的花来威胁我。这不仅仅是在恐吓——这是在侮辱。侮辱方苒，侮辱所有死去的人。"

我看着她，忽然觉得她在那一刻比任何时候都要美丽。不是外表的美丽，而是一种内在的、来自灵魂深处的美丽。那种美丽不是温室里的花朵，而是暴风雨中的火焰——越是被风吹，就烧得越旺。

"我们不能坐以待毙。"我说，"周建平在反击，说明他害怕了。一个不害怕的人不需要威胁别人。"

"但他在暗处，我们在明处。"林琳说，"他有钱、有人脉、有资源。我们什么都没有。"

"我们有真相。"

"真相在没有被揭露之前，什么都不是。"

她说得对。真相如果不被说出来，就只是沉默的另一种形式。我们需要把真相变成武器——变成能够击穿周建平面具的武器。

"方驰。"我忽然说。

"什么？"

"方驰。他一直在暗中调查周建平。他手里可能有一些我们不知道的证据。如果我们能联系上他——"

"方驰在逃。"林琳说，"警方在找他。他不可能主动联系我们。"

"但他联系过我。"

"那是之前。现在苏晴被捕了，案件已经公开了，他暴露的风险更大。"

"我还是想试试。"我说。

当天晚上，我给方驰的加密邮箱发了一封邮件。邮件的内容很简单：

"情况有变。周建平开始反击。我们需要你手里的东西。——张小雨。"

发完邮件后，我躺在床上，望着天花板。宿舍里很安静，李伟已经睡了，均匀的鼾声从对面的床铺上传来。窗外的月光透过窗帘的缝隙照进来，在地板上画出一条银白色的线。

我想起了今天发生的一切——被取消的合作项目、教室里的警告信、宿舍楼下的陌生人、林琳宿舍门口的栀子花。这些不是孤立的事件，而是一个系统性的反击。周建平在用他所有的资源来施压：经济上的（取消合作）、心理上的（警告信）、物理上的（监视和栀子花）。

他在告诉我们：你们赢不了。

但我不信。

一个真正无所畏惧的人不需要做这些事。周建平之所以如此大张旗鼓地反击，恰恰说明他感到了威胁。他害怕了。他害怕我们手里的证据，害怕苏晴的供述，害怕真相被揭露的那一天。

而他越害怕，就越容易犯错。

手机震动了一下。是方驰的回复。

只有一行字：

"明天下午三点，老地方。"

老地方。方驰和我从来没有在现实中见过面，我们所有的联系都是通过加密邮件。他说的"老地方"是什么意思？

我翻看了之前的邮件记录。在我们最早的一次通信中，方驰提到过一个地点——沧澜大学东门外的一家旧书店，叫做"拾光书屋"。他说那是他姐姐方苒最喜欢去的地方。

"拾光书屋"。

第二天下午两点四十五分，我来到了"拾光书屋"。

这是一家很小的书店，夹在一家奶茶店和一家打印店之间，门面窄得几乎会被路人忽略。但走进去之后，空间意外地宽敞——两面墙都是顶天立地的书架，上面摆满了各种旧书和杂志。空气中弥漫着旧纸和木头的气味，让人想起某个遥远的、被遗忘的年代。

书店里只有一个客人——一个戴着棒球帽和口罩的年轻男人，站在最里面的书架前，假装在看书。

我走过去。他转过头，摘下了口罩。

是方驰。

他比照片上瘦了很多。颧骨突出，眼窝凹陷，下巴上有一层短短的胡茬。他的眼睛布满了血丝，像是很久没有睡过觉。但他的眼神依然锐利——那种锐利不是来自自信，而是来自一种被逼到绝境之后的警觉。

"你来了。"他的声音很低。

"你说老地方，我就知道是这里。"

他点了点头，把目光移向了门口。"我们没有太多时间。如果有人在跟踪你——"

"没有人跟踪我。我绕了三条街才过来的。"

方驰微微放松了一些。他从背包里掏出一个笔记本，翻到某一页，递给我看。

"这是我在调查周建平的过程中收集的信息。"他说，"大部分是间接证据，但有一些很关键。"

我快速浏览了笔记本上的内容。方驰的字迹很工整，每一条信息都标注了来源和日期。

"你查到周建平二〇〇八年在文学社的活动记录了吗？"我问。

"查到了一部分。"方驰说，"文学社的档案室在文学院的地下一层，我有朋友帮我进去看过。二〇〇八年的活动记录里有一些被删除的痕迹——有人在我们之前就去过档案室，删掉了一些东西。"

"删掉了什么？"

"不确定。但从剩余的记录来看，二〇〇八年十一月到十二月之间，文学社举办了多次活动。每次活动的签到表上都有方苒的名字——但在十二月的签到表上，她的名字突然消失了。"

"十二月。"我说，"方苒是在十一月前后被周建平侵犯的。十二月她不再参加活动，说明她已经——"

"已经崩溃了。"方驰的声音变得很硬，像是一块被压缩到极限的钢铁，"她不再去文学社，不再去上课，不再和任何人说话。她把自己关在宿舍里，谁也不见。我后来从她的室友那里了解到，她那段时间每天都在哭。"

我沉默了。

"然后一月份，她就死了。"方驰说，"寒假。在家里。"

"你恨周建平吗？"我问。

他看着我，眼睛里有一种我无法描述的东西。不是恨——恨太简单了。那是一种比恨更深、更痛、更无法愈合的东西。

"我姐姐死了。"他说，"她才十八岁。她的人生还没有开始。你说，我应不应该恨他？"

"应该。"我说，"但恨不够。我们需要证据。"

"我知道。"他把笔记本翻到另一页，"这里有一些东西。周建平的公司——晴光文化传媒——的财务记录。我通过一些渠道拿到了部分数据。"

"什么渠道？"

"这个我不能说。"

"方驰——"

"张小雨，"他打断了我，"你不需要知道所有的细节。你只需要知道，这些信息是可靠的。"

我看了看那些财务记录。它们显示，晴光文化传媒在二〇〇九年成立，初始资金来自一家叫做"恒远投资"的公司——和周建平给沧澜大学捐款的是同一家公司。而恒远投资的法定代表人是沈国昌——沈亦寒的父亲。

"周建平用的是妻子的钱来开公司。"我说。

"对。但有趣的是——"方驰指着一行数字，"恒远投资在二〇〇五年就已经注销了，因为沈国昌在那一年去世了。但晴光文化传媒的注册文件上写着，恒远投资在二〇〇九年仍然作为出资方存在。"

"一个已经注销的公司，怎么能出资注册新公司？"

"除非——注册文件是伪造的。"方驰说，"或者有人故意隐瞒了恒远投资注销的事实，用虚假的材料完成了注册。"

"这意味着什么？"

"意味着周建平在注册公司时使用了虚假材料。这是犯罪。"方驰说，"而且——如果恒远投资在二〇〇九年已经不存在了，那晴光文化传媒的初始资金到底来自哪里？"

"来自周建平自己？"

"或者来自另一个不愿被追溯到的来源。"方驰说，"我还在查。"

我们又在书店里待了半个小时，交换了各自掌握的信息。方驰知道的比我预想的多得多——他不仅调查了周建平的公司，还调查了周建平的社会关系、商业往来、甚至日常行踪。

"你为什么不去报警？"我问。

"报了。"方驰苦笑了一下，"二〇一〇年，我去市公安局报了案。你知道他们怎么说的？"

"怎么说？"

"'证据不足，不予立案。'"

"证据不足？"

"我手里有方苒的日记副本，有她生前的邮件截图，有她室友的证词。但警方说这些都不够——日记是副本不是原件，邮件无法验证真伪，室友不愿意出面作证。"

"因为有人在阻止他们作证。"

"对。"方驰说，"后来我去省厅报案，被踢回来了。去信访，石沉大海。最后——"他停了一下，"最后我决定用自己的方式。"

"用自己的方式？"

"你知道的。"他说，"王建国。"

我看着他。他的眼神在那一刻变得很冷，冷得像一块冰。

"王建国该死。"他说，"他毁了方苒，毁了我的姐姐。他帮周建平掩盖了一切，然后心安理得地过了三年。我杀了他，我不后悔。"

"但你不应该——"

"张小雨，"方驰打断了我，"你没有失去过姐姐。你不知道那种感觉。你每天醒来，都想着——如果当初我多做一些，如果当初我没有放弃，她可能不会死。那种感觉会把你逼疯。"

我沉默了。

"但现在不是讨论这些的时候。"方驰把笔记本合上，递给我，"这个你拿着。里面的信息比我们之前讨论的更详细。你需要它。"

"你呢？"

"我要走了。"他说，"这个地方不安全。我不能待太久。"

"你要去哪？"

"不能告诉你。"他把棒球帽重新戴好，拉了拉口罩，"但我会继续联系你。如果有什么重要的发现，我会发邮件。"

"方驰。"我叫住他。

他回过头。

"小心。"我说。

他点了点头，然后推开书店的门，走进了外面的街道。他的身影很快消失在了人群中——一个瘦削的、戴着棒球帽的年轻人，混入了沧阳市灰色的街景之中，像一滴水融入了大海。

我拿着他的笔记本走出书店。外面的天色已经暗了，路灯在暮色中亮了起来，把街道照成了一条橘黄色的光带。

我低头看了看手中的笔记本。方驰的字迹工整而有力，每一笔都像是在纸上刻下的痕迹。这不是一本普通的笔记本——这是一个弟弟对姐姐的爱的证据，是一个家庭被摧毁之后的残骸，是一个年轻人用三年的逃亡和孤独换来的真相。

我把笔记本小心地放进了外套的内袋里，然后快步走向校门。

身后的"拾光书屋"在暮色中变成了一团模糊的暗影。书店的灯已经关了，只有门缝里透出一丝微弱的光。

方苒最喜欢的地方。

现在，它也成了这场战争的一部分。
