# 第七十五章 质问

三月十七日，星期四。

我坐上了回沧阳市郊区家的长途汽车。

三个小时的车程，窗外的风景从城市变成了郊区，从高楼大厦变成了低矮的民房和农田。三月的田野还没有完全绿起来，大片大片的黄褐色土地在灰蓝色的天空下延伸着，像一幅褪了色的油画。

我的脑子里一片混乱。

从昨晚到今天早上，我和林琳谈了很久。她没有给我建议——她知道这种决定不能由别人来做。她只是陪着我，帮我整理思路，帮我列出所有的可能性。

"如果你决定揭露你父亲，"她说，"那周建平的律师一定会利用这一点来攻击你的可信度。他们会说你是因为和父亲有矛盾才捏造证据。"

"我知道。"

"但如果你不揭露——"

"那方苒就永远得不到公道。"

"对。"

"所以我没有选择。"

"你有。"林琳说，"只是每一个选择都很痛苦。"

她说得对。每一个选择都很痛苦。但有些痛苦是必须承受的——就像手术刀割开皮肤时的疼痛，不是为了伤害，而是为了治愈。

汽车在下午两点到了家附近的站点。我下了车，沿着熟悉的街道走向家。这条路我走了十八年——从小学到高中，每一块地砖、每一棵树、每一家店铺都刻在了我的记忆里。街角的早餐店还在，老板娘看到我还会笑着打招呼："小雨回来啦？"

"嗯。"

"你爸在家呢。今天一早就去买菜了。"

我勉强笑了笑，继续往前走。

家在一栋六层居民楼的三楼。灰色的外墙，锈迹斑斑的铁门，楼道里弥漫着一股熟悉的饭菜和清洁剂混合的气味。我上了楼，站在门前，深吸了一口气。

门开了。

父亲站在门口，穿着一件灰色的家居毛衣，头发比上次见面时白了很多。他看到我，脸上露出了一丝微笑——但那个微笑很勉强，像是一张面具在裂缝中勉强维持着完整。

"小雨，进来吧。"

我走进家门。客厅的布置和记忆中一模一样——旧沙发、老电视、茶几上的茶杯和报纸。墙上挂着一家三口的合影——那是十年前拍的，照片里的父亲还很年轻，头发乌黑，笑容灿烂。我站在他旁边，穿着初中的校服，一脸稚气。

那时候，我认为父亲是世界上最正直的人。

母亲在厨房里忙碌着。她听到我回来，探出头来笑着说："小雨回来了？先洗手，马上吃饭。"

"妈。"

"你爸今天特意去市场买了你最爱吃的排骨。"

我走进厨房，看到案板上摆着新鲜的排骨和青菜。母亲的手在忙碌着，围裙上沾着面粉，头发用一根橡皮筋随意地扎在脑后。她的背影和十年前没有什么变化——依然瘦小、依然忙碌、依然为这个家倾注着全部的爱。

她不知道。她什么都不知道。

"妈，"我叫了她一声，然后什么都说不出来了。

"怎么了？"她回过头，看到我脸上的表情，笑容消失了，"出什么事了？"

"没事。"我说，"就是想吃你做的饭了。"

她松了口气，笑着转回去继续忙了。

午饭的气氛很压抑。父亲几乎没怎么说话，只是默默地往我碗里夹菜。母亲在旁边絮絮叨叨地说着家常——邻居的琐事、亲戚的近况、小区里的新鲜事。她的声音像一层薄薄的布，覆盖在我们之间那个巨大的沉默之上。

吃完饭后，母亲去厨房洗碗了。客厅里只剩下我和父亲。

他坐在沙发上，手里端着一杯茶，但没有喝。茶已经凉了，杯面上浮着一层薄薄的雾气，正在慢慢消散。

"爸。"我开口了。

"嗯。"

"你知道我为什么回来。"

父亲的手指在茶杯上微微收紧了。他没有看我，只是盯着茶杯里的茶水，像是在里面寻找某种答案。

"小雨，"他终于说，"你听我解释——"

"你参与了方苒事件的处理。"我没有让他说完，因为如果让他解释，我可能会动摇，"二〇〇八年十二月十五日的校董会会议纪要上，有你的名字。你负责舆论管控。"

父亲闭上了眼睛。

"那个会议——"他的声音变得很低，"当时学校面临国家重点学科评估。如果方苒的事情被曝光，中文系的评估就会泡汤，整个学校的声誉都会受到影响。几千名师生的努力——"

"所以你们选择了牺牲方苒。"

"不是牺牲。"父亲的声音有了一丝急切，"我们的本意是——是妥善处理。让事情不要扩大，让各方都能——"

"让周建平不受惩罚？让赵德厚继续当他的权威教授？让王建国继续当他的保卫处副处长？"

父亲沉默了。

"爸，方苒死了。"我的声音在发抖，但我没有停下来，"她在二〇〇九年一月自杀了。她吃了安眠药。她十八岁。她的人生还没有开始。"

"我知道。"父亲的声音变得沙哑了。

"你知道？"我的声音提高了，"你知道她死了，然后你做了什么？你继续过你的日子。你继续当你的校董。你继续做你的生意。你回家给我做早餐，送我去上学，问我考试考得好不好。你——"

我的喉咙堵住了。

"你每天晚上闭上眼睛的时候，不会想到方苒吗？"

父亲没有回答。但他的沉默就是答案。

"你会。"我说，"你当然会。因为你不是坏人。你只是一个做了坏事的好人。这比坏人更可怕——因为坏人做坏事是理所当然的，但好人做坏事，每一次回忆都是一次凌迟。"

父亲的眼眶红了。

"小雨，"他的声音破碎了，"我当时……我当时以为事情不会那么严重。我以为那个女学生只是——只是受了些委屈。我以为给她一些补偿，让她换个环境，事情就过去了。我不知道她会——我不知道她会——"

"你不知道她会死？"

"我不知道。"

"但你有没有想过这种可能？"

沉默。

"你有没有想过——一个十八岁的女孩被一个博士生侵犯了，然后整个学校的权力机器都在帮她掩盖真相——她会不会绝望？她会不会觉得活着没有意义？你有没有想过？"

父亲低下了头。他的肩膀在微微颤抖。

"我想过。"他的声音几乎听不见了，"后来——后来她死了之后——我每天都在想。"

"但你没有说出来。"

"说出来有什么用？"他抬起头看着我，眼睛里布满了血丝，"说出来能让她复活吗？说出来能让我的家庭破碎吗？能让你——让你有一个坐牢的父亲吗？"

这句话像一把刀一样刺进了我的心脏。

"所以你选择了沉默。"

"我选择了保护你。"

"不。"我说，"你选择了保护你自己。"

这句话太重了。父亲的脸上出现了一种我从未见过的表情——不是愤怒，不是悲伤，而是一种被剥光了所有伪装之后的赤裸。那种赤裸比任何惩罚都更残酷。

我们沉默了很久。窗外的阳光已经西斜了，把客厅照成了一片橘红色。墙上那张十年前的合影在夕阳中显得格外刺眼——照片里的父亲笑容灿烂，眼神坚定，像是一个永远不会犯错的英雄。

但英雄已经倒了。

"爸，"我的声音终于平静了下来，"我不会因为这件事恨你。但我不能假装它没有发生过。"

"你想怎么做？"

"我要把真相说出来。"

"包括我的部分？"

"包括你的部分。"

父亲闭上了眼睛。他的脸上在那一刻似乎老了十岁。

"我知道。"他轻声说，"你一直是个正直的孩子。比我正直。"

"爸——"

"去吧。"他打断了我，声音里带着一种认命般的疲惫，"去做你认为对的事。我……我不会拦你。"

他站起来，走进了卧室。门关上了。轻轻的，几乎没有声音。

我坐在客厅里，看着墙上那张合影。夕阳的光在照片上慢慢移动着，从父亲的笑脸移到了我的笑脸，然后移到了母亲的——母亲不在照片里。这张照片是在母亲去世前一年拍的。

母亲如果还在，她会怎么想？

我不知道。但我知道一件事——明天太阳升起的时候，我必须做出最终的决定。

门开了。母亲从厨房走出来，手里端着一盘切好的水果。

"小雨，吃水果。"她把盘子放在茶几上，然后坐在我旁边，"你和你爸聊了什么？他脸色不太好。"

"没什么。"我说，"就是聊了聊工作的事。"

"你爸这些年压力也大。"母亲叹了口气，"校董的事不好做，又要应酬又要捐款。但他从来不抱怨。"

我看着她。她的脸上有细密的皱纹，眼角有鱼尾纹，鬓角有了白发。但她的眼神还是那么温柔——那种只有母亲才有的、无条件的、不求回报的温柔。

"妈，"我说，"如果——如果爸做了一件错事。一件很大的错事。你会怎么办？"

母亲看了我一眼，眼神里闪过了一丝警觉。但她很快恢复了平静。

"什么错事？"

"假设。"

她想了想，然后说："那要看是什么错事。如果是伤害了别人的错事，那就要去弥补。如果是——如果是法律上的错事，那就要去承担。"

"但你不会恨他？"

"恨？"母亲笑了——一种苦涩的、但充满包容的笑，"小雨，你爸不是坏人。他可能犯了错，但他不是坏人。犯了错的人需要的是改正，不是恨。"

我点了点头，没有再说什么。

母亲不知道。她什么都不知道。但她的话——"犯了错的人需要的是改正，不是恨"——像一盏灯一样，在我心中的黑暗中点亮了一小片光。

晚上，我睡在自己小时候的房间里。床还是那张床，书桌还是那张书桌，书架上还是那些从小看到大的书。墙上贴着我小时候的奖状——"三好学生"、"数学竞赛一等奖"、"作文比赛特等奖"——每一张都是父亲帮我贴上去的。

他帮我贴这些奖状的时候，心里在想什么？他看着那些"正直"、"诚实"、"品学兼优"的评语，会不会想到自己正在做的事情？

还是说——他把"工作"和"家庭"分成了两个完全不同的世界？在那个世界里，他是帮凶；在这个世界里，他是好父亲。两个世界互不干扰，各自运行。

我不知道。也许人就是这样的——可以在做坏事的同时，依然是一个好父亲。这不是借口，但这是事实。而事实，不管多么令人痛苦，都必须被面对。

我翻了个身，闭上眼睛。

明天。明天我要做出最终的决定。

窗外的月亮很圆，银白色的光洒在书桌上，照亮了那些旧奖状。在月光中，那些"正直"、"诚实"的字样显得格外刺眼——像是一个个无声的质问，从过去穿越到现在，直指我的心脏。

我该怎么办？

答案其实已经在我心里了。只是我还不敢说出来。
