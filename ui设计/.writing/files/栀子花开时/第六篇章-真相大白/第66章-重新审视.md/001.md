# 第六十六章 重新审视

二〇一一年三月五日，星期六，阴。

沧澜大学的校园笼罩在一片灰蒙蒙的雾气中，三月的风还带着冬天残余的寒意，从人工湖面上吹过来，湿漉漉地钻进衣领。我裹紧了外套，沿着图书馆后面的小路往宿舍走。梧桐树的枝条还没有抽出新芽，光秃秃地伸向铅灰色的天空，像一只只干瘦的手。

苏晴被捕已经三天了。

这三天里，我几乎没有合过眼。每次闭上眼睛，脑海里就会浮现出苏晴在审讯室里那张疲惫而释然的脸。她承认了杀害王建国，承认了那些被掩埋了三年之久的秘密。但她的供述并不是终点，而是另一个起点——像是一块巨石投入深潭，激起的涟漪正在一圈一圈地向外扩散，而水底的真相，还远远没有浮出水面。

我推开宿舍的门，林琳正坐在我的书桌前，面前摊开着一张巨大的白纸。白纸上画满了线条和箭头，像一张蛛网，又像一幅星图。她听到门响，抬起头来看了我一眼，眼眶下面有淡淡的青色——她也没有睡好。

"你来看。"她说，声音有些沙哑。

我走过去，俯身看那张纸。最中间的位置，她用红色水笔写了一个名字：周建平。从这个名字向外辐射出无数条线，连接着其他所有的名字——赵德厚、王建国、苏晴、方苒、方驰、陈向晚、马玉芬、沈亦寒……每一个名字旁边都标注了简短的说明和日期，像是一份微缩的档案。

"我在整理时间线。"林琳说，"把所有的事情按照发生的顺序排列出来，看看有没有遗漏或者矛盾的地方。"

我拉过一把椅子坐在她旁边，仔细端详这张图。林琳的字迹清秀而工整，每一个日期都经过了反复核对。我看着那些红色的线条在白纸上交错延伸，仿佛看到了三年前的那个冬天，那些年轻的生命如何在一张无形的网中挣扎、碰撞，最终被吞噬。

"从头开始。"我说。

林琳点了点头，用笔尖指着图纸的左上角，开始梳理。

"二〇〇八年九月。"她说，"方苒考入沧澜大学中文系，加入文学社。当时的文学社社长是周建平——中文系博士生，导师是赵德厚。方苒来自小城市，家境普通，性格内向但才华出众。她在日记里写，刚入学时觉得一切都很新鲜，文学社是她最喜欢的地方。"

她的笔尖移到下一个节点。

"二〇〇八年十一月前后。周建平开始对方苒实施侵犯。"林琳的声音微微发颤，但她很快控制住了，"方苒的日记里用隐晦的语言记录了这件事。她没有用'强暴'这个词，而是写'那个好心的学长露出了另一张脸'。她信任他，因为他帮她改稿，帮她推荐发表，她把他当成恩人。"

我闭上眼睛。一个十八岁的女孩，离开家乡来到陌生的城市，在最信任的人身上遭遇了最残酷的背叛。那种绝望，我甚至不敢去想象。

"方苒试图求助。"林琳继续说，"她先找了辅导员，但辅导员把这件事报给了学院，学院又报给了赵德厚。赵德厚是周建平的博导，也是中文系的权威教授。他选择了保护自己的学生——不是保护方苒，而是保护周建平。"

"赵德厚在学校里有多大的影响力？"我问。

"非常大。"林琳说，"二〇〇八年正是沧澜大学申报国家重点学科的关键时期，赵德厚是中文系的顶梁柱，他的学术成果直接关系到学校的评估结果。如果曝出博士生性侵本科生的丑闻，不仅赵德厚本人，整个学校的声誉都会受到严重影响。"

"所以学校选择了掩盖。"

"对。赵德厚找到了王建国——当时学校保卫处的副处长，也是校董会的成员之一。王建国负责'善后'。"林琳的笔尖在纸上画了一个圈，"所谓善后，就是让方苒沉默。他们可能用了威胁，也可能用了利诱，或者两者兼有。方苒一个十八岁的女孩，面对的是整个学校的权力机器，她根本没有反抗的余地。"

"苏晴呢？"我问，"苏晴当时也是文学社的成员，她应该知道一些内情。"

"苏晴知道。"林琳说，"方苒的日记里提到，她把事情告诉了一个'社里的姐姐'。这个姐姐就是苏晴。苏晴比方苒高两级，当时是大三的学生。她试图帮方苒讨回公道，但很快就被威胁了。"

"被谁威胁？"

"很可能是王建国。"林琳说，"王建国是具体执行善后的人，他负责确保所有知情者保持沉默。苏晴当时有一个刚出生不久的妹妹——"

"林琳。"我说。

林琳的手停了一下，然后轻轻点了点头。

"对。我。"她的声音很平静，但我看到她的指节因为握笔太紧而发白，"苏晴后来被威胁，如果她不保持沉默，她妹妹的生活就会受到影响。她当时只有二十岁，面对这样的威胁，她选择了屈服。她带着我离开了沧阳市，去了南方，再也没有回来过。"

"直到三年前。"

"直到三年前。二〇〇八年，苏晴带着我回到了沧阳市。她改名沈晴，在晴光文化传媒工作——那是周建平的公司。"林琳深吸了一口气，"她以为时间过去了一切都会安全，但周建平认出了她。"

沉默在宿舍里蔓延开来。窗外的雾气更浓了，梧桐树的轮廓在灰白色的光线中变得模糊，像是一个个沉默的幽灵。

"然后呢？"我问，虽然我已经知道了答案。

"然后方苒自杀了。"林琳的声音终于有了一丝裂痕，"二〇〇九年一月，寒假期间。方苒在家里服了安眠药。她留下了一封遗书，但遗书被王建国截获了，没有交给警方。方苒的母亲只被告知女儿是'意外服药'，甚至连真相都不知道。"

我的拳头不自觉地攥紧了。一个十八岁的女孩，在最美好的年华里，被侮辱、被威胁、被孤立，最终选择了死亡。而那些造成这一切的人，却安然无恙地继续着他们的生活——升职、发财、结婚、生子，仿佛什么都没有发生过。

"但这还不是全部。"林琳说，她的声音重新变得坚定，"三年前的连环杀人案，才是这一切的延续。"

她开始在纸上画出另一条时间线，用蓝色的笔标注。

"二〇一〇年下半年。王国强——方苒的表哥——开始调查方苒的死因。他不像方苒的母亲那样容易被糊弄，他去了沧澜大学，找了当年的人，问了很多问题。他一定接触到了某些关键信息，否则不会被杀。"

"王国强死在珍本室。"我说，"死法和王建国一样——被钝器击打后脑。但凶器不同，王国强是被一本青铜器图录砸死的。"

"对。而且王国强的死被伪装成了入室盗窃。"林琳说，"但一个盗贼为什么会用书架上的书作为凶器？这明显是临时起意，或者说，是凶手在愤怒中杀人。"

"你觉得是谁杀了王国强？"

林琳抬起头看着我，眼神里有一种我熟悉的锐利。

"现在下结论还太早。"她说，"但有一点可以确定——王国强在调查方苒事件时，一定接触到了不该接触的信息。如果有人不想让方苒的真相被揭露，那王国强就是他们的威胁。"

"所以王国强被杀了。"

"对。而且杀他的人，很可能和方苒事件有直接关联。"

我靠在椅背上，闭上眼睛，让所有的信息在脑海中重新排列。这就像是一道复杂的数学题，每一个已知条件都在指向同一个答案，但那个答案太大了，大到让人不敢相信。

"继续。"我说。

林琳的笔尖移到了下一个节点。

"二〇一〇年十月，陈向晚被杀。陈向晚是新闻系的研究生，她在写毕业论文时触及了方苒事件的真相。她的论文指导老师是赵德厚，但赵德厚并不知道她已经掌握了足够的证据。陈向晚的死被伪装成了意外——她在校园里被人袭击，头部受伤后死亡。"

"但陈向晚留下了录音和笔记。"

"对。她把这些东西藏在了一个很隐蔽的地方，后来被我们找到了。"林琳说，"陈向晚的笔记里提到，她在调查中发现了一个'关系网'——一个由赵德厚、王建国等人组成的保护网，专门用来掩盖学校内部的丑闻。而这个关系网的核心，就是周建平。"

"然后马玉芬。"我说。

"马玉芬是王建国的妻子。二〇一〇年十二月，她发现了丈夫隐藏多年的秘密——一个保险箱，里面装满了和方苒事件有关的文件。她开始偷偷调查，结果被杀了。死法和前几个人一样——钝器击打后脑。"

"最后是王建国。"林琳说，"二〇一一年一月，王建国被杀。苏晴承认是她干的。"

"但苏晴的供述里有矛盾。"我说，"她说她杀王建国是因为王建国威胁她，但她的叙述中有一些细节对不上。比如凶器的来源，比如作案时间的某些节点。"

"你觉得苏晴在隐瞒什么？"

"不是隐瞒。"我想了想，"我觉得她可能杀了王建国，但不是唯一的原因。或者说，她杀王建国的动机比我们知道的更复杂。"

林琳沉默了一会儿，然后说："还有一件事。方驰。"

方驰——方苒的弟弟。那个一直在暗中调查姐姐死因的年轻人。他在逃，但他曾经通过加密邮件和我联系过。

"方驰知道多少？"我问。

"他知道的比他表现出来的多得多。"林琳说，"他一直在调查周建平，他手里可能有一些我们不知道的证据。但他为什么不直接报警？为什么不把证据交给警方？"

"因为他不信任警方。"我说，"三年前王建国被杀的案件至今没有侦破，马国栋队长虽然能力不错，但案件涉及学校高层，他受到的压力可想而知。方驰可能觉得，把证据交给警方只会让它们再次消失。"

"就像方苒的遗书一样。"林琳说。

我们对视了一眼，都从对方的眼睛里看到了同样的东西——一种沉重的、几乎令人窒息的愤怒。不是那种激烈的、火山喷发式的愤怒，而是一种深沉的、冰冷的愤怒，像三月的寒风一样刺骨。

"让我把所有的事情再梳理一遍。"我说，拿起林琳放在桌上的红色水笔，在白纸的空白处画了一条竖线，"这是整条因果链。"

我在竖线的最上端写下"二〇〇八年"，然后开始往下写：

"二〇〇八年——周建平侵犯方苒。赵德厚掩盖真相。王建国负责善后。苏晴被威胁沉默。方苒求助无门。"

"二〇〇九年一月——方苒自杀。"

"二〇一〇年下半年——王国强开始调查方苒事件。"

"二〇一〇年——王国强被杀。"

"二〇一〇年十月——陈向晚被杀。"

"二〇一〇年十二月——马玉芬被杀。"

"二〇一一年一月——王建国被杀。苏晴承认。"

我退后一步，看着这条时间线。它像一架骨牌，从二〇〇八年一直倒到二〇一一年，每一块骨牌的倒下都带着前一块的力量，而最初推倒第一块骨牌的那只手——

"是周建平。"林琳说，说出了我正在想的那个名字。

"所有的事情，都可以追溯到他身上。"我说，"他是这一切的起点。如果他当年没有侵犯方苒，后面的一切都不会发生。如果赵德厚没有帮他掩盖，方苒也许能得到公正的对待。但赵德厚选择了保护他，王建国选择了执行，苏晴选择了沉默。一个又一个选择，像链条一样环环相扣，最终把一个十八岁的女孩逼上了绝路。"

"然后那些试图揭露真相的人，一个接一个地死了。"林琳的声音很轻，但每一个字都像钉子一样扎进空气里。

"王国强、陈向晚、马玉芬。"我念出这三个名字，"还有王建国——虽然他是帮凶，但他最终也死了。这些人里面，谁是凶手杀的，谁是苏晴杀的，谁又是别人杀的？我们现在能确定的，只有王建国是被苏晴杀的。但其他人呢？"

林琳低下头，看着那张密密麻麻的图纸。窗外的天色更暗了，宿舍里没有开灯，灰白色的光线从窗户照进来，把她的侧脸照得明暗分明。

"我有一个问题。"她慢慢地说，"方驰只承认杀了王建国——不，等等，方驰还没有被捕。苏晴承认杀了王建国。但王国强呢？王国强死在珍本室，那时候方驰还没有开始行动。如果方驰只杀了王建国——"

"那王国强是谁杀的？"我接上了她的话。

沉默。

这个问题像一颗石子投入了平静的水面，激起的涟漪一圈一圈地扩散开来。如果王国强不是方驰杀的，也不是苏晴杀的，那是谁？

"还有另一个问题。"林琳说，"陈向晚、马玉芬、赵德厚——他们的死，又是谁干的？"

赵德厚。我差点忘了这个名字。赵德厚是二〇一一年二月被杀的，距离现在不到一个月。他是中文系的教授，周建平的博导，方苒事件的主要掩盖者之一。他的死至今也没有侦破。

"如果把这些死亡事件排列出来，"我慢慢地说，"你会发现一个规律。每一个死掉的人，都和方苒事件有关。王国强在调查方苒事件。陈向晚在研究方苒事件。马玉芬发现了丈夫参与掩盖方苒事件的证据。赵德厚是方苒事件的掩盖者，但他知道太多的秘密。王建国是方苒事件的善后者，同样知道太多。"

"他们在灭口。"林琳说，"有人在系统性地消灭所有和方苒事件有关的知情人。"

"而这个人——或者这些人——的目的，是保护周建平。"

窗外的风更大了，梧桐树的枝条在风中摇晃，发出低沉的呜咽声。我望着那张写满名字的图纸，忽然觉得那些红色的线条像血管一样在纸面上蔓延，而所有的血管都汇聚到同一个心脏——

周建平。

"我们需要更多的证据。"我说，"仅凭推测是不够的。我们需要找到能够直接证明周建平犯罪的证据。"

"U盘。"林琳说，"苏晴交给我们的那个U盘，里面的关系网图只是表层。我总觉得还有更深层的文件没有被发现。"

"你检查过了吗？"

"检查过了，但加密层很复杂，我需要时间。"林琳说，"不过我有一个预感——陈向晚在死前一定做了充分的准备。她不是一个会轻易放弃的人。如果她在调查周建平，她一定会把证据藏在某个安全的地方。"

我点了点头。陈向晚——那个在新闻系以执着著称的研究生，那个为了真相不惜付出生命代价的女孩。她的死不是意外，而是谋杀。而她的论文、她的录音、她的笔记，都是她留给这个世界的最后证词。

"还有一件事。"林琳说，她的声音忽然变得很轻，"周建平的妻子——沈亦寒。"

"赵德厚的学生？"

"对。沈亦寒是赵德厚的硕士研究生，比周建平小两岁。他们是在赵德厚的介绍下认识的，二〇一〇年结婚。"林琳说，"我一直觉得奇怪——沈亦寒是赵德厚的学生，她知不知道赵德厚做了什么？她知不知道周建平的过去？"

"她可能知道，也可能不知道。"我说，"但如果她什么都不知道，那她就是一个被蒙在鼓里的无辜者。如果她知道——"

"那她就选择了沉默。"林琳说，"就像苏晴一样。"

就像苏晴一样。这句话像一根刺一样扎进了我的心里。苏晴选择了沉默，代价是三年的恐惧和逃亡。而沈亦寒呢？如果她知道丈夫的罪行却选择了沉默，她的代价又是什么？

"我想去见沈亦寒。"我说。

林琳看了我一眼，没有说话。但我知道她同意。

窗外的天色已经完全暗了下来。宿舍里没有开灯，只有电脑屏幕发出微弱的蓝光，照在林琳的脸上。她低下头，继续在那张图纸上添加新的线条和标注。我看着她的侧影，忽然想起第一次在法学院报到处见到她时的样子——扎着马尾辫，穿着白衬衫，笑起来眼睛弯弯的，像一弯新月。

而现在，她的眼睛里多了太多不属于十八岁女孩的东西。沉重、锐利、悲伤，还有一种近乎固执的坚定。

"林琳。"我叫她。

"嗯？"

"你害怕吗？"

她停下了笔，想了想，然后说："害怕。但如果害怕就能让方苒白死，那我宁愿不害怕。"

我笑了笑，虽然这个笑容里没有任何快乐的意思。

"好。"我说，"那我们继续。"

窗外的风在梧桐树的枝条间穿行，发出尖锐的呼啸声。三月的沧阳市还没有从冬天中苏醒过来，整个城市灰蒙蒙的，像一张褪了色的老照片。但我知道，春天总会来的。不管冬天有多长，春天总会来的。

而那些在冬天里死去的人，他们的真相，也总会有大白于天下的一天。

我拿起桌上那张写满名字的图纸，小心地折好放进口袋里。然后我打开了电脑，开始在新的文档里敲下第一行字：

"关于方苒事件及相关案件的调查笔记——张小雨。"

这将是一场漫长的战斗。但我不再是一个人了。

屏幕上的光标在闪烁，像一只不知疲倦的眼睛，注视着这个被谎言和沉默笼罩的世界。而在那些谎言和沉默的深处，真相正在一点一点地浮出水面，像冰层下的暗流，无声但不可阻挡。

我深吸了一口气，开始打字。

窗外的风渐渐停了。雾气还没有散去，但在雾气的深处，有什么东西正在改变。

就像春天来临之前的那些日子——表面上看，一切还是冬天的样子。但在泥土深处，在树根深处，在那些看不见的地方，种子正在发芽。

而我们，就是那些种子。
