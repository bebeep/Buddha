# 第七十八章 证据链

三月二十日到三月三十日。

接下来的十天，是我和林琳最忙碌的十天。

我们把所有的时间都投入到了证据链的构建中——上课、吃饭、睡觉之外的每一分钟，都被用来调查、分析、讨论。我们的"作战指挥部"就是图书馆三楼角落的那张桌子，桌上永远堆满了文件、笔记本和两台笔记本电脑。

第一步：确认陈向晚录音中男人的身份。

我们联系了学校信息工程系的音频分析实验室。实验室的负责老师姓吴，是一个沉默寡言的中年人，但对技术有着近乎偏执的热情。在听完录音之后，他告诉我们可以尝试用算法增强模糊音频的清晰度。

"原始录音的噪音很大，"吴老师说，"但人声的频率范围是可以分离的。给我三天时间。"

三天后，增强版的录音出来了。声音依然不算清晰，但比之前好了很多。我把增强版录音发给了沈亦寒——通过一个安全的、匿名的方式。

第二天，沈亦寒回复了。只有一句话：

"是周建平的声音。"

我的心跳加速了。

沈亦寒的辨认不能直接作为法庭证据——但她提供了一个关键的线索：录音中的男人很可能就是周建平。如果结合陈向晚的调查笔记——笔记中提到的"那个人"——就能形成一个间接但有力的证据：周建平在陈向晚死前一个月曾经和她有过对话，并且在对话中试图阻止她继续调查。

第二步：珍本室的秘密。

方驰在被捕前发来的邮件提到了"珍本室的墙壁里"。我一直不明白这句话的意思。直到三月二十五日，马国栋队长主动联系了我。

"张小雨，"他的声音听起来很复杂，"你之前说珍本室有东西？"

"方驰的邮件提到了。"

"我们去了。"马国栋说，"珍本室的墙壁里——准确地说，是珍本室一面书架后面的墙壁夹层中——我们发现了一个信封。"

"信封里是什么？"

"几份文件。"马国栋说，"其中包括一份二〇〇八年的内部通信记录——赵德厚和王建国之间关于如何处理方苒事件的邮件打印件。还有——"

他停了一下。

"还有什么？"

"一份手写的笔记。笔迹初步鉴定属于王国强。"

王国强的笔记。他在死前把一些关键文件藏在了珍本室的墙壁里——他知道有人在监视他，他知道自己的调查可能让他丧命，所以他提前把证据藏了起来。

"笔记里写了什么？"

"很多内容。"马国栋说，"其中最关键的是一段记录——王国强在调查过程中发现，周建平在方苒死后曾经多次联系王建国，要求'确保所有痕迹被清除'。这里用了原话——'确保所有痕迹被清除'。"

"这是周建平指使王建国销毁证据的直接记录。"

"对。虽然不是周建平本人的供述，但结合其他证据——"

"可以构成间接证据链的一环。"

"你越来越像律师了。"马国栋的语气里有一丝苦涩的笑意。

第三步：财务记录。

方驰给我的笔记本中包含了晴光文化传媒的财务记录——那些显示公司注册材料可能造假的数据。林琳花了三天时间对这些数据进行了详细的分析。

"晴光文化传媒的注册资金是一千万。"林琳说，"注册文件上写着资金来源是'恒远投资'。但恒远投资在二〇〇五年就已经注销了。"

"这意味着注册资金可能是虚假的。"

"不只是虚假。"林琳说，"我查了晴光文化传媒的银行账户。公司成立后，有一笔一千万的入账，来源是一家叫做'鼎盛贸易'的公司。鼎盛贸易的法定代表人——"

"是谁？"

"是一个叫李国富的人。李国富是周建平的大学同学，也是晴光文化传媒的联合创始人。"

"所以真正的资金来源是鼎盛贸易，不是恒远投资。"

"对。他们故意在注册文件中使用了已经注销的恒远投资的名字，目的是——"

"掩盖真正的资金来源。"

"对。如果鼎盛贸易的资金来源也是不透明的，那这条线索就断了。但如果我们能证明鼎盛贸易的资金最终来自周建平的个人账户——"

"就能证明周建平在注册时使用了虚假材料。"

"这是经济犯罪。"林琳说，"虽然和杀人案无关，但它能证明周建平有欺骗和隐瞒的行为模式。在法庭上，这种行为模式可以作为辅助证据。"

第四步：沈亦寒的证词。

这是最关键也最困难的一步。沈亦寒需要把她知道的一切正式说出来——不是私下对我说的，而是在律师在场的情况下，以正式证词的形式记录下来。

我通过一个可靠的中间人——法学院的一位教授——联系到了一位愿意帮助沈亦寒的律师。律师姓韩，是一个专门处理家庭暴力案件的女律师，正义感很强。

韩律师告诉我，沈亦寒在经过长时间的心理挣扎后，终于同意作证。

"她说了一句话让我印象深刻。"韩律师在电话里对我说，"她说——'我已经沉默了四年。我不能再沉默了。不是为了我自己，是为了那个死去的女孩。'"

沈亦寒的证词包括以下内容：

一、她确认周建平在二〇〇八年侵犯了一名文学社的女学生（方苒），并且赵德厚帮助周建平掩盖了此事。

二、她确认周建平在方苒死后没有任何悔意，曾经说过"可惜了，她本来可以活得好好的"。

三、她确认周建平在二〇一〇年之后利用虚假的注册材料创办了晴光文化传媒。

四、她确认周建平在日常生活中表现出极强的控制欲，包括监控她的通讯、限制她的社交、威胁她不得泄露任何关于他的信息。

五、她确认周建平在二〇一一年初曾经多次深夜接打电话，语气紧张，她隐约听到了"王国强"、"陈向晚"等名字。

第五点是最关键的——沈亦寒听到周建平在电话中提到王国强和陈向晚的名字。这不能直接证明周建平杀了他们，但能证明周建平在那些人死前知道他们的存在，并且在为某些事情感到紧张。

结合其他证据，这就构成了一条完整的间接证据链：

周建平侵犯方苒 → 赵德厚掩盖 → 王建国善后 → 方苒自杀 → 王国强调查 → 王国强被杀 → 陈向晚调查 → 陈向晚被杀 → 马玉芬发现秘密 → 马玉芬被杀 → 赵德厚知道太多 → 赵德厚被杀。

每一个环节都有至少一项证据支持。虽然每一项证据单独来看都不是"铁证"，但当它们组合在一起时，就形成了一个强大的、排他性的逻辑链条——所有的线索都指向同一个人：周建平。

三月三十日晚上，我和林琳坐在图书馆的自习室里，面前摊着最终的证据链文件。

"十条主线。"林琳数了数，"二十七项证据。每一条都有来源和佐证。"

"够吗？"

"在法律上，"她想了想，"应该够了。间接证据形成的完整链条，能够排除合理怀疑。当然，最终的判定要由法庭来做。"

"周建平的律师一定会反驳。"

"当然。他们会攻击每一项证据的可信度，试图在链条上制造断裂。但我们的链条足够坚固——每一条都有多重佐证，即使其中一条被攻破，其他的依然成立。"

我点了点头。

"还有一件事。"林琳说，"你父亲的部分。"

" included."我说，"校董会的会议纪要、他的签名、他在会议中的角色——都包括在内。"

"你确定？"

"确定。"

她看着我，眼神里有一种我熟悉的东西——不是同情，而是尊重。

"张小雨，"她说，"你比我想象的更勇敢。"

"我不是勇敢。"我说，"我只是不想再沉默了。"

窗外的夜色深沉而安静。校园里的路灯在黑暗中排成一列，像是一串发光的省略号，指向某个未知的、但终将到来的明天。

我把证据链文件小心地整理好，放进了一个文件夹里。

"准备好了。"我说。

"嗯。"林琳说，"准备好了。"

我们对视了一眼。在那个眼神中，有疲惫、有紧张、有期待，还有一种更深层的东西——一种在经历了太多之后才能产生的、无言的默契。

明天。

明天就是最后的战役了。
