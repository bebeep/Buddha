# 第七十七章 抉择

三月十九日，星期六。

春天的脚步终于快了起来。校园里的柳树已经长出了嫩绿的叶子，在微风中轻轻摇曳。人工湖边的草地也从枯黄变成了浅绿，像是一块正在被重新上色的画布。

但我的心情并没有因为春天的到来而轻松多少。

上午十点，我和林琳在图书馆的自习室里碰面。我把我的决定完整地告诉了她——包括我父亲的部分，包括我回家质问父亲的经过，包括我最终的抉择。

林琳听完后，沉默了很久。

"你父亲……"她斟酌着措辞，"他会配合吗？"

"他没有拦我。"我说，"但他也不会主动站出来。他选择了沉默——就像他三年前选择沉默一样。"

"那你打算怎么——"

"我不需要他主动站出来。"我说，"我只需要把证据提交给警方和相关部门。证据会替我说话。"

林琳点了点头。然后她说了一句让我意外的话：

"但我们要等时机。"

"等什么时机？"

"如果我们现在只揭露你父亲，"她分析道，"周建平会趁机脱身。因为所有人的注意力都会集中在你父亲身上——一个校董参与掩盖丑闻，这是爆炸性的新闻。周建平可以利用这种注意力转移来销毁证据、串供、甚至逃跑。"

"所以你的意思是——"

"我们需要把周建平的罪行也一并坐实。"林琳说，"同时揭露。让他们的罪行像一张网一样被完整地展开，谁也跑不掉。"

我想了想，她说得对。

"但问题是，"我说，"我们对周建平的直接证据还不够。我们有动机、有关系网、有时间线，但缺乏直接证明他杀人的证据。"

"所以我们需要两周时间来补全证据链。"

"对。马国栋给了我们两周。"

林琳从包里拿出了那张图纸，摊在桌上。我们用笔在图纸上标注了所有已知证据和缺失证据的位置。

"已知的。"林琳用绿色笔标注，"苏晴的供述——证明周建平侵犯方苒、赵德厚掩盖、王建国善后。陈向晚的录音——证明有人在阻止调查。校董会会议纪要——证明你父亲参与掩盖。刘教授的证词——证明周建平的人格特征和历史行为。沈亦寒的证词——证明周建平的真实性格。方驰的笔记本——证明周建平的财务问题。"

"缺失的。"她用红色笔标注，"直接证明周建平杀人的证据。王国强死亡的真正凶手。陈向晚死亡的真正凶手。马玉芬死亡的真正凶手。赵德厚死亡的真正凶手。"

"四个未破的杀人案。"我说，"每一条都指向周建平，但没有一条有直接证据。"

"直接证据包括——"林琳掰着手指数，"目击证人、物证、DNA、监控录像、凶手的供述。这些我们一个都没有。"

"那怎么办？"

"用间接证据构建完整的证据链。"林琳说，"间接证据在法律上同样有效——只要它们能够形成一个完整的、排他性的逻辑链条，排除一切合理怀疑。"

"怎么构建？"

"让我来。"林琳拿起笔，在图纸的空白处画了一个流程图。

"首先，动机。周建平有杀人的动机——每一个死者都和方苒事件有关，都在威胁着周建平的秘密。这是第一环。"

"第二，能力。周建平有杀人的能力——他有钱、有人脉、有资源。他可以雇人，也可以亲自动手。他的公司在多个地点有分支机构，他经常出入各种场所，行踪难以追踪。"

"第三，机会。"我在旁边补充，"王国强死在珍本室，珍本室的监控恰好在那天晚上'故障'了。如果周建平有能力篡改监控记录，他就有了作案的机会。"

"第四，行为模式。"林琳说，"每一个死者的死法都有相似之处——钝器击打后脑。这说明凶手可能是同一个人，或者至少使用的是同一种手法。"

"但苏晴杀王建国用的也是钝器。"我说，"如果凶手是同一个人，那苏晴和那个凶手之间是什么关系？"

"也许没有直接关系。"林琳说，"也许苏晴杀王建国是出于自己的动机——报仇、恐惧、或者某种更复杂的原因。而另一个凶手杀其他人是出于周建平的指使。两条线平行运行，互不干扰。"

"两条线。"我重复了这个说法，"一条是苏晴的复仇线，一条是周建平的灭口线。两条线在王建国这个点上交叉。"

"对。王建国是唯一一个被两个人都'杀'了的人——当然，实际上只有一个人杀了他。苏晴和方驰都声称杀了王建国。"

"这是一个矛盾。"

"对。这个矛盾需要解决。"

我们讨论了很长时间。窗外的阳光从上午移到了下午，自习室里的人来了又走了，只有我们一直坐在那里，对着那张图纸反复推敲、争论、修改。

到下午四点的时候，我们终于形成了一个初步的证据链框架：

一、周建平在二〇〇八年侵犯方苒。（证据：苏晴供述、方苒日记、方苒室友证词）

二、赵德厚帮助周建平掩盖真相。（证据：苏晴供述、校董会会议纪要、刘教授证词）

三、王建国负责善后，包括截获方苒遗书、威胁知情者。（证据：苏晴供述、校董会会议纪要）

四、张建国参与舆论管控。（证据：校董会会议纪要）

五、方苒在二〇〇九年一月自杀。（证据：死亡证明、方苒母亲证词）

六、王国强在调查方苒事件时被杀。（证据：死亡证明、珍本室现场记录、监控故障记录）

七、陈向晚在调查方苒事件时被杀。（证据：死亡证明、陈向晚论文和笔记、录音）

八、马玉芬在发现丈夫秘密后被杀。（证据：死亡证明、王建国保险箱内容）

九、赵德厚被杀。（证据：死亡证明）

十、王建国被苏晴所杀。（证据：苏晴供述）

"十环。"林琳数了数，"十条证据链。其中一、二、三、四、五比较扎实，有直接证据支持。六到九比较薄弱，主要是间接证据。十有苏晴的供述，但和方驰的供述有矛盾。"

"六到九是关键。"我说，"如果我们能把六到九的证据补强，整条证据链就完整了。"

"怎么补强？"

"找证人。找物证。找任何能够把周建平和这四起死亡直接联系起来的东西。"

林琳想了想说："陈向晚的录音——那段录音中的男人，如果能确认身份，就能证明有人在陈向晚死前试图阻止她。如果那个男人是周建平——"

"那就能证明周建平有直接的杀人动机和行为。"

"但录音中的声音太模糊了。"

"也许可以用技术手段增强。"我说，"学校的信息工程系有音频分析实验室。如果我们能找到认识周建平声音的人来辨认——"

"沈亦寒。"林琳说，"她能辨认出周建平的声音。"

"对。沈亦寒和周建平生活了四年，她一定能辨认出他的声音。"

"但她愿意吗？"

"这需要说服她。"

我们在自习室里一直待到傍晚。夕阳的余晖透过窗户照进来，把图纸上的线条染成了金色。

"张小雨，"林琳忽然说，"这是最后的战役了。"

"嗯。"

"等这一切结束——"她停了一下，"你想做什么？"

我看着她。夕阳的光照在她的脸上，把她的轮廓勾勒成一幅温暖的画。她的眼睛里有光的碎片，像两颗小小的星星。

"等这一切结束，"我说，"我有话跟你说。"

"什么话？"

"到时候再说。"

她笑了笑。那个笑容在夕阳中显得格外温柔——不是平时那种锐利的、充满战斗精神的笑，而是一种柔软的、带着些许羞涩的笑。

"好。"她说，"那我等。"

我们收拾好东西，走出了图书馆。外面的校园在暮色中安静而美丽。柳树在风中轻轻摇摆，人工湖面上泛着金色的波光。远处的教学楼在夕阳中变成了黑色的剪影，像是一座座沉默的纪念碑。

我和林琳并肩走在回宿舍的路上。我们没有说话，但那种沉默不是尴尬的——而是一种舒适的、温暖的、两个人之间不需要语言就能理解的沉默。

我知道前面的路还很长。证据链还没有完成，周建平的反击还在继续，马国栋给的两周期限正在一天天缩短。但在此刻，在这个春天的傍晚，走在我身边的这个人——她的存在本身就是一种力量。

一种让我相信正义终将到来的力量。
