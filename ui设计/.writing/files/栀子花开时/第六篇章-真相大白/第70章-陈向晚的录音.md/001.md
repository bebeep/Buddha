# 第七十章 陈向晚的录音

三月九日，星期三。

回到宿舍后，我把沈亦寒告诉我的话全部转述给了林琳。她听完后沉默了很久，手指无意识地在桌面上敲击着，像是在弹奏一首听不见的曲子。

"她愿意作证吗？"林琳最终问。

"不确定。"我说，"她很害怕。那种恐惧不是装出来的——她在周建平身边生活了四年，那种恐惧已经渗进了骨头里。"

"但她知道真相。"

"对。她知道真相，但她不敢说出来。"

林琳站起身，走到窗边。暮色正在降临，校园里的路灯一盏接一盏地亮了起来，在灰蓝色的暮光中像一串发光的珠子。

"U盘里的东西，"她忽然说，"我还需要再检查一遍。那个音频文件——陈向晚的录音——我觉得有些细节被我们忽略了。"

"什么细节？"

"你听。"

她打开电脑，找到那个音频文件，按下播放键。

沙沙的噪音从扬声器里传出来，像是一阵微弱的风。然后是陈向晚的声音——清晰的、带着某种压抑的紧张感：

"……你为什么要帮她隐瞒？"

然后是那个男人的声音，模糊但能辨认出中年男性的音色：

"你不懂，有些事情不是你想的那么简单。"

"但她是被冤枉的。"

沉默。然后：

"向晚，你不要查了，太危险了。"

录音结束。

"注意这里。"林琳说，她暂停了播放，把进度条拖回到录音的开头，"在陈向晚说话之前，有一段环境音。你听到了吗？"

我凑近电脑，仔细听。在沙沙的噪音之下，确实有另一种声音——很微弱，但很有规律。

"像是……钟声？"我说。

"对。"林琳说，"是钟声。而且不是普通的钟声——是那种老式座钟的报时声。你数一下。"

我闭上眼睛，集中注意力。叮——叮——叮——叮——叮——叮。

"六下。"我说，"六点。"

"对。下午六点。"林琳说，"这段录音是在下午六点录的。陈向晚在六点的时候和某个男人在对话。"

"这能说明什么？"

"说明很多。"林琳说，"首先，陈向晚在录音之前一定做了准备。她知道要去见那个人，她知道对话可能会有价值，所以她打开了录音设备。这不是偶然的录音，而是有预谋的。"

"她去找了那个人。"

"对。而且她问了一个非常具体的问题——'你为什么要帮她隐瞒？'这个'她'指的是方苒。陈向晚在质问那个人为什么帮周建平隐瞒方苒事件。"

"那个人的回答——'有些事情不是你想的那么简单'——这意味着什么？"

林琳想了想说："有两种解读。第一种：他确实在帮周建平隐瞒，但他有自己的理由——也许是被迫的，也许是有苦衷的。第二种：他不是在帮周建平隐瞒，而是在帮另一个人隐瞒。"

"另一个人？"

"想想看。"林琳说，"方苒事件的掩盖不是一个人完成的。赵德厚是主谋，王建国是执行者，苏晴是被迫沉默者。但还有其他人——那些在会议上选择沉默的教师们，那些签了'保密协议'的行政人员。也许那个人也是其中之一。"

"一个有苦衷的沉默者。"

"对。而且——"林琳的眼睛亮了一下，"注意他说的话。'向晚，你不要查了，太危险了。'这句话的语气不像是威胁，更像是……担心。"

"担心陈向晚的安全？"

"对。如果他是周建平，他不会用这种语气说话。周建平是一个控制欲极强的人，他如果要威胁陈向晚，会用更直接的方式。但这句话——'太危险了'——听起来像是一个知道内情的人在真心劝告陈向晚不要冒险。"

我靠在椅背上，让这些信息在脑海中沉淀。

"你觉得那个人不是周建平？"

"我不确定。"林琳说，"声音太模糊了，我无法辨认。但从语气和措辞来看，我更倾向于认为那个人不是周建平。"

"那是谁？"

"我有一个猜测。"林琳说，"但需要验证。"

她没有说她的猜测是什么。我看了她一眼，她的表情很专注，像是在心里反复推敲某个想法。我知道她不会在没有把握的时候说出猜测，所以我也没有追问。

"还有一件事。"林琳说，"我检查了录音文件的元数据——就是文件本身携带的技术信息。这个录音是用一种特定型号的手机录的。二〇一〇年，使用这种手机的型号不多。"

"你查到了什么？"

"陈向晚的遗物清单里有一部手机，型号和录音文件的元数据匹配。"林琳说，"这证明录音确实是陈向晚用自己的手机录的。"

"但陈向晚的遗物不是应该在警方的证物室里吗？我们怎么会有她的录音文件？"

"U盘。"林琳说，"苏晴交给我们的U盘。陈向晚在死前把一些重要的文件复制到了U盘上，然后交给了苏晴保管。苏晴不知道U盘里有什么——或者她知道，但她没有告诉我们。"

"苏晴知道U盘里有这段录音吗？"

"我问过她。"林琳说，"在审讯室里。她说她只知道U盘里有一些文件，但没有仔细看过。她把U盘藏在了一个安全的地方，然后……然后就是后来的事情了。"

我点了点头。苏晴——那个在恐惧中生活了三年的女人——她保管着陈向晚留下的证据，却不知道那些证据的具体内容。这是多么讽刺的一件事。

"让我再听一遍。"我说。

林琳重新播放了录音。这一次，我闭上眼睛，把所有的注意力都集中在声音上。

陈向晚的声音先出现。她说话时带着一种克制的愤怒——不是那种爆发式的愤怒，而是一种被理性压制着的、随时可能冲破堤坝的愤怒。

"……你为什么要帮她隐瞒？"

然后是那个男人的声音。他的声音比上次听的时候感觉更清晰了一些——也许是因为我已经习惯了录音的噪音，大脑自动过滤了背景杂音。

"你不懂，有些事情不是你想的那么简单。"

他的语速不快，每个字都说得很清楚。但声音里有一种疲惫感——不是身体的疲惫，而是精神的疲惫，像是一个背负了太久重担的人。

"但她是被冤枉的。"陈向晚说。

然后是沉默。这段沉默大约有五六秒钟。在这段沉默中，我能听到背景里的钟声——叮——叮——叮——叮——叮——叮。六下。下午六点。

然后男人说："向晚，你不要查了，太危险了。"

"太危险了。"我重复了这三个字，"他在告诉她，继续查下去会有危险。这个危险来自谁？来自周建平？还是来自其他人？"

"也许两者都是。"林琳说，"如果那个人知道周建平曾经对方苒做了什么，他就应该知道周建平有能力让一个人消失。他劝陈向晚不要查了，也许真的是在保护她。"

"但陈向晚没有听。"

"对。然后她就死了。"

沉默在我们之间蔓延开来。窗外的夜色已经完全降临了，路灯的光透过窗帘的缝隙照进来，在地板上画出一条细细的光线。

"林琳，"我说，"你觉得那个男人是谁？"

她犹豫了一下，然后说："我有一个猜测。但我不确定。"

"说吧。"

"赵德厚。"

我愣了一下。"赵德厚？但赵德厚是方苒事件的主要掩盖者。他为什么要帮周建平隐瞒？"

"也许不完全是帮周建平。"林琳说，"也许他是在保护自己。如果方苒事件被揭露，不仅周建平会完蛋，赵德厚自己也会完蛋——因为他参与了掩盖。他劝陈向晚不要查了，可能不是为了保护周建平，而是为了保护他自己。"

"但陈向晚是他的学生。他叫她的名字'向晚'，语气里带着关心。"

"那正是矛盾所在。"林琳说，"赵德厚可能真的关心陈向晚——作为一个老师关心自己的学生。但他同时也在保护自己的利益。这两种感情在他身上同时存在，互相矛盾，但又同时真实。"

"所以他的回答——'有些事情不是你想的那么简单'——可能是在说，他参与掩盖方苒事件有他自己的苦衷。"

"对。也许他认为自己别无选择。也许他认为保护周建平就是保护学校，保护学校就是保护所有人。"

"一种扭曲的逻辑。"

"对。但在他的世界观里，这种逻辑可能是自洽的。"

我沉默了。赵德厚——那个已经死了的教授——他的形象在我脑海中变得更加复杂了。他不是一个简单的"坏人"。他是一个在权力和良知之间做出了选择的人，而他选择了权力。但那个选择是不是真的像他想象的那样"别无选择"？

"还有一件事。"林琳说，她打开了U盘里的另一个文件——一份文档，"陈向晚的调查笔记。你看这里。"

她把电脑转向我。屏幕上是一段手写的笔记扫描版，字迹潦草但能辨认：

"三月十二日。和K见面。他说不能再继续了。他说上面有人施压，要求停止一切调查。我问他是谁施压，他不说。他只说'你不懂这个圈子的规则'。"

"K是谁？"我问。

"不知道。陈向晚在笔记里用字母代替了某些人的名字。K是其中之一。"

"K……赵德厚的拼音首字母是ZDH。周建平的首字母是ZJP。王国强是WGQ。都不匹配K。"

"也许K不是用拼音首字母。"林琳说，"也许是英文名，也许是某种代号。"

"继续看。"

林琳翻到下一页：

"三月十五日。K又来了电话。他说他收到了一封匿名信，信里警告他不要和我接触。他很害怕。他说如果他和我之间的联系被发现，他的处境会很危险。"

"K害怕了。"我说，"有人发现了K和陈向晚之间的联系，并且用匿名信来警告K。"

"然后呢？"

林琳翻到下一页：

"三月二十日。我决定直接去找那个人。我要当面质问他。我知道这很冒险，但我不能继续等下去了。方苒不能继续被冤枉。"

"那个人"——陈向晚要去找的"那个人"是谁？

"如果'那个人'就是录音中的男人，"我说，"那这段录音就是陈向晚去找他时录的。"

"对。"林琳说，"录音的时间是下午六点，地点不确定，但很可能是某个安静的室内场所。陈向晚提前打开了手机录音，然后去见了那个人。"

"她问那个人为什么要帮周建平隐瞒。"

"对。然后那个人回答了她，并且劝她不要查了。"

"然后一个月后，陈向晚就死了。"

"对。"

我们沉默了。窗外的夜色深沉得像一潭墨水，只有远处偶尔传来的汽车喇叭声打破这种寂静。

"林琳，"我说，"你觉得K和录音中的男人是同一个人吗？"

"很可能是。"她说，"笔记里的K和录音中的男人都表现出同样的特征——知道内情，感到害怕，想要退出但又无法完全脱身。"

"如果K就是赵德厚——"

"那一切就说得通了。"林琳接过我的话，"赵德厚是方苒事件的掩盖者，但他同时也在暗中感到不安。陈向晚是他的学生，她在调查方苒事件，这让他陷入了两难——他既要保护自己和周建平，又不想看到自己的学生走上危险的道路。所以他一边劝陈向晚放弃，一边继续维持着那个谎言。"

"但最终，陈向晚的死还是发生了。"

"对。而且——"林琳的声音低了下去，"如果赵德厚真的是K，那他自己的死也就有了另一层含义。"

"什么含义？"

"赵德厚死在二〇一一年二月。他的死因是——"

"中毒。"我说，"一种罕见的植物毒素。"

"对。如果周建平在杀了陈向晚之后，意识到赵德厚也知道太多——毕竟赵德厚是整个掩盖行动的核心——那他就有理由把赵德厚也除掉。"

"一个接一个。"我说，"知道真相的人，一个接一个地死去。"

"直到只剩下周建平一个人。"

"但他忘了一个人。"我说，"方驰。"

"方驰还在逃。"

"但他还在调查。"我说，"而且他和我保持着联系。"

林琳看着我，眼睛里有一种复杂的光。

"张小雨，"她忽然说，"你有没有想过——如果我们也继续查下去，我们也会变成'知道太多的人'？"

"想过。"

"你不怕吗？"

我看着她。路灯的光透过窗帘的缝隙照在她的脸上，把她的轮廓勾勒成一条明亮的线和一条暗影。

"怕。"我说，"但如果怕就能让方苒白死，那我宁愿不怕。"

她笑了一下。那个笑容很浅，但很真实。

"你什么时候变得这么会说话了？"

"跟你学的。"

她轻轻推了我一下，然后低下头，继续查看U盘里的文件。

我靠在椅背上，闭上眼睛。陈向晚的声音还在我的耳边回荡——"但她是被冤枉的"——那么简单的一句话，却用一条人命来作为注脚。

那个录音中的男人，不管他是谁，他选择了沉默。赵德厚选择了沉默，苏晴选择了沉默，沈亦寒选择了沉默。沉默像一种慢性毒药，一点一点地侵蚀着真相，直到真相被埋葬得足够深，深到没有人能够找到。

但他们忘了一件事。

种子被埋在泥土里，不是因为死亡，而是因为生长。

真相也是。

它被埋葬了，但它没有死。它在黑暗中等待着，等待着某一个春天，等待着某一只手，把它从泥土中挖掘出来，让它重新见到阳光。

而我和林琳，就是那双手。

窗外的风停了。夜色深沉而安静，像一块巨大的黑色幕布，覆盖着整个沧阳市。在这块幕布之下，有人在沉睡，有人在恐惧，有人在谋划，也有人在寻找真相。

我睁开眼睛，看着林琳的侧影。她还在电脑前忙碌着，屏幕的蓝光把她的脸照成了一种冷静的银白色。

"林琳。"

"嗯？"

"等这一切结束，你想做什么？"

她想了想，说："去方苒的墓前放一束花。"

"什么花？"

"栀子花。"她说，"她最喜欢的花。"

我点了点头。窗外，一阵微风拂过，把窗帘吹起了一个小小的弧度。在那一瞬间，我看到远处的天际线上有一丝微光——不是黎明，只是城市的灯光在夜空中反射出的一抹淡淡的光晕。

但对我来说，那已经足够了。
