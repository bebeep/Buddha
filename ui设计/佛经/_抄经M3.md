# 抄经（选字模式）实现说明

> 不写字。格子上半格淡色列原文，用户从底部四个选项里挑出当前字，填进下半格。
> 代码：`uilib/.../fragment/book/FojingCopyFragment.kt`、`adapter/FojingCopyAdapter.kt`、`viewmodel/CopyVM.kt`

## 一、交互流程

```
进抄经页(bookId)
  ├─ 目录（Room → 网络）           book_info 的字数用来算百分比
  ├─ 进度（网络 → 断网用 Room）     lastCopySeq / lastCopyOffset / copiedChars
  └─ 正文（Room 先上屏 → 网络比对 contentHash）
        ↓
   切成格子：只收汉字，标点空白不进格；每格记住它在正文里的字符下标
        ↓
   定位：服务端 charOffset → 本章第几个汉字（逐字扫一遍数汉字）
        ↓
   一屏 = row × column 格（沿用原设计 40dp × 80dp，(高-30dp)/85dp × (宽-32dp)/40dp）
        ↓
   点选项 → 对：填格 + 游标前进；错：按钮抖一下，原地重来
        ↓
   本屏抄满 → 自动换下一屏      本章抄完 → 自动进下一章（toast 提示）
```

- 当前待抄的格用红框米字格 `bg_fojing_copy_answer`，其余格是淡虚线 `bg_fojing_copy_item`。
- 上半格范字 `textColor=#4D2C1900`（淡），下半格用户选的字是纯黑 30sp。
- 抄完一屏不保留上一屏内容（一屏一屏往前推）；中断后从「下一个字」继续。

## 二、四个选项怎么来

| 位置 | 内容 |
| --- | --- |
| 1 个 | 正确答案 |
| 3 个 | 本章出现过的其他字（去重后随机），不足时用常用字池兜底 |
| 顺序 | 每换一格重新洗牌 |

同一格点错不会换选项（避免乱跳）。干扰项目前是**随机字**，不是形近字——要形近得靠字形/部件数据，留到读音库那一版再说。

## 三、进度怎么记

抄经是单调游标，没有区间合并问题。

- 本地：`book_copy_progress`（bookId 主键 + lastCopySeq + lastCopyOffset + copiedChars）。
- 服务端：`book_reach_record`，`chars` 传**增量**，服务端累加；`lastCopySeq/lastCopyOffset` 覆盖写；
  `copyPercent` 由服务端按 (本章前累计字数 + charOffset) / book_info.charCount 算，只取更大值。
- 上报时机：每抄满 20 字、抄完一章、`onPause`（退出/切后台）。
- 上报 offset = 当前待抄字在正文里的**字符下标**（与读经 lastReadOffset 同一口径）。
- 正文字符下标 ↔ 第几个汉字 的换算只在客户端做（`hanIndexAt`），不入库。

## 五、边界处理

- 进度里的章已不存在（正文更新过）→ 退回第一章。
- 本章切不出汉字（全是标点）→ 跳过进下一章。
- 正文没加载完就退出 → 不上报（避免把已有进度冲成 offset 0）。
- 章节网络回调晚于本地缓存 → 同章只构建一次，不打断正在抄的位置。
- 同章网络返回新正文（hash 变化）→ 忽略，避免格子错位。

## 六、上一屏回看 / 单字跳过

- **上一屏 / 下一屏**（信息栏左右两个小字）：只能往回看到已抄过的屏，`viewStart < cursorScreenStart` 时信息栏标「回看」，
  四个选项置空防止误抄，点「下一屏」回到当前抄写屏。回看用 `showScreen(start)` 重铺，
  已抄格显示原文（`i < cursor` 保留字），不改变游标。
- **单字跳过**：长按当前格 → 该格字变浅灰、`skipped` 标记、游标前进，`skippedChars` 增量上报。
  跳过的字不计 `copiedChars`，但位置照样往前。回看状态下不可跳。

## 七、抄经显示设置（存服务端）

表 `book_copy_setting`（一账号一行，重复保存用 `ON DUPLICATE KEY UPDATE` 覆盖）：

| 字段 | 含义 |
| --- | --- |
| `id` | 主键 |
| `accountId` | 账号 id，唯一索引 `uk_accountId` |
| `defaultColor` | 原文颜色编号 1-4 |
| `copyColor` | 抄文颜色编号 1-4 |
| `backgroundColor` | 背景编号 1-4 |
| `fontSizeLevel` | 字号档位 1-4，3 = 30sp（默认） |
| `createDate` / `updateDate` | 时间 |

接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/book/getCopySetting?session=` | 没记录时返回默认值（1/1/1/3），不插库 |
| POST | `/book/updateCopySetting` | body 4 个字段，编号必须是 1-4，否则 `FUCK_YOU`；保存后回读整条返回 |

客户端映射（`BookCopySetting` 伴生对象，色值与 `bg_text_color_1~4` / `bg_color_1~4` 一致）：

- 原文色 4 档：#2C1900 / #FF9600 / #51B23D / #AAAAAA，**固定 30% 不透明度**（设置只调色相）
- 抄文色 4 档：同上，不透明
- 背景 4 档：#FFFEFA / #2C1900 / #4DD3E1C6 / #4DEAE3D9；选深色（2）时标题和图标自动反白
- 字号 4 档：22 / 26 / 30 / 34 sp

交互：弹窗里点一下**立即在抄经页生效**（onPreview），关闭弹窗才发一次保存请求（onSave），避免连点触发 `@RepeatSubmit`。
进抄经页时拉一次设置，失败就用默认样式，不影响抄写（设置不落本地）。
