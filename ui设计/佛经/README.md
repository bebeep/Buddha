# 佛经语料库

从 CBETA 电子佛典集成（《大正新脩大藏經》）抓取的佛经正文，按 1000 字切片，供 App 入库使用。

- 收录：**32 部** / **342 卷** / **3,163,086 字**（含标点）
- 切片：每部 3,870 段（繁简各一份，磁盘上共 7,740 个 txt）
- 生成日期：2026-10-20

## 目录结构

```
佛经/
├── _manifest.csv                 # 全部经目总表
├── _schema.sql                   # 建表脚本（sutra / sutra_chapter / 进度表）
├── _import.py                    # 一键入库脚本
├── 001_般若波罗蜜多心经_T0251/
│   ├── _meta.json                # 该经元数据（译者、朝代、字数、来源）
│   ├── _index.csv                # 每个 txt 的卷/品/字数/字符区间
│   ├── 繁體原文/                  # 大正藏原文
│   │   ├── 卷01_正文_0001.txt
│   │   └── ...
│   └── 简体/                      # OpenCC t2s 转换
│       ├── 卷01_正文_0001.txt
│       └── ...
└── 002_金刚般若波罗蜜经_T0235/
    └── ...
```

文件夹名 = `序号_简体经名_CBETA编号`。

## 文件命名规则

```
卷01_品02_方便品第二_0003.txt
 │    │   │          └── 该小节内第 3 个 1000 字片段
 │    │   └───────────── 品名（经名前缀已去除）
 │    └───────────────── 品序，全书连续编号（不是卷内编号）
 └────────────────────── 卷号
```

四种小节前缀：

| 前缀 | 含义 |
|---|---|
| `正文` | 该卷未分品的正宗经文 |
| `品NN` | 分品经文，NN 为全书连续品序 |
| `序NN` | 经序（御制序、弘传序等，非经文） |
| `附NN` | 其他附录 |

## 切片规则

- 每片目标 **1000 字**，字数含标点、不含空白与换行
- 优先在句末（`。！？；…`）断开，找不到就上浮，硬上限 1400 字
- 保留大正藏原始行断（一行约 17–20 字），所以 txt 是短行，便于抄经按行定位
- 不含任何标题、序号、页眉——txt 里只有纯正文

## _index.csv 字段

| 字段 | 说明 |
|---|---|
| `file` | 文件名 |
| `juan` | 卷号 |
| `juan_title` | 卷题 |
| `section_seq` | 卷内小节序号 |
| `section_kind` | 正文 / 品 / 序 / 附 |
| `section_title` | 小节标题 |
| `part` | 该小节内第几片 |
| `chars` | 本片字数（含标点） |
| `char_start` / `char_end` | 本片在该卷内的字符偏移区间 |

`char_start` / `char_end` 就是上一轮讨论的**抄经进度定位**要用的偏移量，导入时一并进库。

## 入库建议

已附两个文件，直接用：

```bash
mysql -u root -p buddha < _schema.sql
pip install pymysql
python _import.py --user root --password xxx --db buddha
```

`_schema.sql` 建了 6 张表：`sutra`（经目）、`sutra_chapter`（正文）、`sutra_asset`（附件 URL）、
`user_reading_progress`、`user_copy_session`、`user_copy_progress`。

`_import.py` 按目录逐个导入，一个 txt 一条 `sutra_chapter`，简繁双列并存，重复导入会覆盖同 `work_no`。

手动导入的话，字段对应关系：

```sql
INSERT INTO sutra_chapter
  (sutra_id, seq, juan_no, juan_title, section_kind, section_title, part_no,
   content, content_trad, char_count, char_start, char_end)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?);
```

- `content` 用 `MEDIUMTEXT`，`chars` 直接用 csv 里的值，不必重算
- 简体、繁体存**两列**（`content` / `content_trad`），不要拆两张表

## 已知的原典特征

- **阿含部有大量极短经文**：雜阿含 1362 经里很多只有一两句（如「闻佛所说，欢喜奉行。」），
  切片后就是十几字的小文件。这是原典结构，不是解析错误。
- **金刚经没有「三十二分」**：昭明太子的分品是后世添加，大正藏底本无此标记，故整卷为「正文」。
- 部分品名带校勘注（如「净土品第八十二丹本净佛国品」），来自 CBETA 的多底本对校标记。
