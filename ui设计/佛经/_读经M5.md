# 读经功能补全（M5：整部下载 / 繁简切换 / 点字查读音）

> 前置：M1 接口与页面、M2 位置采集、M4 显示设置与目录折叠见同目录其它文档。

## 一、整部离线下载

### 服务端：批量取正文

新增 `GET /buddha/book/getBookChapters?session=&bookId=&startSeq=&endSeq=`

- 含**简繁两版**正文（离线也要能切繁体），返回 `List<BookChapter>`
- 单批上限 **20 章**：超了自动截断到 `startSeq+19`，按华严每章五千多字估，一批响应约 140KB
- `prevSeq/nextSeq` 与单章接口口径一致
- 越界（`bookId<=0`、`startSeq<=0`、`endSeq<startSeq`）→ `-9527`；查无数据 → `-37`

Mapper 用注解 SQL（与 `getCopySetting` 一样属于单表直查），Service 里补批次上限常量 `CHAPTER_BATCH_MAX = 20`。

### 客户端：`ChapterDownloader`

挂在单例上的下载器（`baseLib/download`），不是页面里的协程——退出阅读页下载照样继续。

- **只下缺的**：先 `getCachedSeqs(bookId)` 拿已缓存章号，缺的按「连续区间」凑批，中间有洞就断开，不会把已有的章重复拉
- **进度广播**：`LiveData<DownloadState>`（bookId / done / total / running / error），页面自己决定怎么显示
- **失败策略**：单批重试 2 次，仍失败就停并保留已下好的部分，下次从这里接着下
- **完成判定**：Room 里该书的章数 = 目录章数

UI 入口在读经设置弹窗的「离线」一行：

| 状态 | 文案 |
| --- | --- |
| 未下过 / 下了一半 | `下载整部` |
| 下载中 | `下载中 128/557 22%` |
| 下完 | `已缓存全部 557章` |

下载中点同一行 = 停止（已下好的保留）。下载结束只在**本次看到过下载中**的情况下提示一次，避免每次进页面都弹。

## 二、繁简切换

### 数据现状（不用额外干活）

- `book_text_content.contentTrad` 早已全量填充（3870 行，无空行）
- **校验过：3870 行简繁字符数 100% 一致** —— 所以阅读进度的 `charOffset` 简繁通用，切换字形不会丢位置
- 单章接口和批量接口本来就会下发 `contentTrad`，Room 的 `ChapterEntity` 也早就有这一列

### 服务端

`book_read_setting` 加一列 `showTrad`（tinyint，默认 0，跟在 `keepScreenOn` 后面）：

- `BookReadSetting` / `BookReadSettingReq` 加字段
- `getReadSetting` 的 SELECT 加 `showTrad`
- `saveReadSetting` 的 upsert 加 `showTrad`
- `updateReadSetting` 校验只能是 0/1，否则 `-9527`
- 默认设置 `showTrad = 0`（简体）

### 客户端

- `BookReadSetting.showTrad` + `useTrad()`
- 设置弹窗加「字形」一行：`简体 / 繁体` 单击切换，和常亮一样即时生效
- `FojingReadPagerAdapter.contentOf()` 按设置取 `contentTrad`，**老缓存没有繁体时自动退回简体**，不会出现空白页

## 三、点字查读音

### 数据：`assets/reading/reading_dict.tsv`

由 `_读音库.tsv`（321 条术语）+ `_读音库_单字.tsv`（4303 字）生成，脚本：

```
python build_reading_asset.py     # _tmp/build_reading_asset.py
```

生成结果：**6218 行 / 84KB**，格式 `字词 \t 拼音 \t 类别 \t 是否标记`

- 术语优先于单字（同 key 不覆盖）
- 每条都用 opencc `s2t` 补了一份繁体别名 —— **切繁体阅读时点字照样能查**
- `mark=1` 共 108 条（66 条 hint 词 + 繁体写法不同的那些），正文里加下划线提示

### 客户端

`ReadingDict`（`baseLib/reading`）：

- `load(context)` 把 assets 读进 HashMap，只读一次
- `lookup(text, index)`：从 **6 字往 2 字**试，点击字在词里的每个位置都试一遍（点词中间也能命中），都没命中再退回单字
- `mark(text)`：只给 `mark=1` 的词加 `UnderlineSpan`。单字不加线，否则正文满屏下划线

点击判定（`FojingReadPagerAdapter.onCreateViewHolder`）：

- `setOnTouchListener` 里比较按下/抬起坐标，**移动超过 touchSlop 就不算点击**——不然每次滚屏松手都会弹读音
- 坐标换算：`x - totalPaddingLeft + scrollX`、`y - totalPaddingTop + scrollY`，再用 `getLineForVertical` + `getOffsetForHorizontal` 取字符下标（`Layout.getOffsetForPosition` 不在公开 SDK 里，编译不过）
- 命中才响应，没命中不打断阅读

弹窗 `FojingReadingDialog`：底部弹一层，大字 + 拼音 + 类别（法号/法数/处所…），点任意处收起。

## 四、实测

| 场景 | 结果 |
| --- | --- |
| 批量取 1-20 章（华严） | 20 条 / 141KB，简繁双份齐全，prev/next 正确 |
| 批量取 1-100 章 | 自动截断成 1-20，字节数相同 |
| `startSeq=0` | `-9527` |
| `seq 900-920`（越界） | `-37` |
| 读设置含 showTrad | 默认 0 → 存 1 → 回读 1 → 传 5 被拒 → 复位 0 |
| 读音库匹配 | 繁体「般若波羅蜜多」/ 简体「般若波罗蜜多」都命中 `bō rě bō luó mì duō`；单字「空」→ `kōng` |
| 打包验证 | `app/build/intermediates/assets/debug/mergeDebugAssets/reading/reading_dict.tsv` 已合入 |

## 五、没做

- **读音音频**：`_录音清单.tsv` 有 223 条待录，音频文件还没有，弹窗先只给拼音，没放假的播放按钮
- **抄经页查读音**：抄经是选字交互，暂不需要；要加的话复用 `ReadingDict` 即可
- **下载的后台存活**：现在靠进程内单例，App 被杀就停（已下的保留，下次续传）。真要「关掉 App 也继续下」得上 WorkManager + 前台通知
- **繁简在抄经页**：抄经设置里没放这个开关，需要时再加字段复用同一套
