# 佛经专题划分方案

32 部经，10 个专题。分类依据是**用户进来想找什么**，不是大正藏的部类。

命名口径：每部经有且仅有一个**主专题**（决定它出现在哪个分类树下），
另可挂多个**关联专题**（只影响推荐位，不改变归属）。

字数含标点、不含空白，取自各经 `_index.csv` 汇总。

## 落地建议

`sutra` 表不要加 `topic` 单列——一部经天然属于多个专题（心经 = 入门 + 般若）。
建两张表做多对多，`is_primary` 标记主归属。建表与种子数据见 `_topics.sql`。

首页取数逻辑：

```sql
-- 专题卡片（带经数与总字数，一次查完，不用 N+1）
SELECT t.id, t.code, t.name, t.slogan, t.icon,
       COUNT(st.sutra_id) AS sutra_cnt,
       COALESCE(SUM(s.char_count), 0) AS char_sum
FROM sutra_topic t
LEFT JOIN sutra_topic_map st ON st.topic_id = t.id AND st.is_primary = 1
LEFT JOIN sutra s ON s.id = st.sutra_id AND s.status = 1
WHERE t.status = 1
GROUP BY t.id ORDER BY t.sort_no;
```
